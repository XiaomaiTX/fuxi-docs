- 世界服华人联盟发展史(FRT视角)

_创作者：Fraternity.联盟 Fuxi Legion公司 Link Noel（林克）_

在正式开始介绍 凛冬及伏羲 之前 我们要捋一捋EVE Online 世界服的华人联盟发展历史，我在翻阅了联盟论坛的很多帖子以后，大概了解了华人联盟的发展历程：

FlyingBee： 写写我来欧服的经历吧，随时断更。

看到有人问历史啥的，我从我的角度把我的一些经历的写点出来吧，不过因为时间久远，有些记不清了，希望有人补充下。

首先说下玩游戏的目的吧，eve毕竟是个沙盒游戏，每个人对这个游戏的目标都不仅相同，有些人希望刷很多钱开最大的船，有些人想做solo大神一挑多，有些人喜欢小队战发展基友情，有些人喜欢做军团联盟大佬占地割据领袖群雄，有些人喜欢一辈子混在高安任务挖矿制造奸商同样乐趣无穷……玩法很多，我也曾经想做联盟指挥，想做solo大神，玩到现在，我给自己的定义就是个历史见证者（其实就是专业吃瓜群众）。

首先是国服的经历：国服内测就不说了，只玩了一个月多点，基本什么都没搞清楚就内测结束了。2006年6月12日国服eve星战前夜公测了，我也就去注册了账号，完全没有什么要多开的意思，就注册了一个号，只记得当初小行星带里都是护卫，矿带都是空的，过个星门都会提示交通堵塞什么的。当时就和现实里的几个朋友建了个叫人民公社的军团在高安做任务，熟悉游戏，期间过程就不说了。当时也就高安做做任务，大部分时间还在玩魔兽，部落优势服，我个联盟小猎人就喜欢在东西瘟疫杀杀人，引的一屁股的人追着我跑，我的付魔全是骑马速度的，乐此不疲。eve的第一次动心思，是从军团里的一个人开着乌鸦去辛迪加刷小行星带开始，看着军团账户上象征性的1%税收的跳动频率，对比下自己拿全部家产换来的末日沙场做三级任务的收益，心思动了。开着末日，带着家产搬去了辛迪加里面的一个有空间站的星系，中间过程不表，反正就是什么雾中楼舰队的堵门啊啥的，费了好大劲到目的地，其实这些现在看来，当初好菜。接下来的日子么就是刷刷矿带，确实收入很不错，直到有一天本地来了三条巡洋舰，他们打了我养的种子和怪，我不爽了，回站中槽换了个反跳，出站就发现他们三个中的两个就在站门口，正式要打他们的时候反而犹豫了，各种怕，但是还是打了，两个都死了，另一个没过来，eve生涯的首二个km就这样来了，打完发现心狂跳，手心全是汗，但是击杀的感觉真的是超级爽。

随后开始关注论坛，看到原来玩魔剑时候的盟友kok JL imgod都发展的蛮好的，我原来那个公会打架不是太多，就准备去加imgod。原因么就是原来魔剑时期的imgod战斗力令人印象深刻。结果我还没加，imgod分裂了，犹豫了半天，加了珊娜的aow战狂俱乐部。战狂那时候实行战功制，以非常简陋的论坛贴km自己来计算战功，具体怎么算的，已经想不起来了，反正当时下决心改学g族，开始开着小托开始单收生涯，足迹从源泉到绝地到贝斯再到北方特步特，fdk什么的，期间什么打掉烈火国服第一条货舰、第一条海军万王啊什么的活动也参加不少，后来战狂实施小队制，各个小队5到10人死亡分散在各个敌对大联盟附近收割，我也因为战功较多，带了小队在哪个位置收割，哪里又想不起来了。慢慢的，并战功领的战列了，慢慢的，战列越来越多了，然后各联盟战列成为主力，国服从巡洋时代进入战列时代，自然国服的战争就正式开始了。然后就是跟随战狂活跃在各个战场，什么68绞肉机，h-w会战啥的，接下来就是熟悉的BP节节胜利，源泉被纳税者联盟占据，战狂退出eve等等。那会我开始谈女朋友，结婚，生孩子，基本上一年处于半afk状态，又一年孩子出生完全afk，直到孩子一岁多才回归。回来才知道我们原来源泉的被称为源泉余孽啥的，先是熊猫烧香，然后喋血英豪，再后黑夜圣火，经历第三世界联盟，幽灵联盟，太阳联盟，gow，NBBE，经历了多处辗转的2-3年吧。这次回归后因为孩子出生还小，游戏就没有太多的时间去玩了，就开始很自然的成为火力狗环节，而且时间很零碎，而且国服的会战么太会蹲，收割么跑太远，而且那时候很多了开始在ECF上写EVE开服后的历史，我很喜欢看，不管自己BP方的还是FBP方的，对EVE的兴趣就逐渐开始转移，转移到参与到EVE历史进程这么一个过程的游戏方式。而影响游戏历史进程的，肯定都是一些大的事件，或者会战。但当时国服的会战大概率就是互蹲到半夜还不一定打的起来，开始动心思移民欧服。

国服就这样吧，有些没参与到，有些想不起来了。

到欧服来，第一次是09年的不知道哪天建了个号，没过一个礼拜就断了，因为啥都不懂，英文也不好。第二次是找破坦克借了个号，他们当初有一批人一起到欧服去玩过，也就借了个号。那个号在悟空公司，技能和钱都不多，我对欧服环境也不了解，信用卡折算月卡当时汇率应该还要1000多一年，有点舍不得，毕竟有个孩子在，要喝奶粉，要用尿不湿等等一堆需要花钱的地方，而且当时欧服plex应该只有300-500M左右吧，我再也不可能和在国服一样靠卖卡为生，只能老老实实先考虑生存问题。这可有点难到我了，在国服只做过任务，刷过矿带，那时候的什么异常、死亡我都没弄过，开条破BS刷了个把星期的矿带,然后国服好像发生什么事，就回去继续国服了。最后存活的就第三次进欧服了，其实距离第二次也没多少时间，但是这次却是下了很大决心跑欧服来玩的。花了不少钱卖plex，然后买了现在的主号FlyingBee，当时还对欧服的华人势力稍微做了了解，但是为了后面少花钱，还是优先考虑了生存问题去申请加了悟空，记得但是在ECF上写帖子，还被23RD的嘲讽了下说刷子当然选择悟空什么的。其实去了悟空还是没怎么刷，因为技能只有18m sp，纯A技能但是没掠夺，手上也没钱，就干起了第二次进欧服那个熟悉的刷矿带环节，但是好景也不长，好不容易下决心学了掠夺，买了刚运下来还没开始尝试刷异常，goons和test进攻Fountain，悟空所在的Blade联盟很快就放弃抵抗，全境失守。那时候还处于刚进欧服阵痛阶段，总揽上出现船全是英文，完全不知道是什么船，对当时欧服的势力也完全不了解，其实后面了解了才知道是当时的小部分细节。无非是当时Blade的老大IT（原来最早欧服强盟BOB余孽 xD）到了，Blade顶不住goons+test的进攻就直接放弃了。

搬出源泉后，懵逼了好一些日子，然后选择加入那时候还在INIT的子联盟IM下的23RD，然而很悲剧的是，刚过上几天有异常刷，跟跟INIT老大Sister Bliss的队打架的日子，然后就被毛子入侵了，记得那会刚好快圣诞了，跟了几次init的队，让我见识了毛子的两三个编队的drake队的霸气，然后听说Sister Bliss要去度假了，整个联盟基本就放弃抵抗全部搬到curse的G-0修整，从这个事情也让我体会到了欧服主权更替的频繁，还有欧服普遍对主权并不太重视的感觉。反正联盟搬到G-0之后，我没有做天使任务的声望，也还是不太习惯老外联盟这样的玩法，还是离开了23RD，去了stain找当时在W-V附近活跃的闪电，这之间相当长时间就是在stain刷刷矿带，找找boss，跟着ebon出去吃吃肉，偶尔克到低安和几个基友低安浪一圈，就是当时全部的娱乐生活了。

这个阶段持续时间蛮长的，直到23RD的CEO大花找到的我，毕竟他和我都是在杭州，面基过几次，面基的时候还有当时ECF的总版主一度、现在的H叔，盘古创立人之一现在早AFK不见人的roseattack等等。大花那时候找我，说和原来悟空的人一起合并成立功夫流氓公司，去北方venal的K3JR加入一个老外联盟的子联盟，那个联盟现在看很大一部分都在NCDOT里，名字忘了。我并不太喜欢收割的玩法，还是喜欢玩大舰队多点，于是在闪电公司留了一封告别邮件，又离开闪电去了功夫流氓，但是说实话，这次去也没有经历到什么，毕竟那时候英语不好，时间也不稳定，时区也蛋疼，到了K3JR还是基本就一票华人基友从K3JR一路roaming到M-O再到mara附近浪一圈，再一路回去，大舰队基本没玩到。

然后就是成立 紫荆城 联盟了，是当时几家华人公司联合成立的纯华人联盟（之前长城、熊猫啥的我都没体验到），目的是辛迪加的某个4级任务点，运作模式就是和现在的osy模式基本一样，但是当时的组织者比较坑，Luna和手心是倡议这次活动的几个主要负责人之二，Luna是主要组织者，手心当时说会带队在附近打架，然后就是一群热血的人包括我把东西搬到目的地后，完全就没里后话，没人组织，没人做任务，没人运输，没人组织打架，反正啥活动都没，luna和手心大部分时间也都消失不见，于是很快就不了了之，各回各家，各找各妈。

于是我又回了stain找闪电玩，这个时候就要说到后面的传奇人物阿水了，他的ID是Water Brother，俗称水哥，那时候他刚进欧服玩，技能低，每天就是开着一条hurricane在我隔壁一跳刷矿带，晚上闪电起队roaming，阿水就是一条火尾鸡做斥候抓人。水哥成长的非常快，指挥这个东西，确实要看天分的。水哥就是那个自带天赋的人。很快水哥开始开截击带队收割，在后面ebon afk玩魔兽还是回国服的一段时间里，水哥更是成为主力指挥。然后就是当时还是新人高安公司的LOTM在高安的POS被推增强，然后水哥、andy带着闪电众人去高安帮忙，至今那天开的一条geddon我还放在那个星系的空间站里，配置还是炮船配置（geddon现在改成无人机船了）。然后就是双方看的对眼，闪电邀请LOTM也到stain发展，然后就成立了北极星联盟，但说实话，北极星没有啥发展，因为在W-V附近，只能刷刷矿带，好的任务点都有一群毛子占着，多了LOTM的人，矿带其实根本不够分的。不过基于闪电和LOTM的基情，并没有发生什么摩擦，就把北极星当成一个大公司一样的慢慢发展着。这里唯一印象比较深的就是由于水哥的活跃，北极星一度加入了stainwagon，第一次成为一个联盟群的一员。

再次改变的时候，就是盘古的成立了。从悟空出来去过AAA后来又在s2n的Wind spirits和当时在AAA的火星、租地公司cappuccino cafe的roseattack，SOCM的runers，还有老悟空的所思，商量成立华人联盟，热情邀请了当时在stain的闪电和LOTM，这里具体的一些细节，我并不是太清楚，反正就这样盘古成立了。创建之处，盘古主要战斗力就是原来的SOCM，闪电成立加入盘古的马甲公司TCF，人数当时最多但是新人占比率最高的LOTM，还有租地公司的cappuccino cafae，我因为和rose面基的关系，在闪电人员加入TCF的时候，我选择加了面基基友rose的cappuccino cafe。但是盘古刚成立，Wind就运用他的外交关系，拿到delve的c6y附近几个位置的刷怪权，战斗集结地和s2n一样在c3n，走跳桥就2跳，可谓方便。值得一提的是，当初盘古刚成立就能出动几十条全T2 fit的ABD队，后勤也全是guardian，战斗力还是比较彪悍的。但也发生一些摩擦，比较出名的就是踢了Mrdiao事件，其实作为吃瓜群众的我，并不太了解事情的全部细节，但有一点，Mrdiao和手心是非常类似的，就是说话的腔调让人听了会非常的不爽的那种感觉，按Wind的说法，就是diao会制造的麻烦可能会比他所能帮助联盟的更多，所以Mrdiao被火星踢出联盟，也就没说什么。

然后就是当年的世界大战：南北大战。北方是goons+test+一堆联盟（那时候还不是太熟悉欧服的势力），南方叫soco，以AAA,s2n为主。大战一开始，盘古就跟着s2n把所有物资撤到319-的NPC STN里了，goons+test的集结点就在2跳外，319和后面的4-07的一段时间就是我欧服玩的最爽的时期，基本每天不管哪个时间上线一直在打。goons+test+其他或者就叫CFC？（我不确定CFC是不是那个时候开始叫的），反正那时候他们就是一天到晚的堵在319的空间站附近，只要s2n这边有FC，就会起队出去打，那会BC3刚出，s2n就常用naga甩葱test的drake队。这里最出彩的一次就是水哥带领的bomber队一次团了test70+的drake队，也导致后面南北大战的宣传视频里出现盘古联盟的字样（我很不幸的投偏了，没蹭上KB）。但是被堵着空间站，肯定是守不了主权的，当delve这边主权丢差不多的时候，s2n选择回高安修整，而盘古因为Wind和火星（火星那时候是AAA的F1蹭炮王）的关系，去了4-07协助AAA继续守catch。这期间就是在Querious，盘古在Wind和水哥带领下，只有大概10人不到的小队，利用test在拿主权时的失误和游戏机制，拿下了Querious南部H74-的主权和空间站，硬是在那个位置拖延了整整一个多星期的时间，在当时也是非常出彩的一次（我在线时间不多，这个过程并没有参与到）。

接下来就是4-07附近守不住，AAA退回GE-，盘古也跟着搬到AOK附近，也就这时候，我觉得cafe里的PVP氛围不好，重新加了TCF。AAA在GE-也没守多久，就退回stain修整了。恰逢当时势力战争改版，盘古决定去玩势力战争。然后就是疯狂的绕杆子时期，阿水、andy、莫辉、啤酒等一大票人通过绕杆子狠赚了一笔，盘古后期的很多超期就是这个时间绕杆子赚的（我很后悔那时候没一起去绕，不然我也发财了 xD）。疯狂过后，CCP平衡势力战争，一下子就没那么赚了，盘古的众刷子们开始退出势力战争。这个时期水哥已经成长为主力指挥，势力战争之后，水哥带着盘古在BWF-堵门，堵的昏天黑地的，水哥一条截击 一个隐侦扫描，基本过BWF的不管大小船，很难通过我们的封锁，BWF日渐萧条。结合前面的一些经历，也就有了华人联盟抱谁谁死，堵哪哪黄的名句。

再次转折，是NC独守特布特，单抗goons失败后吧应该，具体记不清楚了，反正是NC+nulli(s2n)+另一N开头并不出名的联盟成立了N3联盟群，强行取名N3。在我们把bwf堵黄后，Wind再次外交，加入N3，开始往新的目的地出发。当时的目标就是ckx，通过盘古当时的主力SOCM TCF LOTM的人员的努力，和绕杆子得来的超期，打下ckx虽然付出了些努力，不过总体还算顺利。拿下ckx周边后，盘古进入了一段稳定发展期，人口爆发式增长，联盟内各种新公司增多，nuwa和fuxi应该都是那时候成立的，PLA也是正式的登场了，荣耀先是在LOTM里，然后出来单干成立PLA，其实当时我对联盟内各公司完全不了解，因此当时具体是个什么状况，我也不是很清楚，反正那时候看上去人很多，很繁荣的样子，但其实矛盾已经在慢慢积累了。先是因为周边环境太安逸，周边没有太多敌对势力，整日没架打就是刷，有些战斗人员开始AFK，其次新人和老人也存在矛盾，新人像荣耀这样成立了公司，当了CEO，从盘古大学到了盘古主联盟，也开始为联盟做运输，就想要更多的话语权，直到连联盟CEO Wind也无聊开始玩dota也AFK，把联盟CEO给了火星，矛盾正式开始爆发。
