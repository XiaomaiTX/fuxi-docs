作者：连山

3月22日，凛冬联盟群（熊猫人）和Legacy（鳄鱼先生）的和平协议（NIP）正式结束。但鳄鱼和他的小弟XIX（俄罗斯人）在5天前就已经按耐不住单方面撕毁协议，展开了对凛冬的进攻，拉开了2019年春季主权站的大幕。

![本帖从3月22日开始，记录这场春季防守的战争故事。](/images/winter-2019-war-report/image1.webp)

_本帖从3月22日开始，记录这场春季防守的战争故事。_

凛冬主权战还在继续。鳄鱼+XIX势头很猛，我们不但需要智慧赢得这场战争，还需要更多的枪炮。

战争刚刚开始，初步预计至少持续2个月。慢慢观看。

![image2](/images/winter-2019-war-report/image2.webp)

敌人主要两个方向来袭。一个是46dp方向主要骚扰战，一个是ias方向主要是主权进攻战。

3月24日晚，test组满编噩梦队，拆I-9G的铁壁护盾；WC组满编银鹰队，防守52CN-6的跳桥出增强。

test勾引WC去I-9接战，WC静待TEST主动出击。最后test也知道WC不会上当，拆完铁壁护盾之后，打道回府。WC组飞燕寒鸦队，吃了两条掉队噩梦。

一条噩梦知道跑不掉，选择自爆，义士啊。

![image3](/images/winter-2019-war-report/image3.webp)

3月27日，无大事。从下午到晚上10点，全都是防守型绕点。

进攻性绕点，增强敌人 3Q1T IHUB一处。骚扰部队也有货件和大鱼斩获。

紧接着，4月5日（清明节），test和XIX公共组织了CTA，组织了噩梦队、小马队、银鹰队、小船队和电子护卫队。WC组织了银鹰队、隐轰队、寒鸦队、电子护卫队应对。

结果是输掉了战损比，IAS的IHUB被绕紧了增强，因为我们在IAS有星城且是东迪特的门户，直接关系到整个战略布局，关系到后边战役的主动被动。所以，4月7日IHUB出增强时的大战在所难免。

输掉战损比和IHUB得原因是“ Noraus: 不好意思打得太久了 今天我们损失比对面多很多，原因大部分是诱导进场和电子战对抗的问题。好在这些都不难解决，快点申请srp 周日准备世界大战，下午五点到晚上八点。 ”

![image4](/images/winter-2019-war-report/image4.webp)

虽然打掉了IAS的反诱导，但凛冬压力山大。今天是周末，北京夜幕降临，美洲人起床，欧洲人也在白天活跃期。IAS上方阴云密布。

**4**月**16**日

**4**月**14**日，在**FR46**攻防战的时候，**test**增强了**FQQ**和**1L-**两个很重要的星系的**ihub**。**test**发战略**op**，组了**400**人来绕点，背后有一个满编旗舰队待命；**WC**对等的发了战略**OP**并拉了红灯组了银鹰队和小船队以及旗舰队应对。通过斗智斗勇和反诱导，成功守下点来，双方你来我往的转圈圈，没有接战。

![image8](/images/winter-2019-war-report/image8.webp)

**1L-**和**F-QQ**外传：

1L- 和F-QQ对凛冬 frt来说是有着深厚感情的地方。由于FCON得咄咄逼人，常驻FQQ口袋的盟友因为和fcon处于同一时区，且实力弱小，将FQQ转让给了frt，时值移民潮，又有采星等联盟加入，frt有勇气拿下fqq，fcon扬言打下FQQ再租给我们，想羞辱我们，N刷信用卡守下了FQQ，并以此为跳板打垮了fcon。羽毛这个阶段还总该跳旗舰骑frt，因为FRT刚刚从OSY出来，旗舰力量还比不上羽毛，现在想想，真是时过境迁。

1L是frt从osy走向零零的第一个大站，当初集结点从osy转移到1L-，好多人心里都很忐忑。

1L作为FRT集结点很长时间，在移民潮的福利下，FRT发展迅猛。在邪恶湾流开始进行零零的规模生产。小蜜蜂也在积极的吸收华人移民潮人口，给了好多优惠福利，很多原本不具备加入条件的华人公司都加入了goons。小鳄鱼也不示弱，他的策略不是降低门槛吸收华人，而是要用大棒把FRT额杀住。于是在整个邪恶挽留，布满了test的墩子，J系列就是我们的老朋友。那时候东迪特还是solarfleet的地，我们只能在邪恶挽留顶着墩子刷怪，导出时反诱导，导出被隐投，每天挖矿从下午3点挖到晚上10点半。

随着战局变化，test注意力到了与PL争夺普罗，而我们也对东迪特进行这拉锯战一样的争夺。然后东迪特攻下，普罗被test拿下，XIX被虫洞全明星联手绞杀，XIX的泰坦大航被伏击，联军进攻test，战败，马关条约，马关条约结束，凛冬主权防卫战。

往事不堪回首。

接上文：

现在pgl（test ceo）已经明白非周末或者假期能够真正打赢我们。所以他把战术放在了疲劳战术上，他宣布每天澳洲时区都必须派出截击队骚扰生产。把打击活跃人口放在首位。这是非常让人恶心的战术，所以我也决定每天都必须有人在晚上组织截击队关照伊妹和艾索。只要截击轻突这种效率高的船体。记住要有耐心，我们没有通往敌人腹地的跳桥系统，所以花的时间要比敌人多。

鳄鱼在连续多次接战中吃了屎。目前在调整战略，平时以骚扰为主，但目前效果并不明显。

test在举棋不定，wc在等着test出招。

然后，WC一个机灵鬼混重进了跳驱的带跳范围，然后WC无限跳队友，XIX怎么跳驱都摆脱不了敌人。于是放弃进攻。

![image9](/images/winter-2019-war-report/image9.webp)

一个月骚扰进攻+复活节攻势 ，test+XIX的各种攻势均被WC化解掉，没有沾到一点便宜，反而到处丢盔弃甲。感觉他们已经进入了一个比较疲劳的状态，常规打不过，旗舰不敢冒险。且test出师无名被各种诟病且远距离作战，老百姓并没有体验到想象中的痛打脚本狗的快感，相反到处吃屎，苦不堪言。

作为防守方的WC，这是一场保卫家园的战斗。一方面占据防守优势，一方面占据时区优势，一方面还有凝聚的人心。所谓天时地利人和，全都有了，这块骨头怎么可能好啃？

后面，test如果想继续打下去，除了超期，也没有什么别的底牌了。鳄鱼是否全部家当都弄到前线孤注一掷，战争是否会继续升级或者急剧升级，还是就此偃旗息鼓，和平结束，且看跟踪报道。

TEST:

今天很高兴能在这里向EVE世界服务器介绍即将长期入驻的中国人群体。 晨曦服和宁静服的分离总是让我困扰，因为EVE的魅力正是由于它使整个世界都在同一台服务器上为同一个目标而竞争。无论出于何种原因，有第二台服务器的存在总是让人觉得很遗憾。现在，在中国玩家逐渐开始转移到宁静服务器七年之后，我想说的是，我们现在终于能够欢迎主流中国玩家群体加入到这场全球游戏中了。

多年以来，宁静服的中国玩家群体的数量一直在增长，他们(Pangu Coalition)首先是作为我在绝地之域的盟友，接着在万圣节战争期间与我所在N3联盟并肩作战。我仍然记得Wind Spirits曾告诉我，他必须每周为他的玩家开研讨会，并教会大家如何连接宁静服务器，以及如何续费充卡。此外，N3不得不始终允许Fraternity在战争中拿出相当多的时间去赚取ISK，以获得游戏时间，因为大多数玩家始终无法使用现金购买游戏时间。这也就是为什么尽管中国玩家可以加入宁静服，但是更愿意选择晨曦服并使其蓬勃发展的原因。但是那些时代已经过去了，尽管这次晨曦玩家的大规模进驻是由于一些不幸的事件所导致的，但我们作为宁静的玩家应该把这事私下看作是让宁静服获得了更好发展的机会。

距离Wind Spirits 第一次联系我让我给他们一个星座去发展已经过去了很多年。现在我们的服务器上有许多不同的中国公司和联盟，而Wind Spirits创建的联盟，现在已经是这个游戏中一个独立联盟群的主要领导。随着PIBC及其盟友的加入，中国社区很快将成为宁静服务器上最大的社区之一，而且我们已经看到大量的人员活跃了这个曾经死气沉沉的时区。中国时区现在会同时提供大量的盟友和敌人，TEST联盟碰巧目前正处在这样的情况之下，而这游戏本该如此。

在接下来的几周时间里TEST联盟将帮助这些新的中国玩家联盟进驻欧米斯特（Omist），并帮助这些大部分成员都是全新账号的团队来快速适应我们的服务器。

在过去的数月/数年当中由华人主导的凛冬联盟群一直是我们的主要敌人，因此我们也备受中国社区的关注。这让我们所有的行为都被放在了放大镜之下。这种情况下我们本该要求自己做到最好，但很显然我们没有成为一个值得尊重的敌人，放任仇恨升级为民族矛盾。这是我们的错，我们为此感到懊悔，并一定加以改正。

由于之前某些宁静服务器华人团队给人留下的某种印象，导致宁静服务器中正蔓延着某种担忧：如果我们帮助晨曦的玩家加入我们，会给宁静服务器造成一定程度的损害。这种观点虽然事出有因，但是也会伤及无辜。即使害群之马无法避免，也没有理由因此敌视整个群体，TEST联盟也会在第一时间向他们伸出橄榄枝，并帮助他们发展。

总之，这对整个宁静都将是一个发展的机会。毋庸置疑的是现在EVE的确需要一些新鲜血液的加入，大量新人的进驻通常都会带来大量的活动、新闻和故事，但是通常这些新玩家也不会在EVE里停留太久。而随着AOM及其盟友的加入，现在我们有机会让一个由充满热情的老玩家组成的成熟联盟加入宁静。因此TEST 联盟非常高兴的宣布我们愿意帮助他们，并加快他们的成长速度，我们也很乐意看到他们在这个世界长久的存在下去。

华人势力想自己在零零自己下一块像样的地，异常之艰难。有多少人马不说，反时区进攻主权，就几乎不可能。

凛冬打这片地，也是经过无数次熬夜，加py老外帮忙，再加各种外交机遇才打下来。

AOM初来欧服想靠自己打块地，几乎是不可能的，想快速发展，最好的方法就是有一块安逸的纵深零零主权，但这谈何容易。

在鳄鱼与wc的主权战中，鳄鱼尝尽了反时区作战的痛苦，意识到加八力量的重要性（不仅仅对wc，还有对蜜蜂）。这必然是给AOM开出了很好的条件的因素之一；而凛冬为了巩固自己力量，减少潜在敌人，也给AOM开出了很好的条件。

环视宇宙，或许这是最好的两个条件。而在阵营选择和一山不容二虎的共同作用下，AOM选择了legacy，这在AOM利益来说，是无可厚非的。

Wc和AOM的对抗已成为必然，只不过碍于加八同胞面子，不能太露骨，但又像是wc和RR（RR碍于鳄鱼和wc对立，脱离wc后去了北方而没有去鳄鱼。。这是我猜的，还需要解密）的那种关系。馒头与鳄鱼合作前提有不参与进攻华人主权这一条，N则命令成员不允许收割AOM。但这怎么能遮盖住桌面下的暗流涌动。

馒头已成功迈出第一步，各种舆论和嘲讽是不可能阻止AOM踏入欧米斯特的步伐。受国服威名影响，和开荒的兴奋，很多新旧成员坚定了跟随馒头的信念。而馒头好像也扫除了迈入零零的各种障碍。今后一段时间，AOM将会建立自己的管理体系，过的将会很充实。难点将是以后，如何持续保持成员对自己的信仰，以及兑现自己自强不做pet的承诺。信仰的崩塌会是AOM最大的灾难。

凛冬将迎来又一次战略考验期。如何能在AOM快速成长中，继续保持自己的优势，并捋顺内政外交，将是重要的一课。这将是军事强人N的一堂内政秀。能否成功我们拭目以待。

5.11 WC的46dp 小工业堡护盾增强，XIX起CTA银鹰队，test起缪宁对帮忙，WC起战略OP应对。 DT后，堡垒开始出增强，XIX 依然是跳刀杂技银鹰队，加上小航TJJ打建筑，等着test进场。WC依靠扫描带跳截击，击杀对面几条重览，以及指挥的监视者级。随后test进场，XIX和test合并和WC开始肉搏。双方一阵互换，人口基础差100，船型配置比WC整齐，WC在被打光后勤后撤离。堡垒被打进装甲增强。WC在撤退中，接Nl老板指令，返回46DP，吃掉XIX两条航母。然后撤离。战斗结束。

大家好 我是512日的联盟更新，今天是母亲节不要忘记给妈妈打电话。
