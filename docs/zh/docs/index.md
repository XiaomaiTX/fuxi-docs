# 伏羲天团奥姆尼珀腾斯圣殿

*伏羲是欧服~最正经~的华人军团之一，常年位于*[*Zkill欧服军团PVP排行榜前十位*](https://zkillboard.com/corporation/98185110/ranks/)*，*[*宁静周刊华人军团PVP排行榜*](https://space.bilibili.com/1273724812)*前五位，于2021年赢得CCP举办的*[*军团招新视频奖第一名*](https://www.eveonline.com/news/view/corp-propaganda-contest-the-winners)*并获得NPC空间站投放军团视频广告资格。*

*真-天团伏羲受宇宙五大原初神灵祝福，千年战神黄金阿瓦隆之王，新伊甸黑袍至尊大法师—HY率领麾下机械战帝、灵能圣者、战术宗师一百六十一人及不朽者超级战士二千一百三十六人横扫数十洋人精英PVP头部军团，力竞新伊甸西北部战力天花板，黄金舰队所过之处天地昏黑，日月无光，维度震荡，次元壁龟裂，天地为之颤抖，亿兆生灵自细胞内感受到无尽威压和震撼，无不拜伏。*
