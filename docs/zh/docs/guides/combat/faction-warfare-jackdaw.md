加达里卫队四级任务寒鸦攻略

在低安做卫队任务具有一定的危险性，请给位常用五度扫描，寒鸦本身较脆只能距离抗，请不要各位拿任务寒鸦去PVP，很傻的行为。因为这玩意来个小护卫都可干死你，所以请各位常用五度扫描

在做任务的时候在你跳跃到任务地点的时候，在本地总览中会出现相对应名字的信标点，这样抓你的人会非常的方便。

**K-SE友情提醒您：任务千万条，安全第一条，方法不规范，寒鸦就完蛋！**

- 【阻断供给】

进入轨道后寒鸦开启高速模式，Q键随意走位尽量向后拉不要面向怪拉走位，拉到安全距离后开启狙击模式 在这里一定要注意（联邦精锐科科沙）三个护卫怪会给你上网子，大大降低你的速度请第一时间将其清理（清理护卫的时候请用动伤导弹）

将三个网子怪清理掉之后，你可以Q键手动拉环绕将场上三个工业进行击毁（清理工业的时候去请更换热伤导弹）

寒鸦在拉距离的时候一定要保持70-80KM左右，如果你拉到50KM以内很有可能你就会蒸发了，注意寒鸦盾修不是让你硬钢的

视频链接：https://b23.tv/myfUTI （求个一键三联加关注）

二【开采者的愤怒】

这是一个开放空间任务，进入后寒鸦开启高速模式，迅速Q键拉走位，拉到一个安全距离开启狙击模式 将三个网子护卫怪清理掉后（联邦精锐科沙沙）（动伤导弹），这个任务怪的火力比较高寒鸦保持距离一定要在70-80KM左右，将网子护卫怪清理完成之后，击杀左侧四个工业（热伤导弹）即可完成任务，注意一定要长按五度扫描，因为这是一个开放空间任务，跳过来就可以抓你，如果你的任务点被扫出来了，那就请放弃本次任务等待下一轮刷新。

注意事项这个任务危险性比较高，所以在做得时候一定要常按V键

视频链接；https://b23.tv/13R7LH （求个一键三联加关注）

三【灰色地带】

进入轨道后，开启高速模式快速拉到安全距离后开启狙击模式，将三个网子护卫怪（联邦精锐科沙沙）（动伤导弹）快速清理，注意这里会有战列给你扣帽子，但是问题不大将在场所有工业击杀（热伤导弹）后即可完成任务，本任务因为工业居多，所以所耗时间也会相对较长一些 寒鸦保持距离70-80KM

视频链接：https://b23.tv/lj7RUj （求个一键三联加关注）

四【轻视的代价】

进入轨道后，开启高速模式快速远离怪堆拉到安全位置开启狙击模式 注意这个任务内有会蓝色NPC帮你是非常菜，进入之后将三个网子护卫怪（联邦精锐科沙沙）（动伤导弹）快速清理 同时拉近和舰队指挥官（动伤弹药）的距离 保持70-80km的距离将其击杀任务即可完成这个任务相对简单，就是在打舰队指挥官的时候需要耗费一定的时间

视频链接：https://b23.tv/nXIfcD （求个一键三联加关注）

五【死人不说话】

进入轨道后，开启狙击模式同时快速拉到安全距离 锁定中间的POS（会有四个战列怪）保持距离70KM-80KM 当POS掉到三分之一的甲时，会刷新一波怪，快速将三个网子护卫怪击杀（联邦精锐科科沙）后，将POS打爆即可完成任务 本任务会掉大量的盖伦特声望，如果在意请勿接

视频链接：https://b23.tv/HMQrZu （求个一键三联加关注）
