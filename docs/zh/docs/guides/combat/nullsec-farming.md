# 00 地区刷怪教程

（一种基于传统PVE配置的00区域刷怪的创新性解决方法和生产方案）

## 写在前面的话

00地区稳定存在着大量的战斗异常空间，异常内的怪大部分有着较高的赏金。如果我们采用适当的配置刷怪，就可以以较少的成本、较轻松的操作换取较为稳定的收入。刷怪作为EVE的00区域中的重要生产方式，已经贯穿到00生活的方方面面，因此，对于新人来说，掌握刷怪技能，熟练生产方式，是在00地区立足的重要方式。

## 舰船配置

### 配置思路

普通刷怪的配置思路主要围绕于以下三个方面：便于操作，普适性强，性价比高。

从武器装备的选择上来说，一般为了便于操作，不会选择炮塔、导弹发射器等需要消耗弹药的装备，而是选择无需进行弹药补充和额外锁定操作的无人机。这并不意味着炮塔、导弹发射器等装备在刷怪的领域没有用武之地，但在00地区的一般PVE刷怪中，不同的无人机已经占据了绝大部分生态位，因此在对于新人的刷怪配置中，一般也推荐使用无人机作为基本的PVE武器。

从防御方式的选择来说，由于刷怪具有持续性，一般不会使用纯粹的有效抗、结构抗作为舰船的防御方式，而是采用自修（包括主被动）的方式。盾修和甲修在不同的舰船上适用范围不同，二者均为PVE常用的防御方式。

从舰船的选择来说，出于以上的两点考虑，也出于操作灵活和安全性。除去特殊的配置要求来说，基本的00地区刷怪一般会采用巡洋舰级的舰船，且带有较大的无人机带宽（和相应加成）、较为宽松的中槽数量（便于防御）、以及有较高的性价比。在长时间的实践中，涌现出以狂怒、伊什塔为代表的G族无人机刷怪配置。因此，我们在本教程中，也主要讲解介绍这两类主要的舰船和配置。

在无人机的选择上，优先考虑伤害和加成对应的无人机类别（如兔子-动抗最低-用C族无人机），随后根据无人机带宽，采用重型>中型>轻型的分级模式，分配无人机带宽。一般来说，能使用T2无人机则使用T2无人机，若不能则一般使用势力无人机，一般不推荐T1无人机。

## 基本操作教程

### 前言

00地区存在大量战斗异常。常用于刷怪的包括：集会点、废弃的集会点、老巢、废弃的老巢、避难所、圣坛、庇护所。其中，绝大部分都可以使用YST进行刷怪，仅在效率和玩法上有部分区别。因此，可以根据个人喜好和船体配置等多方面选择刷怪异常，也可以直接刷一般普适推荐的异常点。

在战斗异常打完后，有一定概率（看脸）触发对话框，并提示有新的远征可用，也就是常说的“出远征了”。远征是一类由普通PVE产出的特殊PVE地点，根据不同的难度有着不同的产出，一般会包含盒子（换钱）和死亡装备，也要求不同的舰船配置和操作。对于新人来说，可以简单地将远征售卖给其他专门打远征的玩家而换取利润，有趣的是，军团在官方层面回收所有远征，无论地点，如有需要可单独查看相应内容的教学。

刷怪的收益一般以“跳”的形式发放。每一“跳”的时间范围为击杀第一个怪开始的15分钟，时间结束后重置时间，开始新的循环。除以“跳”形式支付赏金以外，部分赏金会进入星系事件监测装置（ESS）中去，在固定的时间周期后支付到玩家帐户中去。

收益参考：YST（640DPS，小避难）每“跳”收益8-15M

### 一种基于狂怒级舰船的集会点刷怪方式

集会点，全称古斯塔斯集会点，是一种主要以中型舰船怪为主的低难度刷怪地点。其基本的赏金收益较低，主要收益来源为远征（6/10，100-200M ISK）。由于其怪的数量较少，强度较低，比较适合新手入门进行刷怪练习，在熟悉相关操作的同时也能获得不少的收益。

一般来说，落地后可见以下的建筑布局，可在如图所示附近的哨站打开加力和护盾装备进行环绕，放出无人机进行攻击。一般来言，只需要在最开始刷怪时手动锁定和攻击某一个怪，利用自动反击机制便可自动攻击其他和新刷新的怪，无需手动操作。

### 伊什塔刷小避难

避难，全称古斯塔斯避难所，在实际结构上来说有大、小区分。请注意，下图所示的为大避难（无星门），因其刷怪种类以及行为与小避难有显著区别，需要额外的操作，因此不在本次讨论范围内。

![00 地区刷怪教程 图 2](/images/nullsec-farming/04-operations-02.webp)

而小避难也被称为星门避难，得名于其地点建筑（星门）

![00 地区刷怪教程 图 3](/images/nullsec-farming/04-operations-03.webp)

相比大避难，小避难的刷怪以战巡、战列为主，刷怪赏金较为丰富，同时目标较大也利于重型无人机进行攻击，从而达到较高的刷怪效率。

区分大小避难，除跳进去观察建筑和环境以外，还可以通过确认在点击跳跃时是否出现了下图中的提示辨别。

![00 地区刷怪教程 图 4](/images/nullsec-farming/04-operations-04.webp)

YST等舰船在刷小避难时，一般常在星门建筑进行开推环绕（一般1000-5000m，为了防止卡在建筑上），释放无人机并打开火力集中选项打怪。一般来言，只需要在最开始刷怪时手动锁定和攻击某一个怪，利用自动反击机制便可自动攻击其他和新刷新的怪，无需手动操作（注意小避难的怪一般不会转火无人机）。但仍需注意本地情况，并在来白时及时规避，避免损失。
