# 斯特修斯级（中白）刷怪配置与打法

:::tip 船体加成先看清楚
斯特修斯级的加成为：盖伦特巡洋舰每级 **+10% 无人机血量与伤害**，艾玛巡洋舰每级 **+4% 装甲抗性**（满级约 20%），另有隐秘行动隐形装置与探针强度加成。
:::

:::warning 关于本文的盾抗配置
船体的抗性加成作用于**装甲**，而本文示例采用**盾抗**配置——这是作者的选择，可能出于其他考虑（机动性、初始爆抗、电容余量等），并不代表配置有误。

照抄前建议自行对比盾抗与甲抗的实际有效生命值（EHP）与电容表现：想吃到那 20% 装甲抗性就改甲抗，想保留盾抗的机动与初始抗性就维持原配置。
:::

说一下一般人常问的问题：

Q：新人是一开始就不上毒蜥就上这个中白吗？

A：不是的。中白是比毒蜥吃技能的。一个没技能的新人用毒蜥伤害还是更高。但是在新人从毒蜥冲刺yst技能的时候（比如重无技能和G巡洋技能），就可以用中白而不是挂着重无用中无了。

Q：第一个配置大修扛得住吗？

A：环绕任何东西10km，环绕避难的石头10或者星门15，稳稳的。大避难还没测试也不建议去刷。

Q：高槽都是空的，能上隐形吗？

A：当然可以，只要你的cpu和pg够。可以上无人机增效链接加控制距离，也可以上隐形确保安全隐跳和过门。

Q：你这个比毒蜥强在哪里？

两个配置都比毒蜥要便宜。

优点2：永动线高。这个我让工程学3级的萌新模拟过，大修配置完美永动，而且cpu和pg都不超。反观毒蜥因为要上推子和抗性，没地方上回电，已经有很多萌新下推子去刷怪了。

优点3：起跳快。当本地进白，毒蜥需要关推起跳。这点很多不熟练的萌新都会手忙脚乱。而且有时候是推子转了一半甚至一点就进白，然后点起跳朝向需要很久的时间。如果忘了关，开推起跳甚至要9秒（见上图模拟毒蜥）。反观中白，不带推子，起跳4.11秒。不需要任何操作，无人机都不要就跑了。根本抓不到。等技能高了上站撸配置，跳30站撸。站撸起跳有时候更快，而且敌人的落点也不一样，反而更安全。

优点4：无限刷。毒蜥是自回盾，刷的勤快的其实刷几跳盾就下的差不多了，必须回站回满盾再刷。中白是修盾，永远是满的。只要你愿意可以不回站可以一直刷。

优点5：技能重合。中白主要输出在重无上，yst用的也是重无。中白用的盾抗防御，yst用的也是盾抗。中白的G船体加无人机输出，yst需要G巡洋5才能上。所以新人在冲yst技能的时候，中白的刷怪效率也会越来越高。甚至可以先冲重无和G巡洋5，再学重突需要的其他辅助技能（比如cpu和pg管理学5），最大化刷怪效率。

优点6：不占用星系资源。我测试刷了其他异常，收益甚至比刷避难高（）具体往后看。一个星系更多的异常被利用就会有更少的纠纷和抢异常的事件发生，大家都开心。

那中白具体刷啥？

我测试了小避难，forsaken hub（废弃枢纽），forsaken rally point（废弃集会）和port（港）
