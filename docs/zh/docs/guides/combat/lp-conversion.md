# LP 变现攻略（砸单）

:::warning 兑换比例与砸单价会变
LP 兑换所需的材料与 ISK、以及成品的收购价都随市场波动。文中比例只用于说明**计算方法**，实操前请按当期市场重新算一遍。
:::

大家好，我是梦幻。前段时间有越来越多的新人来到了欧塔萨塞做C海军任务。不过新人都不知道该如何把刷到的lp变成isk，论坛内也没教程，我就抽空写一下该如何的最大化讲你的lp变现，获得最大收益。

首先讲一下lp是什么。Lp，loyalty points，中文是忠诚点，每次做任务都会给你相对应的忠诚点最为奖励。这东西类似于积分一样，你用isk+一些材料+一定数量的lp就可以在该势力的NPC空间站兑换值钱的物品。所以思路很简单，就是兑换的物品的价钱要大于你的成本，也就是材料钱和一些换东西的isk，你就能通过lp获利了。

刚刚点个那个按钮是isk比lp的比值。比如如果isk/lp=1000的话，那当你有1万lp的时候，你就能换1千万（10M）的isk。这个按钮是帮你从最高到最低排序的，第一次点击默认从低到高（很智障的设计），第二次才是从高到低。我们的目的是换更多的isk，当然就是要把比例往大了换。还有人可能这时候看到的框是绿色的，C海军上个月也是绿色，这就说明这些值得去换去刷。

在说一下这些栏都有什么用，不会英语的人可以记一下：

最左边的是物品ID，一般用不到

左边第二个“LP”指的是兑换该商品需要消耗的LP量。比如图中第一个商品兑换一个就需要2万4千的lp。

左边第三个“ISK” 指的是兑换该商品需要消耗的ISK量。比如图中第一个商品兑换一个就需要960万的ISK。

左边第四个“Item”指的是物品名称。比如图中第一个商品 Caldari Navy Heavy Assault Missile Launcher 就是加达里海军重型攻击导弹发射器。

左边第五个“Other requirements”指的是指的是兑换该商品需要消耗的特殊材料。比如图中第一个商品兑换一个就需要消耗一个T1发射器，63和captain牌子和106个major牌子。

右边第五个“Other Cost” 指的是指的是兑换该商品需要消耗的特殊材料的总价钱。比如图中第一个商品兑换一个就需要消耗一个T1发射器，63和captain牌子和106个major牌子，他们加起来一共需要1亿零6百万的isk。

右边第四个 “Quantity” 指的是指的是该商品的数量。比如图中第一个商品一次换一个。这个常常在换弹药的时候会用到，再比如图中第二个加达里海军爆伤轻导，一次就换5000个。

右边第三个 “Buy price”指的是该商品的买价。意思就是你花了1E的和lp换了这么个玩意，能卖多少钱。在图中可得知能卖137M（1亿3千7百万）。也就是说净赚30M（3千万）。

右边第二个我也不知道干啥的从来没用过….

右边第一个“Isk/lp”指的是该商品的lp比上纯利润isk的比值。比如图中第一个商品净赚30M左右，需要2万4的isk，那么3千万减去税比上2万4的比值就是900左右，接近于他给出的898的数据。

好了这时候你已经知道你该换什么了，奔着最大的去就好了。

那么问题来了，该怎么换呢？

首先你需要去一个该势力的NPC空间站。如果拿C海军为例，那运气很好，因为jita海4这个贸易中心，就是加达里海军空间站，你可以蹲站直接买材料直接换而不怕被抓。如果是其他势力的，你需要先去jita买材料然后运到最近的空间站换物品在运回jita卖。

还是拿C海军举例，你到了空间站，看好了你想要换的商品，接下来就要去lp商店找到这个商品了。

你就能定位你要换的东西了。

这里需要多一个操作，就是查看本地市场价格与LP网是否相符合。这是lp网的一个缺点，就是数据不实时。不过不实时的不像那种几天不更新一样，就是以防万一。因为有些商品有时候的买单价格会特别高，有一些人会挂少量的高价买单，为了更快的买到货，lp网有可能把那个时候的高买价计算进去，当你去真正换的时候可能别人已经换完了。一个简单的例子：一个势力的isk/lp目前是1500.假设这里有一发导弹，买价都是1M一个，突然有人挂了一个2M一个的单子，挂了10个。lp网提取数据，那原本isk/lp的1000的比值瞬间翻倍成2000.这时候你看到了非常高兴，屁颠屁颠去出货，换完东西发现已经有人抢到你前面把货出了，价格又变成了1M一个。你就非常尴尬，你的lp变成了比值1000的。如果你拿这批lp换其他货就是1500的比值，算下来你血亏。所以说通过这个例子我们需要再在本地核实一下价格。

具体操作是点击商品右上角的小“i”，这个按钮等同于右键该商品然后查看信息（英语是show info）。

然后你要做的是去核实1. 买价是否与lp网相同或者只是相差微量的价格 2. 买单的个数。

一步一步来，我们先看1，看市场详情

可以看到几乎没有偏差，意思就是lp网所算的数据是有效的，你在这个价格出货就能活的比值为898的isk。

然后进行第二步，查看买单数量。从上两图可以看出：137M的买单有四个，136M的有3个，134M的有6个，等等。那我们的数据是按照137M算的，如果你买了20个，那前10个你还能换到比值为差不多898的isk，但是你后十个，他的买价会降到120M左右，就不值898了，而是更低，所以你需要看好货物然后买相对应数量的货。

如果是类似这种情况就很简单了，你看好买单的价格（比如6个发射器），然后算一下你的lp，基本正好的话直接换就完事了

那如果你有很多很多lp，你把137M的货都换了，你的lp还剩余很多该怎么办？那就看lp网的比值第二高的货物，再把步骤重复一遍，然后再算，如果还多余，那依次类推。

那现在也解决了换多少的问题了，可以正式开始换东西了。
