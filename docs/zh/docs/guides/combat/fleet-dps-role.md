# 舰队火力位怎么打（火力狗）

> 来源：<https://docs.qq.com/doc/DQmpCekFoT2FXRGxo>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 跟队三件事
听 FC 的目标、保持与 FC 的距离、别自己找目标。新人被抓多半是因为第三条。
:::

嗨，大家好，我是FRT的kaguya，你也可以叫我辉夜，本人玩了几年EVE，从低安海盗到00会战也算是完整体验过了，这次写这篇教程主要是有感于各位新人在跟随舰队时做出的种种错误操作，不仅让带队的FC血压飙升，更是让新人自己遭受损失，我希望能用这一篇教程让新人们理解跟队的基本注意事项，也希望能拯救各位FC的血压。

**1.**什么舰队？在哪出发？要啥船？

首先，我相信各位应该都加入了自己所在联盟的集结群/通知群

（什么？你没加？快去找你的新手教官！）

![image1](/images/fleet-dps-role/image1.webp)

我们用FRT的这条集结消息为例，这是一个很标准的集结通知，里边包含了以下重要信息

1.缪宁建制（什么船）

2.H-5出发（在哪里）

3.XXX的舰队（谁的舰队）

现在我们可以确认，这是一个使用缪宁建制的，H-5出发的舰队，现在，你打开了游戏，进入了对应的语音频道，我们准备开始下一步的教程

**2.**怎么进舰队啊？配置是啥啊？啥是走位啊？怎么走位啊？跟谁走位啊？

现在，假如你收到了这样一条集结通知：

缪宁建制 XXX出发 kaguya sumeragi的舰队

你正好挂完了缪宁的技能，打算尝试一下舰队作战

摆在你面前的第一道问题是：怎么进舰队。

首先，如果你一直以默认设置进行游戏，那么你的舰队功能会在这里

![image2](/images/fleet-dps-role/image2.webp)

![当然，我建议你右键-添加快捷键，这样可以直接将功能添加到侧边栏，省去了每次点开菜单的麻烦](/images/fleet-dps-role/image3.webp)

_当然，我建议你右键-添加快捷键，这样可以直接将功能添加到侧边栏，省去了每次点开菜单的麻烦_

![image4](/images/fleet-dps-role/image4.webp)

现在，你进入了功能，摆在你面前的是这样一个列表

![image5](/images/fleet-dps-role/image5.webp)

看到这个很长的舰队列表是不是慌了，不要害怕，我们回去看通知，并不是每一个通知都会写明舰队名，但是一定会有统帅的名字，我们可以知道是kaguya

的舰队，那么我们在列表中寻找

![image6](/images/fleet-dps-role/image6.webp)

你很顺利的找到了你想加入的舰队，现在点击加入，并在弹出的窗口点击是，恭喜你，你现在成功的加入了一个舰队

当你顺利加入了舰队，你应该在第一时间查看舰队置顶信息

![image7](/images/fleet-dps-role/image7.webp)

最上方是联盟的配置频道，点击进去可以查看到当前使用建制的联盟标准配置，如果没有特殊情况那么你的建制应该符合频道内的要求

第二行是走位官，走位官是干啥的我们待会再说

第三行是当前舰队的需求顺序，你作为一个没有多少技能的新人可以无视他

第四行是语音频道

当然，每位指挥官都有自己习惯的舰队置顶信息的写法，但通常来说你都能找到当前舰队的具体配置和走位官，如果你确定舰队置顶没有以上两个信息，那么你应该通过打字或者语音询问

如果你忘记或者需要查看置顶信息，但是置顶信息已经淹没在了舰队聊天中，也不要担心，点击左上角的齿轮，使用重新加载置顶信息的功能，你可以用这个功能随时很方便的查看置顶信息

![image8](/images/fleet-dps-role/image8.webp)

接下来，我们来讲解走位官

走位官顾名思义，你在战场上交战时需要跟随着他进行移动。

首先你需要能在舰队的上百人里找到你的走位官，这时你可以使用关注列表功能

右键MOTD（置顶信息）里的走位官的黄字，在舰队一栏找到加入关注列表

![image9](/images/fleet-dps-role/image9.webp)

你可以看到你的屏幕里出现了这样一个窗口

![image10](/images/fleet-dps-role/image10.webp)

对着这个窗口里的名字点击右键，你就可以快速的接近，环绕或者跃迁到目标身边

![image11](/images/fleet-dps-role/image11.webp)

你还可以利用后边的小方块给目标添加颜色

![image12](/images/fleet-dps-role/image12.webp)

至于具体的走位方式，比如是环绕还是保持距离，多远，是需要具体情况具体分析的，如果你拿不准建议询问带队的指挥，我相信指挥很乐于在战斗开始前给你讲解而不是战斗时出现混乱

**3.**我该去哪，我该打谁，我该干啥，我掉血了快修我！**-**舰队广播

点击舰队左上角的菜单，广播设置

![image13](/images/fleet-dps-role/image13.webp)

![image14](/images/fleet-dps-role/image14.webp)

这些对应了你想要看到什么信息，同时为其标注颜色使用的相关广播设置

![你可以在我个人信息的最下面一行找到我自己使用的相关广播设置，直接点击就可以套用](/images/fleet-dps-role/image15.webp)

_你可以在我个人信息的最下面一行找到我自己使用的相关广播设置，直接点击就可以套用_

当然你也可以向老玩家们索取现成的设置或者按照自己的习惯自己设置

首先，你可以在舰队页面的历史一栏里找到广播记录

![image16](/images/fleet-dps-role/image16.webp)

这是你作为一个火力狗最常见的三种广播

![image17](/images/fleet-dps-role/image17.webp)

他们分别对应了攻击目标，跃迁到目标，朝向目标

与关注列表一样，你可以通过右键这些信息，快速进行操作

![image18](/images/fleet-dps-role/image18.webp)

![image19](/images/fleet-dps-role/image19.webp)

当你觉得广播记录太多影响到你使用时，你可以使用右上角的清除历史记录

![image20](/images/fleet-dps-role/image20.webp)

当你挨打的时候，你也需要利用广播系统向舰队里的后勤求救

CCP很贴心的在最下方为你准备了快捷广播栏

![image21](/images/fleet-dps-role/image21.webp)

这个列表有用的只有两个，需要护盾和需要装甲

![image22](/images/fleet-dps-role/image22.webp)

![image23](/images/fleet-dps-role/image23.webp)

当你不幸成为了集火目标，请根据自己是盾抗还是甲抗点击正确的按钮

请注意！！

不要在短时间内重复点击按钮

不要在受到**AOE**伤害（比如炸弹）的情况下点击按钮

否则你可能会因为刷屏会被后勤放生或者在受到AOE伤害时后勤同时收到大量

的摇修请求，导致被集火目标遭到忽略最终死亡

总结

以上这些就是你作为一个F1火力狗需要掌握的舰队知识

请务必注意

这些都是通用的基础知识，在你跟队的过程中请听清舰队指挥官的语音指令，以指挥官的指令为优先，希望各位飞行员们能找到属于自己的一片天地。
