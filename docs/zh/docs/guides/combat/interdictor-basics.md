# 拦截舰入门：泡泡与封路

:::tip 拦截 ≠ 截击
**拦截舰**（Interdictor）负责放拦截泡封路；**截击舰**（Interceptor）负责高速抓人。本文讲的是前者。
:::

- _职业教学-拦截_

_Nuwa Foundation公司 Man diaosi（蛮屌丝）_

_每一个开拦截的驾驶员，最重要的不是你的技术，而是你要知道拦截驾驶员的战场定位。_

*请牢记这几点： *

- *你是小船， 你要够猥琐，你要让自己活得尽量久，释放出尽量多的有效拦截泡，你可以死，但是你要死的有价值。 *

- *拦截泡里，除了T3的拦截淫灭者和截击，其他任何船都无法跃迁和跳跃离开。 *

- _长期的、经常的在每个星系、每个星门、每个空间站做好各类战术点，这是一项必修课，是一种素养。_

- *如果你死了，你要做的就是再拿一条拦截出来继续战斗！所以在平时，你就要在必要的补给点（经常发生战斗的星系）做好补给并配好船。 *

- *舰队里，你的一般身份是指挥官的参谋，一个良好的拦截舰驾驶员，往往也可以担任舰队指挥官，你可以对战场形势进行预判，先于指挥官命令前进行一系列的动作。但是，你所做的一切动作，将要对舰队负责，要时刻与指挥官沟通，交流，在不确定的时候向指挥官确认。 *

- _KM和你没有任何关系！_

*配船方面大致是两种 *

- *跟队： 真正重要的只有大量的有效防御（HP）和一个拦截泡发射器，以及2500+的速度。 你的船插应该只有两种选择 A：跃迁速度插，B：盾抗插 *

- _扫描抓人： 扫描探针发射器需要大量CPU，所以往往低槽会装满CPU，高槽一个战斗探针发射器和拦截泡发射器，剩余的装备曹只有一个意义，速度和HP。_

_场景应对_

- *大型会战 *

*一般这种情况下，拦截的任务是最轻松的，双方贴门对轰。 *

_你所要做的就是在星门（战场）的几百KM左右战术点隐身蹲。在隐身的时候向星门加速；一旦星门没有了拦截弹而你的指挥需要哪里出现拦截泡的时候，就解除隐身起跳，打泡泡后过门，在确定你的船隐身CD刷新后，反贴门或在星门附近隐身，无法隐身情况下起跳脱离；_

_但是，有些时候你也要观察战场形势，一旦发现己方处于劣势，指挥官随时有可能带队跳走的时候，你就不能傻乎乎的继续去补拦截弹，_

_这时候你的存在价值将变更为：阻止敌人跃迁追上我方撤离人员，做到这一点很不容易，需要一个拦截驾驶员的长期经验和与指挥官的配合默契。_

- _小队战_

_一般小队战的接站距离大概是30-70KM，基本以远战为主。这个时候，是拦截爆船风险是最大的时候，因为这些船只普遍会以巡洋、重突、战巡、T3为主， 这些舰船对于拦截舰可是天敌；_

_这类战斗，一般过程比较短，但是风险大。极其需要个人的操作技巧；一般情况下，你会站在远离战场的远点，隐身观察情况。_

*记住你的任务是： ***_1.队伍撤离时断后 **** 在我方通过一个星门撤离后，就起跳星门，放拦截弹出来，拦截敌方追击不对，然后自行找机会归队。_

**_2.对方妄图撤离时 **** 跳到敌方最近能跳的点，然后超载你的推子，冲上去释放尽量多的泡泡（这种情况下，一般你只能释放两个泡泡就会被击杀）如能脱离，向敌方舰队朝向方向跃迁，并且落地打泡泡。_

_**3.在星门上与敌方遭遇（己方舰队在一跳位距离内）**_* 情况一： 如果，对面开火打你，那么好，打个泡泡后就顺势过门，过门后再打个泡泡隐身观察，并且通知舰队，敌方已经开火，告知位置。 **情况二： 如果，对面没有开火，而是过门，你要做的就是跟他们一起过门， 然后过门后隐身不动15秒，观察对面动向。（往往有很多驾驶员，不等这15秒，就开始反贴门，打拦截弹。这是很不明智的，因为过门后有30秒的时间，你是无法再次过门的。这个时候往往就是拦截造成损失的最大因素）如果对方开始现形，并且朝一个方向加速 那么你要观察他们是往哪个方向加速。做出预判。 **这个时候有3种选择： **1，你找一个与他们舰队3点一线的天体，开始超载微曲加速，靠近他们 10KM内的时候打出拦截弹（一般你会阵亡）， 然后——隐身——或者——你这个时候安全的脱离你的拦截弹范围后，朝那个天体跃迁落地打泡泡。**2，敌方大部分起跳，小部分能在拦截范围内的，准备开微驱留下他们的掉队的。 **3，先于敌对起跳至预判方向的70KM打出拦截弹。 然后拉出距离观察。 具体如何选择，那就看当时的战场情况，以及和指挥官充分的沟通。*_要记住，****拦截是战术舰船****， 我们的价值是为了实现指挥官的战术目标，先留住比我们更贵的东西，然后再尽可能的活下去。_
