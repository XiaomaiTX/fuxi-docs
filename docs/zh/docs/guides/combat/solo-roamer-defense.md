# 面对散人收割，新人怎么打

最近入住了25N虫洞，每天过00口打一波快餐小队，逐渐也发现了00的一些问题。

希望这个帖子能对在00的新人们有所帮助，在出门F1之前能做出正确的选择，避免被杀猪

首先，来**00**的散人队按照船体吨位可以分为两种：

一种是以海盗护卫**/T3D/**轻突为主体的小船队，伤害高速度快，讲究一个打完就走，一般以吃肉为目标；

一种是有高中低位搭配，以巡洋**/**战巡级别船体为核心的高速风筝队，通过分工和走位能够进行一些高烈度的对抗。

面对这些小队，不得不承认的是，大多数00联盟/公司都存在人员技能和战斗素质上的差距，经常会被少量人打出一个较高的战损比。

这个帖子我会试着指出一些这类小队的弱点，以及新人反收割应该用什么样的船体对这些小队见招拆招。

面对一沾即走的高速小船队，应该如何应对？

高速的小船队，以上个版本的风筝审判为代表，一般由20km200dps，3000速以上的护卫船体构成主体，通过速度，信号，距离规避伤害，船体本身非常脆弱（大多数）；

面对这样的小队，最有效的办法就是

远距离的轻导**/**磁轨炮和轻快导

![在面对射程远/转速高的武器时，这样的小队很难有效去规避伤害](/images/solo-roamer-defense/image2.webp)

_在面对射程远/转速高的武器时，这样的小队很难有效去规避伤害_

1.为什么要上导弹计算机：我见过无数个因为技能不够导弹射程捉鸡被溜死的新人；

2.有效会不会不够：打小船队出这个船在远处F1就行，新人让队友扛非常合理。

渡鸦可以说是一个低配版的寒鸦，长距离的轻导船可以说是所有的小船队伍最痛恨的船体，无与伦比的射程加上有一丝肉痛的dph，说实话，我开小船我也烦。

操作要点：作为新人，请谨慎的拉开你与对手的距离，简单来说就是让你队友冲你前面，你不要挨打

![image3](/images/solo-roamer-defense/image3.webp)

1.为什么上导弹计算机：理由同上

2.有效会不会不够：打护卫，吨位碾压，最肉的护卫也没你肉

3.伤害会不会有点低：没有办法，已经两个武提了，想要高伤害只能上T2架子，而且这个伤害射小船也已经足够了

小船队最讨厌的船的榜首没有之一，应该就是狞獾了，轻快dps加上吨位碾压，再加上低廉的成本，怎么打怎么恶心。

不过鉴于我自己是有过溜死低技能短手狞獾/毒蜥的经历的，所以我觉得导弹计算机在这里是非常关键的一个装备，当然，也可以改成一个导弹计算机，增加一个盾扩来提高有效，这个请根据个人的实际情况调整装备。由于价格和技能的综合考虑，我上的是Y3的架子，所以伤害很低，如果是T2架子的话，双武提是有300左右的dps的

![image4](/images/solo-roamer-defense/image4.webp)

毛鲁斯：很多人提到毛鲁斯的第一印象都觉得是混子，要我说这个船真是小队里最恶心的滚刀肉牛皮糖，和他的升级版克勒斯一样，看到必杀，不杀难解我心头恨。

为什么毛鲁斯对于小船队是毁灭性的？

面对一个舰船的配置，大多数人会去看速度，看有效，看伤害，然后都忽视了锁定距离。

其实如果有观察过的话，就会发现大多数海盗护卫和轻突锁定距离只有40-60km，意思就是两个帽子压下去他就是一个残疾人了，一个只能锁10km的加姆能风筝谁？

同样的，这个思路也可以打更大吨位一些的收割队，但我不太推荐由新人来操作。如我上面所说，帽子船体在有经验的pvp玩家面前是不下于一个大号的嘲讽的，面对护卫队伍尚且能用帽子保证自身的安全，面对巡洋级别，可能一条巡洋就得用光三个帽子，被集火的时候新人很容易操作出现失误最后送掉，所以要谨慎选择。

PS：说句题外话，昨天我去德克廉打了一波，维新出了一波小胖子来反收割，但是面对加姆，小胖子是真的有点无力，无人机追不上，本体走不掉，只能一个一个被排队枪毙。考虑到00团选择小胖子是因为G船和无人机技能和生产工具不冲突，所以我在这里推荐一下毛鲁斯。只需要挂少量（大概3天左右）的炮扰技能，在团队里会起到比小胖子更恶心的究极讨人嫌的作用。

上面大致说了一下怎么去应对小船队，那么面对大一号的巡洋/战巡精装小队，新人如何把自己的作用发挥到最大呢？

我见过很多热衷于反收割的新人，可惜没有用对方法，导致自己变成了kb上的背景板。很简单的例子，就是在面对一些精装队伍的时候，新人会开出自己的狂怒/毒蜥/小米来反收割，最后这些手短速度慢，又或者伤害无法打全的船体就成了自己队伍里的累赘，徒给对面枪毙。

以前有人问反收割用什么船，我老是开玩笑说超光海灾，其实这也代表了一个反收割的思路，即输出距离远的较强火力，来抵消掉精装小队的距离扛玩法，比较有代表性的船体就是各种重甲战列和720暴风/250猛鲑/重集束先驱这样的炮台型船体。

但是你要让新人跑去开这些船体就会有很大的问题，一个是这些船体很少是联盟建制（即使是建制，也很少开出去），一个是这样的大吨位船体本身就比较吃技能，所以对新人来说这样的船体是有点难受的，想开又开不成。我呢，就推荐两个价格低廉，技能要求也较低的船体，给新人做个参考

![image5](/images/solo-roamer-defense/image5.webp)

惩罚者punisher，A族的T1护卫，船体本身是抗性加成，还有很富足的低槽，所以很容易配出一个补点的肉盾。

这个船体面对高速护卫的话可能很难受，因为速度太慢了，被溜着打的可能性远大于扑死对面一条高价值船的可能性。

但是面对一个立体的巡洋队伍，这条船就有那么点恶心人了。很多队伍的中位（即防空）船体会用海鱼鹰或者舰镰这样的船体，对于大多数00新人喜欢用的伐木/阿特龙/秃鹫，基本都是几轮轻快导送上天，但是碰到这条惩罚的话，可能堪堪20轮打满才能打死，也就是说，如果能吸引到一个轻快导的火力，那么你死后这个火力就陷入35秒的**期，己方的截击和高速护卫就可以有更高的战场机动能力，而如果对面轻快导是打一半来转火，就会发现一个更尴尬的事情，一个弹匣打完了，惩罚还有半甲。而短反就是补点用，FC要你去扰频谁，就超载微曲冲谁，无论最后扰频到与否，都是非常影响对面的输出节奏的

_其实这个断崖倒是没啥技术含量，00联盟人手一个的配置，我把他放出来的原因就是我想讲讲这条船应该在什么时候开出来。_

还记得在去年的时候我去斐得收割，那里一个年轻的华人团开出了他们的断崖来打我的加姆，于是我白嫖两个断崖solo。这样的玩法真的属实很亏，他们要是出两个狞獾我溜的比记者还快，可惜了。

720炮的特征就是高dph，低转速，以及同装备下相对偏低的dps。那么面对那种脆皮高速的巡洋的时候，拉在30km左右的断崖当然可以各种一发入魂，各种恶心人，而对面如果拉到50-70km的话，则换上中距离的硬钼弹（非常非常非常重要！硬钼弹/depleted uranium加转速，加射程，并且保留了可以接受的dph，是非常好用的万金油弹药），同样也可以打出不俗的效果。

但是面对吨位较低的船体/信号半径较小的装配，720炮就会出现各种擦伤各种miss，纸面的输出完全打不出来，想要让720打小船发挥作用，要么拉到90，要么需要长网，而这两点断崖都不具备。所以我给各位新人的建议就是，面对小船队千万不要开出这个船体，会非常难受且屈辱，但是面对巡洋/战巡队，这个船体的F1可以说是白板巡洋里面顶尖的体验了。

最后做一个简单的总结就是

打小船，用轻导，用轻快导，用电子战，白嫖就完事儿了

打大船，用肉猪，用720，恶心人换战损就完事儿了

新人一定要清楚自己的船体在一个舰队里的作用，什么时候该保命，什么时候该板载冲锋，都有其中的道理，可能一开始还是不知道该怎么玩，但是多复盘，多思考，我相信新人们都能脱离00傻肉这样的标签。

最后，祝大家fly dangerous。
