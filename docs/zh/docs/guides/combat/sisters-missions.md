# 姐妹会 1-2 级任务起步

> 来源：<https://docs.qq.com/doc/DQktpWkVZcW5pVXly>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 阅读顺序
本文面向刚进入黑渊、准备用姐妹会任务起步的玩家。若还不熟悉零安过门与本地频道判断，建议先看 [00 地区刷怪教程](/docs/guides/combat/nullsec-farming/)，并确认自己了解本联盟的报点规则（谁报点谁刷、离开即放弃）。
:::

大家好，我是VRGOD的0x0000001A，目前正在跟随军团攻略黑渊以及00姐妹会任务点。

姐妹会任务点，有特布特的主权依托，衔接黑渊5ZXX莫得团任务点，虎视两德，的确是一处战列要地，同时也可以拓展联盟的生产方式，非常不错。

目前莫得团的任务党已经基本稳定，但姐妹会靠近VOLTA，是个非常纷乱的地带，主要由X-7OMU和ROIR-Y 两处构成，经过几天的观察。我认为ROIR-Y的任务经常刷在7，8跳的位置，有些过路星系十分危险，并不适合作为攻略两德的前哨。

而这边白红比较多，星系多宏大，动辄上百AU，运输过门还是非常危险的。所以我写了以1、2级姐妹会安全任务起步，门槛较低，快速过渡到四级，开始燃烧任务的发展路线。

网上有很多关于四级任务的攻略，文字和视频都有。所以我把重点放在了一个新人你如果刚刚来到这里，应该注意什么，以及你如何养成好习惯，活下去。

我的思路是这样，如果你打算在这里生存，你首先应该在姐妹会任务点的覆盖范围铺船，刚开始可能会稍显艰难，但慢慢铺开，利用良好的过门习惯，尽量少损失，完成原始的积累。

我对新手在这里的生存总结如下，这是最基础的原则，如果你被抓，请先思考以下这些东西是否执行或者做好。稍后我会阐述，如何避免一些敌人对你主动的威胁

- 穿梭机交接任务，任务号永远保持白蛋，防止深空炸弹。

2. 你是否连接了“争霸黑渊王座”文件夹，并且上线。这里有非常多的深空点，秒跳点和星门观察点，我会逐渐补充直到这个文件夹变得顺手。

![image1](/images/sisters-missions/image1.webp)

3. 如果你正在用YST或者毒蜥做任务的时候，本地出现红白，你是否保持定向扫描不间断，并且在任务里做好朝向。

4. 如果你的任务空间已经进了人，请放弃这个任务，蓝加间谍会隐形蹲在你的轨道附近，直到再次定向到你，同时白名过门，你落地就会被泡。

5.你只要上线就应该在任务频道的语音待着，方便救援和被救援。

如果你足够聪明及谨慎，将上述这些当成傍身之策，那这个地方99%的危险与你无关。

下面我将介绍如果被敌人针对，你应该知道如何去处理。如果文件夹连接正确，你在黑渊看到的每一座姐妹会空间站都应该包含正面的若干出站秒跳点，和进站0米点。

![image2](/images/sisters-missions/image2.webp)

如果在我们弱势的时区，或者反收割无法有效组织的时候，我希望你可以利用游戏合理的机制和这些便利的条件，正常的生产，同时打击敌人抓傻子的信心。

秒跳点的原理：是利用船只起跳前必须加速到一定速度的机制，在出站船头正前方可以起跳的距离做PIN点，而你出NPC空间站的20秒内是无敌的，无法被锁定，你起跳的瞬间，虽然解除了无敌，但敌人的还没有锁定，你已经起跳。万一你手慢被点，那么进站重来就好。

秒跳点并不是绝对安全的，敌人可以利用你的落地，多次用作战针存点的方式，最终用隐轰或者隐形轻拦在你秒跳的点等你。所以你不应该每次都跳一个相同的点。

而最稳妥的方法应该是利用穿梭机交接任务，那样敌人的努力将会毫无作用，久而久之，他也会因为浪费时间而放弃，所以养成好习惯非常重要。

所以即使敌人有秒锁洛基，重拦堵站，也不应该成为你无法生存的理由，因为他们对这些毫无办法，只能用炸弹船去炸你的落地，但你只要每次落点不同，一会跳30，一会跳50，那炸弹船也基本拿出站的你没有办法。

如果你是一名跳货驾驶员，永远不应该从NPC空间站去接快递，而应该选择有挂靠的建筑。很多跳货驾驶员都是在NPC空间站和玩家建筑之间被泡的。你的跳货只有一种用法，就是出建筑后，诱导跳走。如果有玩家在NPC空间站挂你快递，可以选择不接，或者让他重新挂。

如果弄必须用工业交大体积的任务，比如故事线这种的。一定要熟练掌握拦截失效装置，配合出站点，一般人想抓你也是比较困难的。拦截失效装置是先启动，再起跳。先起跳，再启动是没有作用的，切记。

如果你前期船没有铺好，前期必须要冒险过门的时候，请先起跳星门的观察点（大概距离星门几百公里，有时间我会逐步完善这些星门上的PIN点），即使在NPC空间站到你目的地的星门有泡泡，利用这个方法，第一时间也不会落到泡泡里。姐妹会的星系都比较大，出站后定向能给你的信息非常少，所以我推荐你所有的生产船在必须过门的时候，都要先跳观察点再考虑是否过门，门后要有个眼睛，或者让队友帮你看一下。请记住，99%的过门损，都是不相信自己会死造成的。敌人很可能在星门放个隐形眼睛，等你落地确认安全后，剑齿虎门后打泡泡。

所以最稳健的做法是，铺船，穿梭机交接任务，有堵站出站秒跳， 跳星门观察点防止被炸，过门。你就是任务区最稳的崽了。

如果我正在做任务，本地突然进了红白。首先请不要慌，收割队过境是常事。任何一名斥候在定向看到YST或者毒蜥的时候，都会以为你在异常里，所以不要太过于害怕。

此时你应该关推子，朝向该星系的深空点，或者你自己做的深空点而不是朝向建筑，尤其是本地只有一个铁壁的时候。敌人的轻拦在没有找到你之前，会直接跳铁壁打泡泡，虽然不是100%泡的住你，但有几率在你起跳建筑之前打好泡泡，你落地就被吸进去。

所以在突然进大量红白的时候，保持冷静，先跳自己的安全点，定向确认建筑上看不到跃迁干扰探针再起跳进站。

如果在建筑上看到了跃迁干扰探针，敌人又下了作战针怎么办。请不要惊慌，打开你的位标点文件夹，在不同的观察点中，来回起跳，并且在深空中保存深空点，他们大概扫几轮就会明白你抓不了了，因为他的作战扫描是需要时间的，但你一直在跳来跳去，就是一种永远无法被扫出的状态。一般没有深仇大恨的收割队，不会在一个懂得规避的人身上浪费太多的时间，扫两次发现抓不了，就去下一个星系抓挂机的傻子了。所以完全不用害怕。

关于掠夺和战列的过门，说实话要不是HY非要推广掠夺做四级，我并不太想介绍这个。作为比较沉重的船只，在星门上被抓后是非常无助的。不像巡洋或者护卫，你还有反冲星门的机会，而战列或者掠夺过门，一旦被抓就只有背水一战了。

如果你非要战列和掠夺过门，请星门后必须前置眼睛。如果本地有白，不确实是什么船只的时候，查询他的KB，排除危险，同时起跳星门的PIN点，观察是否充分安全再过门。

如果敌人是隐形盯住你起跳，看你起跳的方向，解除隐形打泡泡，你跳星门的观察点会救你一命。而门后有危险你也不会过门，但我还是推荐铺船的做法，万无一失。

下文所有包含任务说明的攻略，都是为了让你尽快过渡到4级，1、2级的物流任务比较危险，所以我选择的是1、2级的安全任务，在你社会学，关系学达标的情况下，一天就可以达到做四级的标准。

这些任务基本囊括了所有的1、2任务，我用特里斯坦全部进行过测试，完全可以独立完成。有些可能会出现问题的点，已经在任务说明中指出，不建议做的任务，我会标记在任务的名称上，并非这些任务非常困难，而是你需要运送大于穿梭机承载量的任务物品过门，如果你的拦截失效装置运用的非常熟练，那你完全可以用工业舰交这些任务，毫无问题。

我选用的是非常便宜的小胖子配置来做姐妹会1、2级任务。

![image3](/images/sisters-missions/image3.webp)

对于新手来说，大概需要几个小时就可以完全上船，你只需要准备无人机概论5和少许的工程学技能即可，无人机伤害增效装置，换成衍生型的也完全不影响，小型货柜是为了使该船的容载量到170方，可以拾取1、2级最大的掉落150方的任务物品。如果你不做交物品的任务，换成3伤害增效也没问题。

关于四级任务

我推荐

![image4](/images/sisters-missions/image4.webp)

这套纯PVP配置可以通刷4级，而且可以马上参与到战斗中，只是比全伤害的YST效率略低，不过我一直用这套装备打四级，挂机就好。缺点是需要一些技能，优点是便宜泛用。YST做四级任务是完全没有压力的，如果你不想参与战斗，只想闷头刷钱的话，自己用普通刷怪YST就好。

![image5](/images/sisters-missions/image5.webp)

毒蜥我推荐这样，因为我之前经常挂机损，所以高一点的有效可以完全应对四级任务，如果遇到有网子的任务，只要及时清理也不会有什么压力。如果你的资源不够，用紧凑型盾扩，轻快导清小怪，也是可以的。毒蜥的优点是成型快，缺点是更低的效率和更贵的投入。

当然你也可以选择修量装的毒蜥，但你需要较高的工程学技能以维持永动，以及较低的容错率，个别任务会比较难受。
