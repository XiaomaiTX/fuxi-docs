_认识我的人肯定知道我对kikimora的喜欢，以至于我起军团名字的时候都用了kiki（虽然只是一个原因）。所以呢今天就专门开一贴谈谈kikimora，希望大家喜欢也希望大家可以互相交流一下这条船的心得。_

我会从以下几个方面来分享一下我对kikimora的理解：

（1） Kikimora船体分析

（2） Solo kiki

（3） 小队战 kiki

**Kiki**船体

三神裔（阿三）船的船体技能加成都是非常猛的。加入洞团的玩家尤其清楚，刷怪也好打架也好，大多数要求船体IV以上炮台T2专业研究IV以上。而对于kiki而言基本上想玩最好船体V、小炮台专业研究IV。毕竟船体的两个加成都非常有用，每级25%的伤害加成20%的射程加成。

![伤害加成决定了kiki的起手（基础伤害）以及最终的满伤，而距离加成对于阿三非常重要，不单单是因为火力投射还包括了焊枪的持续叠加是否可以叠加上。因此想玩Kikimora的玩家们务必船体学到V。](/images/kikimora-pvp/image2.webp)

_伤害加成决定了kiki的起手（基础伤害）以及最终的满伤，而距离加成对于阿三非常重要，不单单是因为火力投射还包括了焊枪的持续叠加是否可以叠加上。因此想玩Kikimora的玩家们务必船体学到V。_

**Kikimora**的优势：

（1） 基础属性

作为一个伪T1驱逐，kikimora的属性非常逆天。

第一点：比起普通的驱逐，船体速度和灵活优势是显而易见的，日常我们看到的kikimora mwd配置能有平均2700的速度，高蛇神装能有4000+到5000非常优秀。

第二点：火力和火力投射，occult T2近距离300+起手，甚至可以最多到1000的究极伤害，三神裔小炮的转速也非常逆天，而T1 M弹可以打出40+km的持续巡洋级别输出。

第三点：优秀的信号半径，除去防御模式的忏悔和不上盾扩的长尾鲛，kikimora应该是信号半径最小的驱逐船型。这也使得kikimora的ab玩法很受欢迎。

（2） 多样化配置功能

Kikimora的特殊加成和船体槽位使得这条驱逐非常多样。有摇修甲抗kiki，有双推kiki，有单浪毁电结构抗kiki，有盾抗ab等等

（3） 广泛的作战战场

无论是低安、00、虫洞，Kikimora可能是适应性最强的船体，在哪个区域都有用武之地。

低安小杆子的solo无双，参考某瓜~

虫洞的沃尔夫拉叶天象里2000+dps的kikimora。

00各种大神素材的主角。

（4） 帅气的外表

呵~这船太帅了

反过来说说**kikimora**的劣势：

（1） 驱逐船体的通病

驱逐船体有个很大的通病那就是：抓正确配置的PVE船很累很累！现在这个版本里，kikimora单收对象几乎只有挂机的不带轻快毒蜥和不带稳定的YST。运气不好还容易被一些刷怪船秒。而唯一解决这一问题的办法似乎只有加钱好蛋，但是似乎很少有人愿意。

（2） 一生之敌：轻快

这个不用说了，你爹永远是你爹，除非黑科技，基本配置的Kikimora遇到势力轻快跑不掉该死还得死。

（3） 船体+装备价格高

Kiki的配置最低也要200m左右，这个价格可以买一个势力巡洋了，kiki开不好的时候不如玩其他有用。

（4） 克星电子战

作为三神裔光荣的一员，阿三怕的kikimora自然也怕。ECM断伤，炮扰压制，帽子压感应、距离，这些都是kiki最怕的。看到哨兵时，kikimora玩家可能都得更加细节去处理。

接下来来谈一下Kikimora的玩法

![先说**solo kikimora**！](/images/kikimora-pvp/image3.webp)

_先说**solo kikimora**！_

在solo方面的kikimora真的五花八门，各式各样。我这里呢也就给大家一个玩法雏形和基本配置，具体玩法仁者见仁智者见智！

（1） 单盾扩mwd 高速

这绝对是最火最火最火的配置，没有之一。整个EVE里80%以上的solo和小队kikimora都是这个配置，船插不带换的那种。（偶尔有些玩家喜欢损控不要，带索敌或者再加个武提）

这个也是我经常开的配置之一，拥有优秀的风筝速度，两个武提又能保证kikimora的高火力，尽管船体偏向甲抗，但是单盾扩也能保证在倾泻火力击毁对面前的存活。

玩法：合理运用各种弹药进行风筝或者爆发！（画黑板）

许多时候这种kiki很能秀，运用速度和中等的火力投射白嫖小船，在对方接近的时候用进程超载dps叠伤，对方拉出的时候再用优秀的速度不让对方脱离秒杀。因为kiki的火力和转速，在solo时可以优先拉扯嫖伤，在拉扯阵型不错的时候秒杀。

如果面对单个你觉得无压力的小船或者巡洋，直接爆发或者环绕20+B弹磨死也ok~

总体评价：可进可退！

![（2） 注甲注电mwd](/images/kikimora-pvp/image4.webp)

_（2） 注甲注电mwd_

这个只是个大概配置，为了写帖子大概配了下，没仔细精华。可能低槽损控换个全抗，中槽注电换个计算机也有，船插可能也有变，但思路是一样的。

这个配置的优点在于比起第一个信号半径小四分之一，同时更能抗伤更能抗毁电，但缺点也非常明显，火力的下降。个人不是很中意这款，但是大家有兴趣可以再精华一下玩。

玩法和第一种类似~

![（3）10ab甲抗kikimora](/images/kikimora-pvp/image5.webp)

_（3）10ab甲抗kikimora_

这个真的就是大林的大爱，也是我很早就开始玩的一个配置，在kikimora没被削之前也完成了很多精彩击杀。(其实一开始10ab我是拒绝的，感谢青衣)

首先说下这配置的最大优势，还记得我一开始提的信号半径和灵活性嘛！kikimora某种程度上来说是和忏悔比肩的跨ab驱逐。尽管砍了pg后，这船配出来看起来很牵强但还是可以玩，对于巡洋级别很多都非常好打。之前我在特纳solo一个单网重攻loki非常舒服（可惜后来人家来了个长剑=。=）。

玩法：10ab手操规避伤害2000速持续粘人

这个kiki玩法也决定了他的优缺点，首先他打巡洋级别可能可以跨级别击杀，但是同样打高爆发小船（尤其kiki内战）或是遇到护卫风筝、高速巡洋、堵门时基本就GG了。

（3） 剩下配置推荐

剩下的一些都是精细些的配置，无非都是上面一些的变体。

最为推荐的是某瓜的结构抗kiki，天天低安杀穿。

还有些抗电子战的中槽变动，小船狗斗的高槽毁电我就不一一罗列了，大家可以去kb网上查一下~

最后说下小队**kikimora**怎么玩

在说小队Kiki呢，我想把小队Kikimora分成两个部分，一个是散打的kiki，一个是kiki为核心的kiki小队！

首先说散打的kiki

这简单来说就是kiki在一个散打队伍中怎么玩？

（1） 小规模的持续火力点

很多时候的收割队出去时候可以带kiki，因为这是一个能打出面板dps的船。

这一点我也特别解释下。很多新人喜欢开小托，hecate这种突脸船，大部分是觉得这个dps很高，但这是面板而不是真实dps，很多小队战情况，尤其逆风局，这样的打法是瞬间融化，这样的船和玩法不能给到持续火力只有一瞬间的爆发然后自己融化。而kiki在一些4-5人小队，可以作为一个火力支撑点。

配置方面：就是solo第一种的盾扩装，如果有点人船可以进一步更改抗性或者加计算机下盾扩，看喜好。

（2） 小队补点

这个我之前截击篇也说过，截击遇到很大压力的时候需要沟通交流要求队友补点，而kiki优秀的速度让他可以作为一个补点船在场上活动。

配置：依然是盾扩mwd反跳。

（3） 小队防空力量

如果今天的队伍感觉火力充足，那带的这条kiki可以作为场上的一个防空点，不跟火力点名，去清理对方小船，放空我方的截击或者中高位，也是个不错的选择。

配置的话没错还是我，mwd+盾扩/计算机。

注：kikimora在散打小队非常怕对方高dph或者轻快高爆发，这种时候可以来回进场规避伤害，走位和截击相似，不要直线拉

那以kiki为核心的小队的队伍该怎么玩呢？

嘿嘿，这边我也有点小私心，就跟大家大概说一下，不具体透露玩法了，可以给大家一个思路！

比较火的像是缩小版init原来的ab盾抗kiki，优秀的火力加上半径为主的队伍。

第二种呢是现在洞里很多的甲抗1ab 5mwd的双推kikimora，也就是waw的一个小队。

还有类似于10ab的钢板kiki，也有出现不过很少。

总的来说就是：信号半径抗+高近身火力杀穿！
