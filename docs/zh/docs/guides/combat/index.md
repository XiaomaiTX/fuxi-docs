# 战斗与舰队

本板块收集战斗与舰队行动相关的攻略，对应官方职业道路中的**执法者**与**自由战士**。

## 主要方向

- **PvE 战斗**：异常空间、死亡空间、任务与 NPC 势力交战。
- **PvP 交战**：单人遭遇战、小队伏击与反收割。
- **舰队行动**：舰队指挥（FC）体系、建制舰队、出勤（PAP）与补损（SRP）。
- **舰船配置**：常用舰船的装配思路与常用建制配置。
