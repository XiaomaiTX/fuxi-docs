新人问题汇总：

最近由于hy回归开荒5zxx的海盗四级任务，有不少新玩家已经玩了一年多只玩过5级的半老玩家不知道4级是个啥，也不懂燃烧这个概念。就此开一个帖子汇总一下常见问题并进行解答。开头说一句，无论是新人老人有问题都先翻翻论坛，我在本帖也不会写新内容，全部由论坛里的零散内容汇总而成。希望大家有空多翻翻论坛里一些带“精品”“新人必读”标签的帖子，能大大减少公司管理和新人教官的压力。

什么是海盗任务？

顾名思义，海盗任务就是海盗势力的任务。之前在低安做的C海军5级是海军任务，势力隶属于加达里合众国势力加达里海军公司。联盟起家的时候做的天蛇任务，天蛇就是6大海盗势力之一。而这次开荒的莫德团任务，剧情上来讲不算是海盗，但是既然都是4级跟刷海盗任务的方式一样，就延续了这个叫法。实际上是加达里合众国的雇佣军，应该叫做“雇佣军任务”来着…

4级任务和5级任务的区别

这是我在伏羲群最常看到的问题，没有之一。很多半新人都用5级任务的思路去刷4级，其实完全没有必要。俩任务最大的区别是4级没有毁电塔，怪的数量也少一些。所以4级是可以毒蜥用速度抗去刷的。多米也可以单刷4级。如果依然用实践跳刀200km数导弹的话，未免有些太累了。HY最近也在搞多米的活动，有兴趣的可以跟进一下。

什么是燃烧任务

这是我在伏羲群第二常见的问题，现在进行一个统一解答。燃烧任务就是4级任务的一种。4级代理人会随机给。拿5级举例子就好比是以前的越狱，现在的自由间谍。本质上来说就是5级任务，如果你刷到了他们你就知道你有得赚了。他们的名字都有一个共同点就是开头为混乱，英文是anomic。燃烧任务一共只有3大类，混乱团队(anomic team)，混团代理人(anomic agent)，混团基地(anomic base)。这三种任务之下又分为各个势力的任务。具体可以在代理人给你任务的时候看图标。不同的势力有完全不一样的任务怪，需要用不同的船不同的操作去打。

目前主流的打法有3类

- 传统轻突。优点是稳健便宜。已经用了很多年的配置，不可能出现配置不成熟失手的情况；而且轻突本来价格不贵，挂上技能后技能刷任务又能去打架，怎么想都不亏。缺点是吃技能，需要3族护卫5，最好要轻突5，同时小炮得T2，对于新人来说是不少的技能压力。具体攻略看链接：https://forums.winterco.org/t/topic/3468

- 阿三轻突。阿三轻突是一艘船通过换装可以达到全刷的效果。优点是不用买10艘船了，买一艘打完换装就行。缺点是第一吃技能，第二配置不便宜，第三在小对战和会战阿三轻突的存在感远不如其他轻突比如美洲虎，enyo。

- 3开夜魔侠。这种比较少见，都是大佬在干的事。3开夜魔侠+1麒麟。思路就是3夜魔侠的dps能到1000，直接暴力杀穿，麒麟作为护卫后勤保证一个续航。是无限燃烧大佬的专属。

任务过程中的安全问题

1.任务怪带来的危险

所有的任务中，

第一危险的是反跳怪，基本上是护卫级别，被反跳，意味着你无法随时跃迁，在被怪集火，被反跳的情况下，盾撑不住是非常危险的。

第二危险的是网子怪或者网子塔，基本是护卫级别，一些任务会有网子无人机，网子怪不论是对无人机还是Gila而言，都是比较危险的，网住无人机，会很容易损无人机，网住Gila会降低速度，受到更大的伤害。

之后比较危险的是伤害从高到低的怪，对Gila来说，只要开推子拉起角速度，任务怪是基本打不中，或者打中很少的伤害，相对来说比较安全。

所以在任务攻略里，几乎每个任务都是从小往大打，这样是为了让Gila和无人机更加安全，不会因为某些不知名的原因怪损。

2.抓人船带来的危险

是的，任务地区是真正意义上的高危地区，几乎每天，每隔一段时间都会有人来收割，本地会有人在任务空间，或是空间站抓任务船。

为了减少人为因素的损船，新人需要注意：

1)时刻扫针：

在没有反抗能力的情况下，如何规避抓人船，舰载扫描是最有用的预防方式，

首先在太空中按“V”键，会打开舰载扫描界面，在左上角调整舰载扫描的角度和范围，角度设置为360°，范围随时更换，一般为10AU->5AU->1AU，这样的顺序进行调整。

那么扫到什么算是危险？

首先如果本地进入红白，或红白常驻，你就要按“V”打开你的舰载扫描，调整范围为10AU开始扫描，扫描频率越快越好，如果在10AU扫到战斗针（一般是Sisters Combat Scanner Probe（姐妹会战斗探针），偶尔会有Combat Scanner Probe I（战斗探针 I）），你就应该准备好跑路了，之后马上调整范围为5AU，如果在5AU扫到战斗针，那么你就应该跳到安全点（深空点或者是铁壁，最好不要去空间站，因为可能会有拦截泡堵站），等待本地红白消失后再去完成任务。

注意：是扫描到战斗探针（Combat Scanner Probe I 或者Sisters Combat Scanner Probe）而不是核心探针（Core Scanner Probe I或者Sisters Core Scanner Probe），扫描舰船只有战斗针可以做到，请务必注意。

2)加入防御舰队

加入防御舰队不是仅仅是加入，如果你因为一些原因被抓住了，加入防御舰队可以让反收割成员更快地来救你，而不是被抓了，眼睁睁看着你的船被打死。

**那么如何进行救援提醒？**

首先，如果你使用舰载扫描扫到了战斗针，你可以选择跳走，或者选择反杀（新人不建议），

反杀的步骤是，先在Fleet频道，拖你的星系，并写===，在mumble上大喊，举个例子，你在5zxx美滋滋地做着任务扫着针，突然发现10AU有4根战斗针，马上去mumble频道大喊，我在5zxx扫到战斗针了，并在Fleet频道打：5zxx ===，让队友们做好准备，之后持续进行舰载扫描，同时拉远落地点80-100KM，舰载扫描扫到其他船，比如Loki（洛基）之类的，马上在mumble频道汇报对方船型，并在舰队打XXX，让舰队成员跳你，之后，注意不要被打死，同时配合队友进行反杀。

3)如何做深空点和安全进站点

深空点，在你跃迁的过程中，使用Ctrl+B，即可显示保存位标页面，点击Submit（确认），即可保存深空点，

为何叫深空点？

因为在跃迁途中所保存的位标，周围没有任何参照物，不能根据参照物来判断你的跃迁方向，所以称之为深空点。

在有代理人的空间站，直接跃迁到空间站有时是非常危险的，因为你直接跃迁到空间站，是处在进站边缘，你很有可能需要爬几千米才会进站，如果有敌对存在，完全可以趁你爬这几千米的时间将你打死。

你需要自己做一些观测点和安全进站点，

以5ZXX空间站为例，你可以在空间站上方或者下方做一个300KM、500KM的安全观察点，以及一出站马上按Ctrl+B保存出站口点，

在本地有情况的时候，你可以先跳500KM观察点，如果没有看到情况，跳安全出站口点后进站，安全出站口点是一定能够让你马上进站，而不会爬几千米。

做任务声望问题

如何接取四级任务？

需要满足以下条件：

代理人，公司以及势力声望，任一方声望为5.0以上，并且其他两方的声望不在-2.0以下。

举个例子说明：

如果你的天蛇4级任务代理人（Tuvan Orth爸爸）声望为5.2，天蛇公司声望为0.2，天蛇势力声望为0.02，那么你就可以做天蛇四级了，

相反：

如果你的天蛇势力声望为9.99，天蛇公司声望为9.99，但Tuvan Orth爸爸的声望为-3.0，那么你依旧无法做天蛇四级任务，除非Tuvan Orth爸爸对你的声望在-2.0以上。

那么如何提高相应的声望？

势力声望可以通过刷一级任务出故事线，完成故事线提高声望，公司声望可以通过完成一级任务以及故事线来提高声望，代理人只有通过完成相应的代理人任务才可以提高声望，

如果你的势力和公司声望很低，那么你可以通过做一级任务及故事线来提高声望，

如果你的代理人声望很低，很抱歉，你只能求组任务大佬来带你做相应的代理人任务，通过组队分享任务来提高你的代理人声望。

MTU改名字做点（保存位标）

做任务，势必会遇到一些LOOT非常值钱的任务，放MTU是非常常见的，但是如何让你不丢MTU，以及忘记MTU以后如何收回，新人一定要学会，

MTU从船舱拖到太空即可放置，你的第一任务，是把没有改名字的MTU改名字，鼠标右键太空中的MTU，选择Set Name（命名），之后第二要做的事情是，保存当前MTU的位标，鼠标右键太空中的MTU，选择Save Location…（保存位置…），在之后的页面里的Folder（文件夹）选择Personal Locations（个人位置），点Submit（确认），即可保存MTU的位置。

过门不要自动导航

是的，不要自动导航，这里不是国服，没有零跳也不允许你们使用零跳脚本，不要图省事开启自动导航，在0.0地区尤其是OSY-UD附近使用自动导航无异于送死，

为什么呢？

因为自动导航的原理是，先跳目标地点（包括空间站和星门）15KM，之后爬15KM到目标地点完成目标，我想这么说大家都可以明白，你跳了星门15KM，然后去爬星门，在有敌对的情况下，尤其是任务船，别说15KM了，你5KM都爬不到就被打死了。所以，以后一定不要使用自动导航！

如何防止爆船

1.防止怪损

刷怪或者做任务的正确的操作方法是：在通过加速轨道或跃迁进入任务空间后，立刻扔出Mobile Tractor Unit，然后点开加力以最快的速度远离你的MTU（因为这是你的落地点）。你可以直接朝怪的方向冲过去，然后等怪都开始打你后再拉开，或者是向头顶上跳刀走，接着放出与怪同种族的无人机进行攻击。

在点开Tactical Overlay后你可以在屏幕上看到自己的环绕圈，你必须保证自己的环绕圈不会经过任何会让你停下来的障碍物，或是以过近的距离掠过任意一个怪堆：

![image3](/images/nullsec-mission-faq/image3.webp)

在杀怪时，因为只有小怪才有反跳和网子，同时也只有小怪才会对你的无人机产生威胁，所以正确的杀怪顺序一般都是：反跳小怪＞网子小怪＞普通小怪＞巡洋怪＞战列怪。

有些空间内有石头或者建筑，要防止被卡住。

只要能够记住并实行以上三点，你便能保证自己不会怪损，然后接下来我将教你如何避免被抓。

2.防止被玩家爆

在0.0被抓主要集中在三个地方：第一是星门，第二是空间站，第三是任务空间。

第一，做任务免不了要频繁地过门，所以如果你想避免自己在过门后被抓，最好的办法就是在所有任务常去的星系的堡垒里放一艘任务毒蜥，然后当有任务需要你去这个星系时，只开小护卫在各个星系间往返即可。

但也并不是说开小护卫就一定安全，在本地有红名和白名时你最好能先跳这个星门边上的堡垒看一下星门的状况，然后再跳星门。

接着，如果你在过门后发现自己被一群人堵了的时候也别紧张，因为第一你开的只是小护卫死了也没多大损失，第二还是因为你开的只是小护卫所以你可以立刻超载微曲反冲星门，一般很难被抓住。

刷异常的话，刷怪船最好不要过门。

第二，在空间站被抓分为出站被抓和进站被抓两种，但无论是出站被抓还是进站被抓，只要你能提前做好必要的战术点，就能杜绝这些情况的发生。杜绝出站被抓的方法是出站后保持航向不变一直飞，并在离空间站300KM，500KM和800KM时按Ctrl+B保存三个出站秒跳点，之后在出站后就直接先跳这三个战术点中的任意一个，然后再去你想去的地方。杜绝进站被抓也一样，你只需任意选一个出站秒跳点，跳过去看一下站外的情况，然后再跳空间站停靠

第三，为了防止在任务空间里被抓，你还必须学会在做任务的同时扫探针。扫探针的方法很简单，首先按Alt+D打开舰载扫描器，然后将扫描范围设成360度，距离设成5AU：

![image4](/images/nullsec-mission-faq/image4.webp)

接着按键盘V键就能扫描1次，当本地有敌对时就隔几秒按一下V，然后看扫描结果中是否有战斗针：

![image5](/images/nullsec-mission-faq/image5.webp)

在5AU内发现战斗针的意思就是疑似有人在扫你，接下来你需要将扫描距离改到1AU，而如果1AU内还是能扫到针的话，请直接撤离，或是继续做任务并同时在语音频道上喊人让他们准备吃肉。

当然我知道在做任务时还要不停地按V键是非常累人的一件事情，所以如果你怕自己一时疏忽忘了扫描的话，我的建议是在任务空间里以最大距离远离加速轨道和你的MTU飞行（100KM+）。

因为之前我所介绍的那个任务毒蜥可以锁定112KM，而无人机操控距离也达到了120KM，所以你不必担心出现离得太远就无法打怪的问题，而相反你离轨道和MTU越远，那敌人进来想抓你的欲望也就越低。

**最后还请切记：在****0.0****做任务的时候一定要上语音（****Mumble****）能说话。**
