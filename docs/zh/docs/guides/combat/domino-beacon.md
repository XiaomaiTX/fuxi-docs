# 多米刷标攻略

![多米刷标攻略 图 1](/images/domino-beacon/00-overview-01.webp)

本教程旨在给新人提供航母标刷法的介绍。文中的"多米"指**多米尼克斯级**（Dominix）。如果有文档讲得不清楚的内容（不限于细节补充、提升效率等），请在军团群内联系文档维护者，联系方式见 [黑渊社区教程](/docs/community/pure-blind-community/)。

为什么要搞这个操作呢？多米刷小航标有什么优势呢？

首先，多米成本低。5条多米合计成本1.3B，13亿左右，一条火力多米2亿左右，成本很低。收益估算一个小时能到个4亿左右。其次操作全自动，什么叫全自动？就是只要阵型摆好，除了开标关标的事情之外，其他你不需要再操作任何，哪怕一个按键都不需要，出怪他自动打，这叫全自动。

最后一点就是不用去抢炸鱼点，不用考虑本地有没有人在炸小避难。他只要有个铁臂能放小航就足够了。

## 二、开标准备工作

开标应当有自己的位标点位，建议自己做一个铁壁秒跳且总览可见距离的位标，距离铁壁2-4万km较为合适。

刷标点位示例图如下：

![多米刷标攻略 图 1](/images/domino-beacon/02-preparation-01.webp)

开标点在肉盾和火力抱团点下方10km左右，火力落地点距离抱团点10km左右。

1、肉盾和开标小航一起跳下方的开标点。火力多米分别跳火力1234点位，落地后扔出岗哨无人机！！！！！！！因为我们火力多米是带着港带着炸弹的，所以说岗哨一定要扔远一点，岗哨一定要扔远一点。

2、扔出无人机后所有多米接近抱团点开始搞基，所有火力无人机给肉盾多米挂守卫效果并打开传电和摇修，肉盾号给每条火力挂一个摇修。最终效果如下：

4、接下来就是漫长的挂机时间，除非有人抓你，否则不需要再有任何操作（PS：火力请务必保障无人机操作距离大于61km，否则打不到60km环绕的无人机会非常尴尬，建议无人机操作距离相关技能至少4以上）
