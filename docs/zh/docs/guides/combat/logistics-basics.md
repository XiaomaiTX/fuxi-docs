# 舰队后勤入门：职责与操作

:::tip 后勤不是"跟着修"
后勤的难点在**被点名**与**电容耗尽**，而不是把修量刷满。本文的站位与预判部分比配船部分更值得读两遍。
:::

后勤扫盲 + 后勤职业教学

_部分内容来自于 ** Fuxi Legion Stardust memeda（么么哒）_

_**后勤舰，作为舰队战和小队战中的支援舰种，在每一支队伍里都有着极大的作用，他们利用自己的维修装备，修复被击穿的护盾，填补破损的装甲，使舰队里的其它成员的生存得到了保障。那么怎么样才能才能变成一个合格的后勤驾驶员呢？我们就来好好梳理梳理。**_

当下舰队出门不带后勤已经越来越罕见了，这也是PVP大环境发展的结果。早年高速盾抗队(流浪队塞纳波队小马队) 还能凭借距离抗，没后勤也能混口饭吃，但目前的几种主力舰船(缪宁，毒蜥，TFI，小希等)射程都是轻松可以达到100KM，纯粹的速度抗距离抗已经没有太大发展空间，通常都需要配备一定数量后勤保证持续战斗力。

- 一个舰队后勤基数决定了他能打什么样的对手，去跟什么样队伍接战。

- 为什么要带后勤，因为没后勤对方打你1条少1条，对方有后勤你打死他3条，死了1条逐渐的战场优势会向对方倾斜。

技能方面

常规后勤舰分T1和T2，技能上来说T1后勤相对较低，只需要最低1级的巡洋船体和不多的维修装备技能即可驾驶，而T2后勤则是功能专一的T2修理船只，这些船修量高，PG充裕，抗性也更加优秀，但是需要的技能也很高，T2后勤至少需要一族的船体5，远距锁定5，信号分析5，和后勤舰操作1级才能上船，而一个能够上战场的T2后勤则需要后勤舰操作至少4，最高5，取决于你是否是传电后勤。装备方面T2后勤与T1后勤相似，但是由于功能更加专精，T2后勤的配装往往需要较高的辅助技能，例如护盾升级5。

后勤种类

上面提到，T2后勤上战场至少需要后勤4，最高5。这是取决于你开的后勤船体的，因为后勤舰操作技能直接影响了你的遥修装备耗电，A、C两族的T2后勤拥有传电加成，因此这两艘船依靠后勤之间的互相传电保持舰船电容的平衡，以此达到永动修理，因此后勤4也可以保证电量的充足。而G、M两族的后勤没有传电加成，因此需要后勤5点支撑才能在作战时达到永动修理。在遥修类型上，C、M两族加成为盾遥修，A、G两族为甲遥修。

广播设定

首先是广播设定，由于后勤的功能不同，舰队广播的设定是与火力不同的，盾遥修后勤的广播需要勾选“need shield”，C后勤需要额外勾选“need capacitor”，甲遥修后勤需要勾选“need armor”，A后勤额外勾选“need capacitor”。

走位和摇修操作

_接下来是走位和遥修的操作，一般来说在舰队出发前需要加入后勤频道和后勤语音，在后勤频道里会公示后勤走位，将这个走位加入关注列表，战斗开始以后保持走位500-1000m，然后看广播或总览锁定队友遥修。_

*在分配遥修时应当有所保留(1个修)，不要一口气把所有的修激活，因为每激活一次就意味着在这一圈遥修转完前你这个修不能遥修新的对象，在发现修量不够时将所有修挂上去并且超载，上面这些是我自己的经验。 *

传电操作

最后也是最重要的传电操作，传电后勤需要依靠传电链才能永动，因此没有传电链的话就没有修量可言了。

在出发前传电后勤驾驶员应当加入后勤频道和传电频道，传电的对象以频道成员列表为准，

如果是“上下双传”，那么你要做的就是锁上列表中你的名字的上面一个和下面一个人，分别挂一个传电，而他们也会给你回挂一个传电，传电频道里的每个人都这样做以后，传电链就形成了。

如果是“向上/下单传”，那么你要做的是锁上你的上/下面一个人，给他挂1个传电，多余的一个传电用于给广播需要电容的其它舰队成员传电。

由于在战斗中可能会出现后勤减员情况，因此建议将自己的传电对象和备用传电对象提前加入监视列表，在第一传电对象被击毁后迅速锁上第二对象传电，避免传电链的断裂。

被击毁的传电后勤要在传电频道告知自己的舰船被击毁，然后迅速退出传电频道。

热键设置

后勤驾驶员，尤其是曲剑和奥内驾驶员，都应该使用一个热键，叫做“一键解锁所有目标”。这个热键在游戏默认中是空的，需要你手动设定。设置好这个热键，你可以在多开后勤或者大规模会战中迅速解除所有之前你修起来的目标，重新锁定最新广播的目标，是新手后勤和老手后勤的关键区别之一。

- 后勤舰驾驶的思路与操作（针对C后勤讲）

- 首先是传电后勤舰的注意事项与作战准备

- 传电断掉后的处理方式 第一种：被ECM只能上针对性的抗ECM装备 第二种 ：被打爆就退出传电频道，最好能打出T1后勤-1 或 T2后勤-1 便于让舰队指挥判断形势。通常来说后勤在大舰时不占用语音频道尽量在传电频道打字交流，让舰队成员获取更多有效信息

- 3，关注列表最高15个关注上线。舰队开拔前将传电链目标加入关注列表、舰队长、火力导标、后勤导标加关注（如果有可能多加几个传电目标以提前预防断电）

- 4，无人机也可以带几个武士，飞的快，最好是单个单个的放出来去签名，也带一些ECM无人机，被抓后，可以E中对方有几率逃生

二、实战操作

1，如果盾修，已经明显发现修不起来，尝试超载修

2，如果对方舰队能斩首掉我方舰队指挥官，建议给我方指挥/火力走位官常挂一个遥修

3，被打直接超载你的抗性，我比较懒是直接超载整个防御槽的，比方说盾抗防御在中槽，我直接超载中槽点遥修。

4，小队战里可以刷屏点遥修，大舰队里瞎几把刷遥修的火力特种都是实战经验不够（都是SB）。

5，一定要跟好你的后勤走位官，并且在开打的时候保持精神集中~只需要你保持这么一会精神集中就能干死你的对面

6，控电，没电了停止激活你的抗性装备，预先超载抗性，看对方舰队如果对你大量闪黄，激活你的抗性装备。一般来说只有曲剑 镰刀 需要控电。

7，如果遇到战列级别或者侦察舰的毁电，毁电基本就是后勤的天敌，emmmm那努力超载你的抗性 听天由命吧…
