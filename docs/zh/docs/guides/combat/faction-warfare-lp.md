# 势力战争开局与 LP 变现

> 来源：<https://docs.qq.com/doc/DQlBxWXViZHRVd0Nv>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::warning 势力战争在 2022 年重做过，本文数据时点偏早
Uprising 版本（2022）重构了势力战争：星系分为**前线 / 指挥 / 后方**三档，LP 收益按**与敌方空间的接近程度**缩放，并引入优势值（Advantage）、胜利点与战场（Battlefield）机制。

因此文中「做几级任务换月卡」的换算只能作量级参考，实际 LP 效率请看游戏内势力战争面板的当期星系分级。
:::

A号白嫖月卡小方法

势力战争就是加达里和艾玛与盖伦特和米玛塔尔之间的战争。玩家可以加入其中一个国家的卫队参与战争。加达里和艾玛是盟友，盖伦特和米玛塔尔也是盟友。

这里建议参加加达里的卫队，因为如果参加米玛塔尔和盖伦特的卫队，进入艾玛和加达里的高安星系就会被海军打，也就是进入吉他很危险，出货难。加达里的最近兑换物品的地方离吉他只有3跳。

这里以加达里卫队为例，加入卫队后，你需要准备一艘小护卫，找你能开的最便宜的就可以了（联合矿业的冲锋者，venture级不可以）。可以完全不装任何装备。准备好船我们就可以出发去生产了。

只需要保证你的dps在300左右即可。还是怎么便宜怎么来。绕完一个杆子时，右下角会出现提示，也可以在钱包中查询lp的数量。（注：由于四大帝国的盟友性质，如果你加入加达里卫队，米玛塔尔和盖伦特的杆子都算为敌方杆子，你也可以绕米玛塔尔的杆子，也会获得加达里卫队的lp，同样的你绕艾玛帝国的杆子是会算为己方杆子，也是获得加达里卫队的lp，可以开一个小号加入a卫队看一看a与m势力战争的情况，从而考虑绕艾玛的高占领的杆子，放弃加达里的低占领杆子）

将lp兑换为isk的步骤，首先前往努尔瓦凯肯的空间站，在空间站中选择lp商店，将lp兑换为物品，再将兑换的物品拉到吉他海4出售即可。

势力战争并不安逸，时常会有人来抓你，需要时刻做好爆船的准备，要保证不要开开不起的船，不要一次爆船就倾家荡产。

有前人为例，最快1周即可嫖出第一张月卡。
