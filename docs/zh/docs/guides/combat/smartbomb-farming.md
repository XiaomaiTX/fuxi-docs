# 立体炸弹刷怪（炸鱼）入门到精通

众所周知，炸鱼是一种高效的PVE生产方式，通过使用立体炸弹来清理大量刷新在一起的NPC，来达到快速获得远征或者ISK的方式。

本帖将以自己来到EVE的炸鱼经历，从0开始讲述炸鱼相关的经验和知识，希望能帮得到大家，祝各位看的开心ᕕ( ᐛ )ᕗ。

![image1](/images/smartbomb-farming/image1.webp)

PS：炸鱼需要双开甚至多开，单开炸鱼这种邪教还请三思，与其单开炸鱼不如狂怒伊什塔毒蜥挂机绕圈圈

本文将从四个方面来讲述炸鱼经验以及相关技巧：

1.炸鱼前的准备；

2.炸鱼所需技能及其装配；

3.炸鱼方式解析；

4.安全炸鱼注意须知。

不过在最开始之前，我想讲讲自己是如何走上炸鱼这条道路的。

2021年的七月底八月初，萌新加入了EVE这个宇宙。

加团第二天萌新就开上了军团发的毒蜥，开始刷兔子生涯。很可惜，由于操作不当和意识不到位，本地来白贪无人机，毒蜥第三天就被抓爆了。

望着我的毒蜥残骸，我开始思考挂机刷怪是不是真的有意义，有没有办法更高效进行PVE生产而不是挂机绕圈圈。

在我苦恼之际，我们的军团CEO告诉我，想要快点生产刷怪，就只能选择炸鱼这一条道路，并发给了我几个和炸鱼有关的视频链接。我观看后，选择走上炸鱼这一条用效率换收益的道路，并在加团第四天就氪卡开了另一个小号～从此在炸鱼的路上一去不复返ᕕ( ᐛ )ᕗ

那么现在正式开始讲述炸鱼技巧与经验吧，希望能对各位有所帮助。

- 炸鱼前的准备工作

在开始炸鱼之前，你一个适合自己的刷怪总览，这个总览只有一个最基础的要求，其他随意：能同时显示NPC舰船和友方以及敌对白名红名舰船，纯粹的一键框选刷怪总览请不要使用。如果被敌对摸到身边而没发现的话，你的炸鱼船只能自求多福了。

其次，准备一艘扫描船，在开始炸鱼前把你所在的炸鱼星系的未知信号做一下扫描确定这些信号类型。如果本地虫洞太多又不熟练炸鱼的话请换个地方炸鱼生产，本地存在信标洞同理，请牢记一点，只有活着才有输出，活着才有收益。

最后，如果你运气很好，上线一看没有发现信标洞或者本地没有异常信号，也不要开始炸鱼生产，在空间站内停泊或者出站挂靠在铁壁外，等待一两分钟，查看预警频道是不是有附近的敌对信息。一两分钟不会要了你的命，但是可能要了你的船的命。

说到扫描信号，推荐使用摆烂挖坟金鹏，最近看到一个很有意思的挖坟金鹏配置：BV15U4y1g7JY

盾扩皮中A金鹏，七万三的有效，护盾抗性平均70%起步，硬抗爆炸高隐挖坟，怪来了也打不死你（反正高隐怪落地后30秒就会卡其脱离太，打不死你到时间他们就跑了）

摆烂挖隐秘坟首选～爆抗小白什么的都是邪教～

![image2](/images/smartbomb-farming/image2.webp)

回到正题，炸鱼双开基本都是一炸一补，也就是一个炸弹船做主力输出，一个补刀船协助炸弹船清理逃逸出立体炸弹范围内的小怪，最常见的补刀船应该就是可以携带岗哨无人机的船了。而炸弹船就多种多样了，比如灾难或者海灾难、实践、马克瑞，如果你ISK富裕可以选择巴盖斯或者元帅作为炸鱼船体验生活。总之炸鱼船的要求是高槽富余，电容和能栅以及CPU充沛，最后是炸弹船长轴够长，立体炸弹的炸弹范围也和舰船长轴有关的哦。

那么我是怎么起家的呢？答案很简单，双开实践炸鱼，实践这个船作为朱庇特黑科技，有这离谱的转向起跳速度和高中低槽数量，是炸鱼起步的最优选择。那有人可能要问了：实践7个高槽会不会有点少啊，只能装7个立体炸弹。没关系，我可以保证七个炸弹一点都不少，而且我之后的炸鱼船也只会装载7个炸弹，还有一个槽位是装的隐身，没有人能抓住深空隐身的炸鱼船

对了，补充一些炸鱼前的准备工作：

1、你所处的生产星系内请做好五到六个深空点，把深空的存在单独的一个文件夹里面并以单独窗口展示在你的布局界面上，确保能随时选择深空点起跳。

2、本地建筑附近做一个距离建筑五千公里左右的建筑观察点，以便观察建筑情况。本地来白来红后炸鱼船起跳深空隐身，挂机就行。如果扫描到作战针，在深空落地后假隐跳到建筑观察点，确定没有泡泡后跳回铁壁驻留。本地来白来红不要之前起跳铁壁，因为启动立体炸弹后有一分钟的开火倒计时，在此期间你不能进站或者驻留，极其危险。

那么问题又来了：我没有足够的ISK，能不能用T1炸弹或者T2炸弹？我只能说不如选择不炸鱼

![image3](/images/smartbomb-farming/image3.webp)

如图，势力炸弹耗电量最少，作用范围最大，伤害最高（官员炸弹不在考虑范围内），唯一的缺点——贵，是你的缺点

其次，T2炸弹需要炸弹技能五级，五级炸弹技能又意味着你需要更多装备来弥补巨额的电量消耗，而势力炸弹没有这种问题，它还更加省电

补刀船依旧是实践，100的无人机带宽也足够了，实践船体属性有无人机增并且可以放出四个岗哨无人机，技能不够的话除了无人机DDA以外都可以换成T1装备，保证永动即可

![image4](/images/smartbomb-farming/image4.webp)

补刀船进阶可以换成伊什塔，反正最终每个人都会开上伊什塔的，大家都爱伊什塔

![image5](/images/smartbomb-farming/image5.webp)

二、简单说完配置，接下来就是双开炸集会的方法了。众所周知，是个NPC怪（无人机区没有人权，不过也能炸，之后会讲到）就会有集会点，而CCP又偷懒，把相同的一套NPC产生方式用在了各大集会点上，所以炸鱼方式是通用的。

集会点分为两种，首先是近点集会，顾名思义，落地后怪就在你身边，远处有4个炮台/导弹发射台。

这种集会点在你落地后点击屏幕上那个绿色的异常标识，就会显示出异常点的具体位置，通过Q键手动调整炸弹船与异常点标准重合即可，落地可以一边开炸弹一边慢慢摸过去，第一波怪跑不出去的。

- 补刀船一般来说跳异常点50足矣，细致一点可以观察炸弹船落地方向来细化跳跃距离，不过操作量太大了，没太大必要。补刀船落地后放出岗哨，把炸弹船加入关注列表并且右键无人机，选择【守卫】这个选项，守卫炸弹船就ok啦

![image6](/images/smartbomb-farming/image6.webp)

第二种集会点就是远点集会，落地后怪离你比较远，需要开微曲到达刷怪位置。

![image7](/images/smartbomb-farming/image7.webp)

选择右侧的古斯塔斯哨站，观察，然后使用Q键进行走位，开推定点到如图所示的位置即可，到位后记得关微曲，稍微冲过头也没关系。

![image8](/images/smartbomb-farming/image8.webp)

接下来就是炸鱼船进阶！炸鱼船的最终阶段永远是马克瑞，跑得快，底槽多，8高槽。无论是一炸一补或者双开炸集会，还是以后的多开炸避难，马克瑞永远是最优解（个人认为）。话不多说，直接看一下小马一炸一补配置

![image9](/images/smartbomb-farming/image9.webp)

推子是500MN的C推，你要是有钱上X推也无所谓。但是我强烈建议把高槽隐形换成加强隐形，更便于假隐跳。我这一套配置CPU溢出一点，上一个603的CPU插即可解决

双开炸鱼甚至三开炸集会或者其他东西，就需要另一套小马配置了

![image10](/images/smartbomb-farming/image10.webp)

去掉皮球，把皮球换成反应式装甲增强，反应完全后能给你的马克瑞提供60%的对应抗性，于此同时C大修也要换成X修，不然修量跟不上伤害。至于炸弹，说实话你都双开马克瑞炸鱼了还缺一两个炸弹伤害？直接换成隐身。这一套炸弹马需要一个605的CPU插，不然CPU会溢出。

相信我，一个隐身能带给你的安全感远超本地20个人随时准备捞你。

别问为什么是兔子隐身，兔子区自产自销就顺便装上了，使用一个加强隐身效果也完全没问题的，只要能做到假隐跳，你上官员隐身都行

熟练炸鱼后一炸一补能做到一个集会点三分钟到四分钟（从落地开始计算到最后一波战列死掉），炸多了你甚至可以算好时间提前做好朝向起跳，减少转向时间优化效率。

再说一下其他注意事项吧。在炸集会的时候我最讨厌的是倒数第二波怪。倒数第二波怪有两种，三到四个战巡或者两到三个巡洋，战巡怪很轻松就能被炸死或者补刀补死，而巡洋怪，以兔子区为例，灾难皮特姆什么的玩意，抗性高的吓死人，巨硬无比，我炸鱼最讨厌倒数第二波怪出现灾难精英巡洋怪，这意味着一要消耗较多时间在这些巡洋怪身上。我完全有理由相信其他地区的集会点也是这个情况

但是我必须要说，一炸一补终究是有极限的，而双开炸弹马成本高，操作量也相对较大，如果走位失误可能需要分一个小马去追跑出去的怪，令人糟心。

那么问题来了，有没有一种方法能简化操作的同时增加效率和安全性呢？直到我看到了这个视频：

BV1bA411P7Bv

简单描述下视频内容：马克瑞和雷裔刷星门避难

![image11](/images/smartbomb-farming/image11.webp)

我又仔细观看了这个视频，并进行了实践。

电弧炮虽然比不上隔壁电弧百分百的护盾和装甲穿透，直接对结构造成伤害，但是有一个很大的特点：能弹射到附近的10个目标身上。

那么能不能照抄视频配置，一炸一补（迫真补刀）炸集会呢？实验后完全可行，马上给出配置和操作要求。

马克瑞配置如下，把反应甲置换成一个X动抗，其他保持不变即可。因为是兔子区，兔子怪动抗最低，动热伤又最高，并且优先动伤，再加上之后要使用雷裔进行补刀，所以需要两个动抗减少所承受的动能伤害

![image12](/images/smartbomb-farming/image12.webp)

雷裔的配置也很简单，因为是刷怪需要，所以选用动伤占比最大的爆发电容包作为弹药，但是在刷怪的同时要保证雷裔的安全性，所以跳刀微曲隐身也是必要的。并且需要减少雷裔转向和起跳的时间。

那么怎么刷怪呢？也行这就是为什么炸弹船都会选择马克瑞的原因，冥冥之中自有天意，马克瑞的装甲电抗有60%，加上主动抗性装备的增益，可以达到60%的电抗和80%的动抗，抗一个以动能伤害为主，电磁伤害为辅的电弧绰绰有余。具体操作是马克瑞正常按照一炸一补进行走位开炸弹，雷裔跳集会点30KM（这是最合适的距离），使用加瓦波电容包锁上马克瑞F1即可

如果你真的想用雷裔加上马克瑞刷怪，请做好一些心里准备：

雷裔的船体和三神裔船一样，属于有单独的势力划分的船只，也就是说船体技能需要从头开始学习，但最大的问题是电弧投射器的炮辅是自成一路的，不吃其他任何炮术辅助技能加持，只吃自己的炮术加持

![image13](/images/smartbomb-farming/image13.webp)

四项基本炮辅分别是增加电弧爆炸半径和爆炸速度、增加射速、增加伤害、增加射程，也就是说这四个炮术辅助技能需要挂满，最次只有电弧范围放大研究四级，其他都必须五级，因为这个和你刷怪速度息息相关。（我完全不能理解电弧为什么还会有爆炸半径和爆炸速度的）

和导弹一样，想要尽可能打出高伤害，就必须同时减少电弧爆炸半径、增加爆炸伤害和增加爆炸速度，我是不会告诉你雷裔电一个赫卡特只打了60伤害。

船体技能也是越高越好，因为。。。。

![image14](/images/smartbomb-farming/image14.webp)

每升一级加射速和伤害，很难不怀疑设计师脑子有问题，战列舰加成还只有这么点。。。

使用爆发电容包的话船体5级应该是有接近四百的DPS和3000的DPH，还是比较可观，作为半径10KM的立体炸弹来说

![image15](/images/smartbomb-farming/image15.webp)

再补充一点其他的吧。

脑插相关：

炸弹马有闲钱可以装上这一套脑插，其中605CPU插必要，其他脑插都是锦上添花了

![image16](/images/smartbomb-farming/image16.webp)

雷裔可以装一个705规避机动插和805电容管理插，减少惯性加电容量，不上其实也可以，不过我建议最好是705规避机动都上

再补一个成本问题：爆发电容包大概是两万二一发，一个集会点操作正确最多不超过20发就刷掉了，完全是赚的，不用担心会不会亏本

关于炸避难，其实也是一样，马克瑞往星门上一放，雷裔锁定星门F1就行。再随便加一个什么补刀船可以做到五分钟一个避难。你所需要做的只有把雷裔和马克瑞加入关注列表专心补刀。

至于无畏怪不用担心，兔子无畏没有反跳，开个跳刀拉远起跳就走人了。本地来红来白同理，跳刀-起跳深空，看有没有作战针，没有针就隐身等着就行，有作战针就再假隐跳到铁壁观察点看看能不能回铁壁。

雷裔和补刀船就更简单了，直接起跳回铁壁。因为雷裔的锁定目标是星门而不是马克瑞，所以不会有PVP倒计时能直接吃驻留，即使是对马克瑞造成了伤害（神必逻辑）。

补刀船的选择？魔像，小克都行，但是魔像最好别开模块，因为实际效率提升差不多。以魔像鱼雷为例，给每个战列打一轮，然后切下一个战列怪发射一轮鱼雷，开模块四分钟一个避难，不开模块四分半，但是开模块罚站还有开火倒计时。。。

雷裔电鱼，电避难可以直接起跳回铁壁，如果是锁定星门开火的话，如果锁定炸弹马开火请起跳深空，按照炸弹马流程操作。

关于炸鱼要说的就这么多了，总之炸鱼是一项技术活，胆小一点，心细一点。

本地来人不要紧张，操作正确及时他们不可能抓住你的（蓝加剑齿虎除外），希望这一篇炸鱼攻略能给大家带来欢乐。
