# 高安 NPC 采矿队（棱形矿队）攻略

> 来源：<https://docs.qq.com/doc/DQnZvZk5yVkR4dldw>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 术语说明
官方英文名为 **NPC Mining Operations**；社区俗称「棱形矿队」「菱形矿队」，中文正式名待核。
:::

:::warning 攻击采矿队会招来支援舰队
按 EVE University Wiki 的记录，NPC 采矿舰队被攻击后会召唤**支援舰队**（含后勤），且会根据声望判断敌意。动手前先确认自己的舰船能扛住支援舰队，或打完立刻跳走。
:::

棱形矿队是在Lifeblood资料片中推出的新NPC怪，各个势力都有自己的棱形矿队以及舰船，与此同时推出的还有资源战争、兔子和血袭者要塞、以及月矿改版。高安区的棱形矿队中除了运输舰会掉落盒子以外，其他的掉落都不值钱。

此教程将会教你如何用T3驱逐刷高安区的棱形工业。

准备工作：

的确你可以通过高火力战巡直接秒工业，但是这个方法在C工业以及各个强运面前不适用。所以首先你需要一条T3驱逐，配满火力，狙击模式DPS500以上，并确保自己的开推后速度能达到2200以上，且高槽装备延伸探针发射器。

下图为自用忏悔当然HKT及其他T3驱逐也可以，该配置仅供参考。

![image1](/images/npc-mining-fleets/image1.webp)

首先调整你的总览，来高效定位本地是否有运作中的NPC矿队。NPC矿队在很多星系都有。但是NPC工业的出现条件是公开的玩家建筑（未确认是否必须公开）以及本地存在NPC空间站。半径小的星系可以使用定向扫描来定位，庞大的星系（如50AU+）可以下作战针拉满距离扫一下（注意一下本地小行星带的分布，有时可以事半功倍）。

![image3](/images/npc-mining-fleets/image3.webp)

利用基本的5度经验，定位工业舰所在的大致位置。如果手慢正好工业准备跃迁了也没关系，根据工业的跃迁方向就可以大概率找到目的地。

![image4](/images/npc-mining-fleets/image4.webp)

NPC工业不会马上进站，你可以攻击他几下迫使他跳到深空安全点并刷出护矿NPC。

![image5](/images/npc-mining-fleets/image5.webp)

第一轮攻击的目的是为了让工业舰跳入深空点，并刷出护矿队。护矿队最终也会跟随矿队进入深空安全点。

在工业跃迁到深空安全点之后，使用你的作战探针，定位深空点的位置。然后跃迁到100KM。

![image6](/images/npc-mining-fleets/image6.webp)

在跃迁过去之后，开启你的高速模式和微曲，反向拉离护矿队。此时护矿队是打不中你的。有两个例外，一是艾玛的主宰级巡洋舰，二是任何战列级别的棱形怪，如果5度到了这俩个就放弃放弃打这个点。（星系安全等级越高刷战列和巡洋的几率越低）。

![image7](/images/npc-mining-fleets/image7.webp)

在你拉离期间，护矿队会一直追你，但是他们不会跳脸。将护矿队带离后计算离你最远的护矿队舰船和你的目标工业舰距离，普通工业舰150KM，C獾级200KM，A强运200到250KM，C强运300KM。满足以上距离后，跃迁到工业上。此时你的总览应如下图所示，跟所有护矿队都保持相应的距离。

![image8](/images/npc-mining-fleets/image8.webp)

之后开启狙击模式，锁上工业开火，如果DPS不够护航队可能要追上来就超载打，实在不行可以使用上面的方法再拉一次怪。产出如下。

![image9](/images/npc-mining-fleets/image9.webp)

![image10](/images/npc-mining-fleets/image10.webp)

可能的收益：

盒子可能掉落故事线采矿激光器，以及势力采矿无人机蓝图，几率大约2.5%-6%（当然不包括鱼儿子）。 必定掉落一个工业制服涂装，取决于你爆了哪个势力的会给对应势力工业制服。吨位越大越稀有（大金鱼1.5，小金鱼1.5，各个T2 2-6% 等等）

最后是有些人担心的声望方面，不会掉帝国声望，只会掉0.07左右的公司声望。
