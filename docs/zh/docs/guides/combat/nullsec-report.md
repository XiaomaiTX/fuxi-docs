# 00 地区报点规范

> 来源：<https://docs.qq.com/doc/DQktLQm1icUxma3Rm>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::warning 规则以当期公告为准
本文是联盟报点规则的整理，规则会随联盟管理调整。发生纠纷时以联盟当期公告与管理人员裁定为准，本文只用于说明常规流程。
:::

联盟规定

异常空间归属

- 刷完一个异常空间以后才可以在报点频道报点，获得下一个异常空间的所有权，需要提前朝向的旗舰可以在合理时间内提前报点。

- 无论是来敌还是主动放弃异常空间，离开则视为放弃该异常空间的所有权，其他刷怪舰船可通过报点获得该异常空间所有权。离开后若无其他人占据，请继续刷完该异常空间，禁止重新报点。

- 未刷怪行为的舰船在异常空间挂机占位会被强制移除所有权，包括各种原因导致的下线或者AFK等。联盟会依据实际报点与刷怪情况予以考虑，妥善处理由此产生的纠纷，

- 报点获得异常空间所有权后，其中包含的残骸垃圾、远征以及任何附加价值物品都属于刷怪舰船。

- 打捞异常空间里的残骸垃圾，必须在报点频道内征得刷怪舰船的同意。

- 禁止在未报点的异常空间内提前放置移动牵引装置（MTU）。未征得同意放置MTU的，刷怪舰船可以在保留截图证据后，将该MTU击毁。

报点规范

- 刷怪角色报该角色刷的异常空间，多开刷怪的不能用一个角色报其他角色刷怪的点。

- 如果报错点，及时在报点频道说明，再重新报点。如遇挑点刷怪（经常报点又说不刷的），请及时向联盟管理反馈。

- 刷怪舰船开始生产前，应当再报点频道应打出：大航+1、小航+1、常规+1等，向本星系其他刷怪船说明自己舰船类型。

- 同星系有对某一异常空间优先的舰船开始生产时，其他舰船禁止获得该类异常空间。若此时低优先级舰船正在生产，刷完当前异常空间后立即更换异常空间类型。高优先级舰船开始报点后，后续低优先级舰船报点获得的同类异常空间均无效。

报点方式

**注：不要在4-H刷怪**

刷新 [联盟] 频道置顶

![image1](/images/nullsec-report/image1.webp)

找到其中 [报点] 频道

![image2](/images/nullsec-report/image2.webp)

根据左上角 [星系]<[星座]<[星域] 进入对应星系的报点频道（直到频道置顶中不再有子频道）

![image3](/images/nullsec-report/image3.webp)

![image4](/images/nullsec-report/image4.webp)
