序言

本文旨在于给予有成为**FC**方向的新手玩家一些基本必须操作的入门文。本文面向群体应当为萌新而且老油条，请各位大佬键盘留情减少过多的因抬杠而引起的口水战。本人的**EVE**履历虽然不算丰富，但是长时间致力于对于新人的教学成长工作，对于新人成长有一定自己的见解。

大量的新手玩家大部分都是被各个视频网站上**EVE**的游戏视频所吸引而来，其中主要的莫过于战斗。驾驶着银河战舰将敌人炮轰成碎片是许多新手玩家的目标，那么指挥着一支舰队将敌方部队撕裂更是每一位战斗倾向新人玩家的梦想。

本文正是想为这一些玩家提供一定的理论知识，帮助他们更好的去处理游戏内大大小小的问题以及人与人之间大大小小的问题。在成为名酱**FC**的路途之中你不仅需要的是足够的战斗经验，优秀的指挥操作，还有更多人与人之间的合作是你们所要学习的。希望在阅读过本文之后可以给予你们一定的帮助，让你们可以在**EVE**的银河里面闯出自己的一片天地！

三．新人**FC**的常见问题

初生牛犊**—F1**战士

每一位来到EVE的玩家都会对战斗充满着好奇，可能有些以及早在B站看过各种各样的视频，小到操作迷幻的单人单浪，大到只能见到这边一坨那边一坨的超旗对轰。其实不论是你以后将要成为一位名酱FC，又或者是舰队中流砥柱的火力战士，还是在边上默默当爹的后勤爸爸，F1战士都是各位必经的一个阶段。在这个阶段中，你们会对EVE的战斗有了最初的定义，你们会逐渐地分流，有些玩家将会厌倦F1的生活转而把经历投于EVE的其他玩法中；有些玩家会被长时间F1所磨平了自己曾经的梦想，逐渐的变为咸鱼；有些玩家则会在不断的F1中获取战斗经验，从F1的大队中脱颖而出去胜任舰队中的其他重要角色。新人们就像沙砾一般被投入F1这个大贝壳中，只有足够优秀的玩家才能最终修炼成一颗璀璨的珍珠。

当你绝对要成为一名FC了之后，你一定要将你的F1之旅升华。首先你要明白如果话说得难听一些，在FC的眼中，F1战士只是一个数字，只是提供一个火力的名字。FC不需要你们去思考，只需要你们能够像机器一般完成他的指挥操作。但是你需要去思考，每一次F1的经历都是你成长的垫脚石。

首先，尊重你的**FC**！你才刚刚踏入游戏，每一位FC都是你的前辈，他们的技术会有高下，有些可能平易近人时不时得说一个笑话，有些也会不拘言笑，对于操作失误直接指出甚至谩骂你。不论如何都要给予他们尊重，嘴巴甜的孩子从不会吃亏。

其次，减少发呆刷手机走神吹牛逼的时间。EVE是一个沙盒游戏，不会有人像刷怪一样刷在一个地方让你们去打（约炮除外）。再加上大部分势力的集结效率普遍不高，所以从你做好一切准备到真正与敌人交火中间需要相当长的一段时间。切记要多多利用这段时间，从出站朝向的那一刻开始舰队就已经成型，后面FC的每一个指挥都可能是未来你致胜的法宝。在还没进入战斗状态的时候多去问问题，没有哪个老玩家会把它所知的一切传授给你，但如果你愿意多问，也许就会。

次之，要持续对战斗有积极的态度，F1的时候常常是无聊的，在规定时间准备就绪后，莫名的跑向一个地方，莫名的和另一些人打了起来，运气好的话可能还有几个签名甚至是KM，运气不好可能刚进去就被点掉了。你的操作只能是无尽的朝向，带跳，过门，朝向，带跳，F1，击毁报告可用。大部分玩家都会因为着机械化的长时间操作而逐渐失去了对战斗的热情。而你需要的则是对每一次跟队保持足够的积极性。在跟队中多去学习FC的常规操作，随着跟队时长的逐渐增加你就可以开始思考FC操作的含义。我见过玩了一周就开始带队的新人，他可以颤颤巍巍的指挥朝向带跳，但是一旦进入战场就自闭了。为什么呢？因为他其实只是会依葫芦画瓢，一旦进入了变化多端的战场环境就无从下手，这种绣花枕头一包草的情况是你们需要去杜绝的。真正的FC不是模仿别人而来的，而是从跟队带队中获取经验，并且将经验思考后转化成自己的技术。不要小看每次的跟队，多多做自我的反思与总结，有些FC也会在结束后做一个小总结。当你的战斗总结思考方向和他相同的时候，你就已经成功上道了。

而后，多多交流很重要。如果没有了现成的理论，你的成长必然需要的是思维的碰撞。EVE的战斗情况永远无法复制，双方从是用着不同的舰队在不同的地方进行不同的战斗。学会去跟老玩家，跟军团FC多进行交流，他们所说的自己观点可能会有偏差，但你只需要去其糟粕取其精华【说白了就是把吹牛皮的去掉】他们都将是你成为FC的好帮手。

最后，每个人的F1之旅时长可能有长有短，这会有种种原因所致。有些虽不熟练的玩家因为军团的需要被迫跳过很多步骤走上FC的贼船，有些玩家虽然已经具备了很好的战斗素养和带队能力但是因为军团没有需求而只能继续做F1战士。机遇是随机的，但是只有了提升了自我才能有继续成长的能力。望各位还在F1熔炉里的未来FC们共勉！

循序渐进**—**斥候

通过了第一时间段F1的磨练，你们慢慢的成长，随着你们技术的提升，你们中有部分玩家可能会被授予斥候—这个光荣的称号。当你的FC告诉你你今天是队伍的斥候时候，恭喜你，你的半只脚已经踏入了FC行列。

斥候，这是一个熟悉又陌生的名词。玩过LOL的各位都晓得，迅捷斥候—提莫就是个灵活小巧，能够隐身能够加速拿这个望远镜偷窥你【还能吹箫QwQ】的崽子。斥候斥候，主要的任务就是平时在在前方找肉吃，打架时候窥探战场情况给舰队拉ping点的存在。

看了刚刚的名词解释，相信你们都已经跃跃欲试，一边想着把所有能吃的肉都抓出来；一边想着在战场上搜寻战机，帮助舰队打破困局。但我不得不为各位浇一盆冷水QAQ因为你们刚开始FC对你们的要求就是“XX，给我拉个200KM点”一次两次，没事，但后面你会发现你干的还是这一些事情，与你以前所想的有很大出入，有些玩家就丧失了积极性，这是非常可惜的。

我可以很负责任的告诉你，99%的名酱都是由斥候而来。如果说FC是一支舰队的核心，是一支舰队的总经理，那么你—斥候就是总经理的秘书。FC在带队的时候需要兼顾大量的事情，斥候正如协处理器一般帮助FC筛选一些信息从而达到效率最大化。

那你肯定很疑惑了，为什么只让我拉点至少让我去前面看看敌情吧？有很多时候不是FC不想让你去，而是他不能让你去，虽然你经过了F1的磨练，按F1抢KM的操作很流畅。但是当你开着小截击过门看到门后各种未知的情况时，你将会不知所措。最基础的操作，报本地的人数你可能都无法完成。本地由白有红有蓝，三四个你可以数，如果是一大列呢？一过门敌人已经贴门放出无人机环绕起星门，生与死可能只是几百米的距离你会不会慌张呢？最后往往你在压力下只能慌张地给FC一部分信息，可能只有人数而没有舰制，只有舰制没有位置，甚至于信息出现错误。FC对于战场的判断就像是扫描一般，你的信息越少越混乱甚至是错误时，他就需要排除错误，然后再填补你缺漏的信息。这样就造成了信息流上缺乏时效性，更可怕的时候会因为沟通出错导致舰队的覆灭。这就是FC们常常习惯于使用与自己搭班的斥候而不愿使用新斥候的原因。

首先，要成为一名合格的斥候最基础的就是以最大能力获取信息并将信息准确快速的汇报给FC。什么是最大能力？就是在保证你不死的情况下，把敌方的所有信息【包括但不仅有人数，舰制，星系位置，星座位置，朝向，速度等】获取并且简单明了地汇报给FC。

其次，对于信息的优先级进行筛选。随着你的操作【逃跑能力】有了提升之后，你往往能够获得敌方舰队的大量信息。但一个优秀的斥候不应当将这些信息一股脑的全部甩给FC，而是需要将它们进行筛选，先汇报优先级别高的信息，剔出一些无效信息。例如在窥探敌方舰队时候，本来敌方舰队30人一人下线变成29人，二敌人又开始朝XX星门拉朝向。那么这时候明显朝向信息是高优先级，因为朝向信息可以让FC提前了解敌方舰队的去向，至于30个人中有一个下线，在这个时候就成为了低优先级信息。但不代表少人永远都是低优先级信息，如果你的舰队处于周围骚扰状态往往一两个掉队的就成为了你们今晚的盘中餐。

随着你做斥候的履历增加，你就可以更加精准的对信息进行筛选，这是斥候进阶必不可少的过程。

其次，开始自行处理信息并给予FC建议【指示】。FC总所周知是舰队的指挥官，那为什么我说斥候可以给FC下达指示呢？因为你的信息比他要多！你与FC同时都知晓自己舰队的舰制人数战斗力，而你又能看得到敌方舰队的情况。当你成长到一定阶段时候你就可以自行对敌方舰队进行预判，并指挥你的舰队。这其实在战场上是很普遍的情况。战斗力强的舰队往往斥候就是FC龙套。当你能通过窥探敌方舰队情况并处理信息指挥己方舰队的时候，你就又向FC迈了一大步。

最后，虽然上文显示你能指挥舰队，但你仅仅只是指挥舰队的去向，你的能力依然不够成为FC因为你缺乏在接战时对舰队的指挥。斥候是一个吃力的工作，开始还需要和FC进行磨合，这其中肯定会有一些问题存在。所以当前很多FC都喜欢自己多开截击作为斥候，但当你能达成我上面所说的三点时你的舰队效率势必会高于多开党。

化蛹成蝶**—FC**

恭喜你，你终于成为了一名FC！可能你到了一步会有些迷茫，曾经你一直幻想着成为FC，当你真的变成了，其实也就是这样。外在光鲜亮丽的背后，是每一个FC在成长路上所留下的汗与泪，是常常被迫顶着军团联盟压力无处发泄还要被F1战士唧唧歪歪的苦涩，是无法打出足够优秀KB证明自己能力的委屈与无奈。

当你走到了这一步，你已经快完成了你曾经的梦想。初成FC的你千万不要太过于急功近利，当你成为了一名FC以后，舰队的所有锅都需要你来背，斥候不会背，点名走位不会背，F1们更不会背。你面对的将是各个地方的其他FC们，他们有些玩的时间超过你挂技能的时间，他们有些在你带队时候打架，在你入眠时候依然在打架，他们有些有着战斗素养很强的队伍，他们…当你站在了一个高出你就需要去跟更强大的敌人竞争，名酱一抓一大把但谁又能打包票我今晚必胜呢？顶多战略胜利【KB】或者战略胜利取其一。不要太把自己当回事，难听的话有时总有它的道理。继续在自己的职位上发光发热，投入足够的时间与经历在带队上，你终将有所建树。

曾经有位老板跟我说过，FC是用钱砸出来的，思来想去也的确有点道理。放下你的架子，别把自己要求的太高，大家都是普普通通的玩家不是么？玩游戏最重要的是快乐，你，一定要快乐哦QWQ

二．**FC**的基本操作

在上一节中我主要想讲述的是大部分FC的成长之旅，了解自己的成长过程相当的重要，成长不论在游戏内或游戏外读需要付出血与泪。在这一节我想要讲述的是初成FC后你应当需要有的意识和操作。我并不能为各位面面俱到，将所有的FC理论知识全部列举而出，主要是强调一些我觉得实用性强的知识点。本节知识并不具备把你武装成优秀FC的能力，但是可以帮助你理清一些思路，让你更好的去分析问题。

**1. FC**的职责

职责意味职业责任，那么一只FC的职责又是什么呢？如果狭义的解读话，FC的职责就是在拟定的计划下，指挥舰队达到计划中的战略或战术目的。这样的情况常见于联盟队中，因为联盟队组成错综复杂，有自己家的有隔壁家的甚至还有地图对面的友军。而且在联盟队中往往有要求较高的战略目的，所以FC们往往就恨不得使用巴啦啦能量将你们全部变成只需要接受指挥并执行的木头人，这样可以减少他当老母亲到处操心的工作量。

但是在现实情况中，FC的职责常常并不是这些。因为大部分军团往往会出现管理层不足的情况，而既然你是FC，在所有人眼中你打仗牛皮打架肯定也很牛皮，打架牛皮就代表PVP牛皮，会打架肯定要会配船等等。所以最后，你常常不仅要负责带队，你可能还需要负责军团的舰船装备工作，负责萌新们战斗方向的指导工作，集结开始前需要求着各位大佬们来，集结后要感谢F1战士们的积极参加。所以我强烈的建议各位想成为FC的新人们你需要的不仅仅只是指挥方面的能力，你还需要对EVE各个方面都有一定的知识储备，还有就是一个很强的人际沟通能力，FC需要把舰队凝聚起来，使其爆发出强大的战斗力，这一点我将在后面的文段中做细节讲解。所以不要因为自己似乎忙于军团各种大大小小的事情而不是专注于FC感到沮丧，做事就是学习锻炼的机会，把自己完完全全的武装起来是关键！

FC培养一些据有能力的F1战士也是非常有必要的。将他们培养成你的斥候，你的点名走位官甚至于新星FC这都可以极大的提升你的工作效率，而且有了自己的一套班子之后，不论F1战士如何更换，整体舰队的战斗力都有一个不错的保证。

最后，FC虽然代表的是舰队指挥官，但往往他们都一人干着很多其他工作。想要成为一名优秀的FC，你们不仅仅只需要指挥技巧，综合性的游戏能力也是必不可少的。除了指挥能力外，号召力凝聚力也是必不可少的。49会战的时候联军的超旗掉线了常常再也不愿登陆，甚者更是大家诱导进战场他诱导回家。FC一定要把舰队带成一根绳，上下心齐才能让战斗力最大化。

**1. **如何组建一支舰队

FC是Fleet Commander的缩写，要做一个Commander首先就先需要一支Fleet。那么组建一支舰队是非常重要的任务，为了方便与后面的战斗，你需要有一个系统化的舰队构成思维。

首先一支舰队有必需位置和可以空缺的位置。首先必需位置就是FC，斥候，F1火力三者。

FC不需要解释，没有FC那么舰队的存在也就没有了意义，作为舰队的核心FC是必不可缺的。

斥候是FC的眼睛，帮助FC获得各种各样的战场信息，没有斥候的话舰队就只能蒙上眼睛乱冲，排除瞎猫碰到死耗子的情况剩下的结局都不会太好，所以斥候也是必须的。

F1火力是舰队的中流砥柱，没有输出那不论FC与斥候有多么的优秀都无法打出KB或者完成战略目的。【这里表达的是主流舰队，例如电子战舰队或者后勤舰队等等不包含在其中】

前面说的三者都是舰队的必需要素，后面再来说一些其他的位置。后勤，后勤就是奶妈，他的作用就是提供源源不断的额外生命值。一支完整的舰队中后勤是必不可少的，因为只有有了后勤舰队才会有持续作战的能力。但是在一些舰队，例如HOT队散打队这些队伍对后勤并不是强制性的要求因为他们往往不需要持续战斗力而是直接抓住敌人按死就溜。后勤的技能也是与战斗技能完全分开，所以在大家技能点不够的时候去挂后勤的人数普遍会少一些。一旦拥有了后勤，你的底气也会足很多【毕竟有人能够捞你】在拥有足够的F1的情况下为舰队添加后勤也是非常好的选择。

电子战也是舰队中的着重加分项。通常一支简单的舰队会由F1FC斥候来带电子战【扰断扰频缠绕】，但随着舰队的成熟有了独立的电子战成员那么电子站能力就会有很大的提升【例如平常的缠绕反跳都只有10-20KM左右但是势力舰船如血袭者，莫德团有50%的距离加成天蛇有50%缠绕效果加成而常用的专业级别舰船如长剑拉克都可以使距离达到60KM 部分势力舰船还有其他方面的加成血袭者的吸电毁电】除了反跳缠绕这种最基础的电子战外，G族的感应抑阻，A族的武器扰断，M族的标记和C族的ECM都是能让敌人难受至极的电子战。电子战作为一直以来舰队的辅助手段，通过合理的运用是可以达到巨大的效果的。

走位官/点名官这两位在上文中其实意义已经阐述的很详细了，这里就不再多重复，主要是想说明他们还有一个重要作用就是规避斩首惩罚。斩首也是上文所提到的，一旦FC被斩首，如果是一个较为简易的舰队缺少其他指挥，那么舰队就会直接变成一盘散沙。但是一旦你拥有了点名官/走位官以后即使被斩首，舰队依然可以继续维持住当前的状态而不是直接崩溃。而且一旦你拥有了走位点名特种后，你可以极大减少被斩首的风险【队友抗】。所以在培养出有能力的F1之后将自己的职能分出去是很有必要的，也可以很好的降低自己的工作量，把更多的精力投入到其他问题上。

除了舰队成员的确定以外，舰队舰制也是你所要思考的问题。EVE的战斗自由性很大程度上正是来自于舰制的多样性，不同种族不同类型的战舰编组在一起有时就能打出不一样的效果来。在你们还没有足够经验的情况下，我建议你们先根据比较主流的舰制进行小的改动。因为主流舰制之所以能流行必然是因为它有OP的地方所在，创新是好的想法但现需要把基础领悟透彻。

影响舰队舰制主要有两个大因素。第一是战略目的，比如我今天准备组一个收割队伍，但是目的地很远我又不是很像跑过去再跑回来，那么我思来想去就准备组一个长尾蛟HOT队。而比如今天是一个主权争夺战，对面已经摆开了阵势是一支完整的舰队，那么明显上HOT队伍就不太合适。根据不同的作战需求来编排自己的舰队舰制很重要。第二则是舰队成员，比如大家都是新人刚开始也只能使用一些T1驱逐巡洋，那我可能就会考虑还是组狞獾等这样要求不高的简单T1队会好一些，这也要完全的考虑到舰队成员的技能，战斗能力与他仓库里的存货。

最后，编排舰队是FC出门打架前最重要的任务之一，需要你在平衡的情况下，最大限度的保证舰队的输出火力抓人能力持续能力等等，大部分时候都需要你有一定的取舍，这又与你的个人经验有很大关系。通过跟队作战可以有效的提高你对于舰队编制的理解，理论的知识永远都只是死板的东西，只有当你把它思考后理解并运用自如才是真正的掌握了它。

**1. **如何搜索可口的猎物

当作为FC的你把舰队拉起来了以后，迫在眉睫的事情就是搜索可以食用的猎物。作为一位刚起步的FC，你应当选择反抗能力较低，美味可口的猎物。下面我来给你介绍几种要求偏低的队伍。

一．** **抓杆子队

绕杆子是很多PvP玩家的起始点。通过绕杆子既可以获得相当可观的收益，又可以锻炼一定的PVP能力。抓杆子队的优势是非常大的，首先你面对的大部分都是单人的绕杆子船，绕杆子船普遍火力高缺少防御。【他们还十分喜欢挂机】只要你足够勤奋，一天你可以轻轻松松抓到两位数的杆子船。杆子区都位于低安区域，不论你是高安低安00团都可以相对轻松的到达，交通便利。杆子区还有许多的其他PVP玩家，绝对是你磨练PVP能力的绝佳之处。

二．**00**收割队

00是许多FC最终的归宿，大部分FC都需要待在00为他的公司与联盟作战，所以锻炼自己的00作战技能是必不可缺的一部分。00收割队正是你在00可以带的强度最低的队伍。因为00的大部分玩家并不像低安玩家时刻处于战斗状态，他们的主要生活是生产作业【包括刷怪挖矿打死亡等等】而且大部分00玩家的个人战斗素养是偏低的。所以你可以带着你的收割队轻松的屠杀这些farmers。

开始的时候可以尝试使用一些HOT队伍，成本低回家速度还快。

三**.**过洞队

虫洞是EVE一个神奇的空间连接设定。他不仅可以将游戏里的任意星系连接在一起，还有额外的虫洞空间可以去探索。因为虫洞的特殊属性，所以你可以经常清理驻地附近的信号。如果发现了足够合适的虫洞就可以组织过洞队。过洞经常可以让你穿越到一个00的腹地星系这样你就可以绕过他们的外圈预警，从后方来的箭往往是致命的。还有的虫洞会通往一个虫洞空间，虫洞空间没有本地频道作为预警，只能通过舰船扫描器来搜索空间中的物体。你可以轻松的使用隐身船或者侦察舰躲避对方的定向扫描。

EVE的战斗有着极强的多样性和不可预测性。以上的仅仅是我眼中的一些新手FC起步的低强度队伍。通过低强度的队伍可以一方面增加你的自信心，另一方面锻炼你的指挥技术。这些看起来简简单单的队伍往往都是名酱们成才的基础。

在自己有学习实践条件的时候一定要多学习多实践，把握住机会你就有更上一步的可能。
