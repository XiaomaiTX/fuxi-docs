- EVE最快的起步方式之一：高安死亡远征

这里提供新人一个最安全简单快速上手的起步方法来赚取EVE中的第一桶金。

在高安星系也有很多遍地可见的异常，这些异常在打完之后会有概率触发远征，远征既是只有你自己能知道在哪里的一个死亡空间，概率产出死亡装备和势力装备。

萨沙——萨沙隐蔽处/庇护所 产出：异常BOSS 萨沙爱国者XXX(护卫/驱逐船体) 萨沙3-10死亡 萨沙司令部。死亡产出：魔女级图纸，森A系列死亡装备，萨沙爱国者小型装备。

萨沙贼窝 产出：异常BOSS 萨沙爱国者XXX(巡洋船体) 萨沙5-10远征 萨沙神经麻痹中心，**小概率在低安，对新手难度较大。**产出幽灵级蓝图以及森塔姆B型装备，萨沙爱国者中型 装备。

血袭着——血袭着庇护所 产出：异常BOSS 黑暗血袭着XXX(驱逐船体) 血袭着4-10死亡 毛一扎塔修道院。死亡产出：科波母C型装备，阿什母级蓝图，黑暗血袭着中型装备。

血袭着贼窝 产出：黑暗血袭着XXX(巡洋船体)血袭着5-10死亡 血袭着精神药品仓库，**小概率在低安，对新手难度较大。**死亡产出阿什母级蓝图，科波母B型装备。

天蛇——天蛇隐蔽处/庇护所 产出：异常BOSS暗影天蛇XXX(护卫/驱逐船体) 天蛇3-10死亡 天蛇改良哨站。死亡产出：夜魔侠级图纸，暗影天蛇小型装备，克尔利伊A型装备。

天蛇贼窝 产出：异常BOSS暗影天蛇XXX(巡洋船体) 天蛇5-10 天蛇集团水培站点，**小概率在低安，对新手难度较大**。死亡产出：克尔鲁姆B型装备，警惕级蓝图，暗影天蛇中型装备。

古斯塔斯——古斯塔斯隐蔽处/庇护所 产出：异常BOSS 恐惧古斯塔斯XXX(护卫/驱逐船体) 古斯塔斯4-10死亡 古斯塔斯侦察哨站。死亡产出：毒蜥级蓝图，恐惧古斯塔斯中型装备，皮特姆C型装备。

古斯塔斯贼窝 产出：异常BOSS恐惧古斯塔斯XXX(巡洋船体) 古斯塔斯5-10死亡 古斯塔斯迷幻剂供应中转站，**小概率在低安，对新手难度较大。**死亡产出：毒蜥级蓝图，恐惧古斯塔斯中型装备，皮特姆B型装备。

天使——天使庇护所/贼窝 产出异常BOSS 主天使XXX(驱逐/巡洋船体) 天使5-10 天使红灯区。**小概率在低安，对新手难度较大**，死亡产出：吉斯塔姆C型装备，主天使中型装备，塞纳波级蓝图。

以上的所有BOSS，都记得要捡残骸，有条件带打捞器进行打捞，能有T2打捞件产出。

**当你的船在远征的死亡空间里时，你的远征是可以被其他玩家并且抢走的（抢杀boss），千万小心。**
