基础知识

行星开发是最休闲的一种EVE玩法，大部分操作在建筑内就可以完成，每天需要做的就是鼠标点一点，开船收集一下产物，类似于多年前的QQ农场。所以大家也称行星开发为“种菜”，将行星产物称为“菜”。

**菜**

EVE按等级划分共有5种菜，从低到高分别是P0、P1、P2、P3、P4。其中P0是直接从行星上开采不经任何加工的菜，但在一般生产种，我们通常选择采集P0菜后，直接加工为P1后进行收集。P2是相对P1更高级的菜，需要两种P1来合成。P3是更高级的菜，需要2种或3种P2来合成。P4是EVE种最高阶的菜，需要3种P3合成或者两种P3与1种P1来合成。

**行星**

众所周知，每个星系都有一颗恒星、众多行星和许多卫星及小行星带组成，本玩法的重点就是行星。EVE中可供行星开发的行星共分为8种，分别是温和、贫瘠、海洋、风暴、冰体、熔岩、气体、等离子。我们可右键星系的名字来查看该星系中分布有哪些类型的行星。

![image2](/images/planetary-p1/image2.webp)

![image3](/images/planetary-p1/image3.webp)

不同类型的行星对应着不同的行星产物，例如：每颗贫瘠行星都基础金属、微生物、水基液体、碳化合物、贵金属，也就是说在贫瘠行星上可以生产5种菜。每种类型的行星都对应5种菜。

特别需要注意的一点是：如果想加工P4，只能在贫瘠与温和行星上完成，其他类型的行星不可以建造生产P4的工厂。

**海关**

顾名思义，海关是管理行星进出口的地方。如果行星没有海关，那么你便不能将行星产出的菜收上来，亦不可以把你的原材料输入到行星。你可以在总览中，勾选行星海关办公室的方法让海关显示在总览中。也可以在总览或任意能找到行星的地方右键行星查看该行星是否具有海关。

![image4](/images/planetary-p1/image4.webp)

如果你已经成功了解了海关的意义，那么在你种菜前还需要格外关注的是海关的**税率**。找到海关办公室→查看信息，在属性界面你可以找到有关该海关的税率的信息。如果税率是10%，那么在海关与行星之间进行物料的传输，你需要支付传输物资价值10%的税。简单来说，如果税率过高，会极大影响你种菜的收益。

![image5](/images/planetary-p1/image5.webp)

如果你要在海关与行星之间运输物料，你需要右键行星→海关办公室→联系海关办公室。在该界面你可以通过左右拖拽，再点击右下角转移实现海关办公室与行星之间物料的传输。值得注意的是，海关办公室拥有35000m3的容量，只给许多懒人许多偷懒的机会，我们将会在下文中介绍这种方法。

![image6](/images/planetary-p1/image6.webp)

技能篇

相比其他玩法，种菜需要的技能点极其之少。

行星开发，宜先追求质再追求量，因此，对于小号或新号，请先先将行星学升级至1级后，再将指挥中心概论升级至4级，最后将行星统筹管理学升级至4级。至此，行星开发技能已足够，也是性价比最高的等级。当然，如果条件允许，指挥中心升级概论升至V，可以带来更多的收益。

开始你的种菜旅程

**种菜准备**

为了顺利的开始种菜，你需要准备**数个行星指挥中心**，一艘能够容纳数个行星指挥中心的工业舰（建议使用**伊特龙级**）和一艘用来收菜的工业舰（建议使用**埃比斯级**）。如果你的种菜场所稳定不经常更换，那么你只需要使用一次伊特龙级来安装你的行星指挥中心。

接下来你需要选择你要种菜的行星。这里你需要知道，不同行星包含的资源种类和丰富度是不同的。你可以通过右键行星→查看行星工业来进行勘测（当然，勘测的前提是你掌握了行星学和遥测感应技术）。其中每种资源右边的方格表示着该资源在该星球的丰富程度，方格越多越丰富。一般来说我们会选择种植该星球含量丰富的菜。

种菜的收益

既然你已经能独立自主地种菜了，那这项活动能给你带来多少收益呢？

我们为大家开发了一个方便实用的工具表格，你可以利用工具表格查看。

![image35](/images/planetary-p1/image35.webp)

**如果你保持2天对行星管理一次的频率（也就是能保证工厂满载运行），种植的菜价格也在600isk以上，那么你5颗星球的日收益可达24m（以菜价600isk估算，月收益可达720m），如果你种的是高价值的菜，日收益可达38m（以菜价1000isk估算，月收益可达1140m）。**

那需要花费多少时间代价呢？每两天只需要8分钟！4分钟用来调整生产，行星的资源并不是固定不变的，经过一段时间开采，原本富饶的地区会变贫瘠，原来贫瘠的地方会变富饶，所以你需要调整采集控制模块的位置和采集节点（也就是前文中的小蓝点）的位置，然后将采集好的P1菜发射到海关。如果你是新手，这个步骤可能会花费你更多时间，当你日渐熟练，这个步骤对你来说就是小菜一碟，三下五除二即可做完。你可以将你的采集周期设置为2天12小时，这样你的每小时平均产量较高，且两天的时间，不会造成你的库存爆仓，引起浪费。
