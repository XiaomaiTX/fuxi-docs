# 挖气教程

## 基础概念

挖气，即主要通过在气云信号内通过使用气云回收装置进行气云的采集工作的生产行为（长难句起手）。因为其具有技能要求较低，单位时间收益较高，舰船装备投入较小，生产时间灵活等特点，适合新手在中前期获取较大的生产收益。但气云信号刷新速度慢，且局限于少部分星系（座），必须指出完全依赖挖气进行生产显然是不现实的。不过，将挖气作为其他生产行为的适当补充，是极有利可图的。

挖气的舰船没有特定限制，除去专职进行资源采集的舰船以外，其他所有带有炮台位的舰船均可装备至高5门气云回收装置。但由于气云体积较大，考虑到成本、灵活性和安全性，一般仍然推荐采用采矿护卫、T2采矿护卫进行挖气生产。

另外，在静寂谷的某些特殊丝胶的开采具有特殊的联盟规则。但仅限于静寂谷地区，在黑渊、菲德的活动不受该规则影响。

## 地点选择

气云信号的刷新局限于某些特定的星系（座），以2-3级未知信号形式出现，其中4级信号为气云坟（里面没有气云）。需要玩家使用扫描舰船对信号点进行扫描，扫描强度达到100%后即出现气云地点，可跳跃进入进行相应生产活动。

## 操作方法

一般而言，一个地点中常常含有距离在50-100km分布的2-3个（取决于气云类型）气云矿，靠近气云矿后需要锁定气云才可进行采集操作。除最初的锁定和开枪以外，采集过程可持续，直到舰船的矿仓（采矿舰船）、货柜仓（其他舰船）被装满后停止。我们一般建议提前规划时间，满仓前后及时返回建筑进行卸货，提高整体生产效率

气云的产出可以卖给专门回收矿物的玩家，也可以按军团回收渠道处理（见 [黑渊社区教程](/docs/community/pure-blind-community/)）。气云的收益区别于不同的气云种类，收益在20M-200M不等。
