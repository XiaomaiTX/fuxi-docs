# 行星开发基础介绍

> 来源：<https://docs.qq.com/doc/DQklkRXJCQVJnZUR1>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 术语
行星开发（Planetary Industry，PI）在社区常称「种菜」；产物按加工程度分为 **P1–P4**，P0 为原始采集物。
:::

种菜指南

- 什么是种菜

种菜是eve里星球开发的别称，指在星球上布置海关等种菜设施开采行星的资源。种菜的收入与角色数目成正比，勤快人一天收一次，懒人可以半个月收一次，收益的话，四个角色一天收一次可以负担起两个号的月卡开支。一般在同一账号下除了主角色外，另外两个角色只种菜，获取最大收益。

这里以利润最高的P4产品广播节点Broadcast Node举例，左下角选中广播节点

![image22](/images/planetary-basics/image22.webp)

可以看到需要三种P3 ；六种P2； 12种P0 P1。

标准技能下，每个角色可以开采五个星球，这里计划一个角色开采加工一种P3，共需三个角色。每个角色五个球，拿出四个球分别开采四种P0并加工成P1以便减少运输体积。剩下一个球作为工厂星，将P1合成P2和P3， 第四个角色灵活开采短缺稀少P1 维持整个体系工厂持续运转，同时将P3合成P4。

这里3000个p0生产20个P1；80个p1生产5个P2；20个P2生产3个P3；18个P3生产一个P4；因此体积被极速压缩，方便运输。但是P3和P4体积相差并不悬殊，但是利润P4更高一些。

![不同星球P1产出是有重叠的，可以点击后面三角符号查看，比如稀有气体，风暴冰体气体都有产出](/images/planetary-basics/image23.webp)

_不同星球P1产出是有重叠的，可以点击后面三角符号查看，比如稀有气体，风暴冰体气体都有产出_

选哪个球呢？这里就需要因地制宜。尽量选择储量大，半径小的球。这里就需要群里的《C1洞各行星物质含量》表了，比如活性气体这个在表里可以看到 6789行星都有活性气体但9号行星明显储量多，因此选择9号行星；但有一个特例 比如某个元素只存在一个特定行星上有，那么就只能开采这个了。

工厂星选择尽量在半径小，最后含有点所需P0的星球。

八、安全收菜技巧

1.快捷菜单--菜单-商业-行星殖民地--拖拽到左侧控制边栏上，在该选项中可以快捷种菜

2.时间---最佳收菜时间为维护前后半个小时（+8区19:00前后30min）

3.配船--开白蛋，G族专用菜船，低槽上最少俩稳定剩余低槽上惯性稳定。

4.操作界面--打开工业货仓-拖动到屏幕上方，切换到行星产物仓，打开海关仓库，紧挨着货仓放到下面

5.减少损失--在海关被抓第一时间将船舱内菜全部扔进海关办公室（所以直到起跳离开后，才可以关闭当前海关界面）被抓后狂点跃迁到本地 基础设施中心（I hub)

6.收菜标准动作---从pos向海关跃迁，在跃迁过程中打开目的地海关界面，飞到海关后马上向下一个海关跃迁，在跃迁开始前迅速将当前海关内菜拖动到船舱里，在跃迁过程中打开下一目的地海关界面，如此循环

ps：收菜前最好先将所有所有星球内菜传输到海关
