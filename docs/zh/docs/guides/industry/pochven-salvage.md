# 波赫文打捞入门

> 来源：<https://docs.qq.com/doc/DQkFwb2FBY2pwaUVD>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::warning 区域进出有风险
波赫文（三神故土）的进出口依赖纤维与虫洞通道，进出时机与路线一旦被堵，损失往往超过打捞收益。进区前先确认撤离方案。
:::

三神裔空间萌新打捞

原作：自言自语的聪哥

起一个舰队，跳安全点，使用任意故土5人纤维进入故土，例如最便宜的 Home-5 'Pochven' Filament

三神裔空间一般就两个地方大概有残骸可以捞

第一就是 观测站闪点

进入异常空间后做一个点, 然后进轨道做一个点. 这种战斗异常很快会被玩家打掉, 我们的目标就是两个点留下的残骸。

三神裔残骸大部分价值在于打捞件, 伊甸统合的残骸打捞件难度很高, 而且值钱的T2打捞件并不多, 所以萌新努力捡掉落就好了。

**如果你想捞这些****T2****残骸，用****3****打捞插的驱逐。**

如果有友军的闪点舰队，跟在他们后面打捞，一个点可以捞一亿多。如果是白名的闪点队，注意安全，先做好位标，等信号消失，人走干净了再去捞。

现在故土内长期有队伍刷点，一般平均走8跳你就会遇到一个刷点队或者正在被刷的点。避开PH集结地撒卡森，那里堵门会比较多。

第二就是 位于恒星的 星际舰队部署点

这个地方根据本地星系的虫洞类型不同, 来进攻的敌人种类也不同. 当然也有可能没有敌人来犯. 如果一旦有敌人交战, 那么玩家丢下MTU就可以隐身在旁边看戏了.

等到交战双防有一方胜利后, 就可以打捞.

注意的是, 三神裔声望和伊甸统合的声望都要是正的, 不然没办法打捞.

如果是冬眠者胜利的话, 最好放弃等待, 因为三神裔打不过冬眠者

存够垃圾以后可以考虑用Proximity-5 'Extraction' Filament 脱离纤维直接立刻故土，但这个纤维比较贵，所以扫个洞出去更便宜，当然也更麻烦。

东西运输的时候，尤其是进吉他的时候小心强暴。
