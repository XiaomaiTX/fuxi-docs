# 工业与制造

本板块收集行星工业、采矿、工业与制造相关的攻略，从**离线也能赚 ISK 的种菜**——行星工业开始。这个板块旨在揭开 EVE Online 庞大工业体系的一角，介绍这个游戏在操纵太空舰船之外的玩法。

## 主要方向

- **采矿**：小行星带、冰带、月矿与气云点的开采方式与收益对比。
- **提炼与反应**：矿石提炼、月矿反应与材料链。
- **制造**：蓝图研究、材料效率与常用舰船的制造流程。
- **行星工业**：行星生产线的搭建与产出规划（即俗称的“种菜”）。
- **工业设施**：军团与联盟工业设施的使用方式与注意事项。
