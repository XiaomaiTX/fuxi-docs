# 新号生产起步指引

> 来源：<https://docs.qq.com/doc/DQnhQdEVPQkZxS25G>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 数据时点
本文写于较早版本，技能规划与收益数字只作路线参考。现行的技能与产出数值请以游戏内为准；同行星开发、打捞等相邻玩法可以交叉参考 `guides/industry/` 下的其他页面。
:::

- 三体军事学院新人新号生产指引

第一篇，非常新的新人

先把姐妹会的史诗任务做了，就是新手任务结束后给你的一个，要你去很远的地方的一个任务。这个任务非常重要，奖励也非常高，对你熟悉游戏的基本机制很有帮助。

当你对游戏有了一些了解之后，你可以考虑以下开局：

1，高安异常死亡远征

- 用巡洋甚至驱逐就可以刷，当然推荐用势力巡洋或者战巡。

- 小心强暴，落地开推环绕，本地有红减的话不要停留。

- EVE最快的起步方式之一：高安死亡远征

2，UMI或2D-附近跟随00刷怪大佬打捞垃圾

UMI星系周边和黑渊是FRTU新人的活动范围，你可以在那边自己挂机刷怪，或者打捞别人刷怪的残骸。成本低，收入可观，买一条打捞促进就可以开工，不过需要有人刷怪的时候才能开工。

新人打捞教程

3，狂怒挂机刷怪+卖远征

- 狂怒挂机刷怪也是非常安逸的一种收入模式，你可以一边看电影一边挂机赚钱，收入不算太高，但不用看着，技能要求也低。如果出了远征还能卖钱，00远征这个阶段不推荐你自己去打。

- 狂怒摆烂生产指南（古斯塔斯区限定）

- _**推荐一种10/10交易流程和具体操作**_

4，欧塔虫洞挖气云

- 欧塔周边3跳固定刷新虫洞，准备个回盾幼龙，把怪清了以后就可以慢慢用冲锋挂机挖，半个小时看一次。成本极低，极其安逸，收入也不错。气云军团和联盟都包收购，出货方法看低安频道置顶信息。

- 虫洞气云攻略v0.3.11

5，4-H周边行星开发

非常安逸，可以和其他活动同步进行。基本上1-2个星期收一次菜，直接4-H市场卖掉，就是不少钱，尤其对新号而言。

行星开发的教程很多，看主目录下的教程集，选择适合自己的方案

6，背面号/小号势力战争绕杠子

需要一定脑力，不过基本上不管怎么玩都是赚钱，比较有挑战性，但收入也很高，技能点要求也不高。

- (视频) EVE新人快速赚钱之绕杆子教程

**不推荐：高安任务，高安挖矿，扫描破解和考古信号**

**高安任务在这个版本收入过低，尤其对于新号而言，爆船风险巨大效率极低，打着玩玩可以，别指望赚钱。**

**在欧服，新号高安挖矿就是自找没趣，不但收入低，还有极大概率被强暴。**

**破解和扫描信号除了00和虫洞的一部分以外，收入都非常低，完全划不来。**

- 第二篇，稍微有点经验以后

- 1，X-70，ROIR星系姐妹会任务+燃烧

- 需要有一定生存经验，但收入肯定比刷怪多很多。这是军团的主力生产模式的铺垫，姐妹会LP有专人收购，具体看黑渊任务频道置顶，也可以自己出货。

- 具体攻略比较多，请看主目录下的低安任务攻略。

- 2，欧塔萨塞C海军5级任务

- 五级任务需要刷比较长时间的声望，在你开始五级前，强烈建议你先去刷姐妹会任务，把声望刷到6，再开始C海军，这样你可以拥有双正高声望。

- 3，5ZXX莫德团4级任务+燃烧

- 同上，建议你先刷姐妹会，刷到高势力声望以后再刷莫德团。莫得团的声望和C海军挂钩，所以不管你刷哪个，先把姐妹会声望刷够。因为刷姐妹会声望会扣C海军声望，但刷C海军声望不会扣姐妹会声望，这个逻辑你想想看。

- 4，跟随矿队挖矿

- 不推荐新人挖矿，收入低且不稳定

- 5，毒蜥、伊斯塔刷4级深渊

- 需要动点脑子，不过如果你能在深渊上有所发展，收益效率将大大高于上述其他路线。

- 高级深渊生产指北

- 深渊没有那么危险——深渊致富大型指北（伊什塔视角）

- 6，00扫描破解，打远征和死亡

- 三体公司的号是不能随意打死亡和扫描信号的，只能打远征，想打死亡需要加入伏羲主团。

- 你需要仔细看攻略，和老手确认你的配置正确，否则必死。

- 具体攻略比较多，请看主目录下的扫描和死亡攻略。

- 7，三神空间捡垃圾+打捞

- 这是一个PVP和竞争性非常强的地方，但收入也挺不错，有时会爆发。某次两队人马混战，我一个促进偷偷摸摸捡了20亿垃圾。

- 故土三神空间萌新打捞
