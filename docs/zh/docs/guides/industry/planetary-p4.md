序言

各位朋友们好，本手册作为Jan Zhang所著《FRT种菜萌新指南》的补充，将着重关注种菜的进阶玩法——行星工厂，也就是通过合成采集自不同行星的低阶产物来制造P2到P4级别的产品。不同于依赖于资源浓度和分布的P1产物，高阶的行星产物更加依赖对于生产的总体规划，并且这类产物将直接参与到POS（玩家建筑）、旗舰以及各种高级脑插等配件的生产之中。

鉴于《萌新指南》已经涵盖了许多行星生产的基础知识，本手册假设所有的读者都已经对行星生产有一个最基本的认识，故不再对一些诸如如何架设指挥中心、设置传送带和进/出口产物之类的基础操作进行解释。熟悉种菜但又对行星生产比较陌生的朋友们不用担心，笔者会在手册的各个部分强调生产和种菜在核心思路方面的不同，以帮助大家顺利过渡到生产思维中。

本手册的部分章节借鉴《萌新指南》但是对整体结构做出了较大改动。在序言之后，笔者以实例和概念结合的方式将行星工厂的规划分解成**选址-定标-布局**三个主要部分。由于不同的P4有很多种组合方式，而组成它们的P2和P3又有自己的排列组合，一本手册不可能穷尽，所以本手册中涉及的概念部分更多是一种方法论的体现。其主要目的不是让读者直接照搬开始生产，而是拥有根据自己的需求设计不同组合方式的能力。

在实例方面，笔者将以广播节点（Broadcast Node）这一组合相对复杂、价值极高并且需求广泛的P4进行演示。一旦掌握了广播节点的生产规划，其他的P4以及更加简单的P3也能兼容。需要重复的一点是，仅笔者本人就基于不同情况尝试过三种广播节点的生产规划，本手册中使用的排布并不是最优解，只是基于某种需求或某些限制条件的最合适解。

聊完规划，就应该聊一聊收益。再次以实例中的P4广播节点生产为例，笔者将对不同情况下的投入和收益进行解析。**简单来说，按照本手册的思路，3个角色的O号可以达到每天操作60-90分钟，收入115-270M的地步**。值得一提的是，由于P4的生产基础是体量大但成本又低的P1，本章节中还会涉及许多与市场相关的技巧和信息。笔者希望能够通过分享这些知识帮助读者们以更加低廉和高效的方式获取生产P4所需的基本材料。

最后，笔者会结合自身的经验给出一些能够更进一步提升生产效率或者保障安全的技巧，这些内容十分主观、并且完全不是必需的，希望读者们能够以讨论和批判的眼光看待这一最后的章节。

话不多说，让我们进入正题。

如何选择生产地点

序言中提到过，行星工厂指的是通过输入低阶行星产物（P1和P2）来制造P3以及P4级别产物的PVE生产活动。与EVE中的传统制造业不同，P3和P4的生产蓝图完全是工厂节点自带、并且可以随时改变的，在输入材料充足的情况下其时间和材料效率也是固定的，并不会因为研究或者技能的提高而提高。

在与工业制造区分开来的同时，行星工厂与它的兄弟行星开采（即种菜）也有着本质上的区别。虽然二者使用的都是PI（Planetary Interaction）的基本框架和UI、发生地也都是在每个星系的诸多行星之上，但是它们背后的逻辑和最终形成的布局却相去甚远，让我们来看一张图。

![image1](/images/planetary-p4/image1.webp)

上图是笔者在欧塔萨塞IV行星上建立的P2至P4生产基地，相比《萌新指南》中看到的P1开采基地，其最大的不同就是完全没有采集器和钻头的存在，PG（能量栅格/Powergrid）和CPU的消耗完全来自于各级工厂、发射台和仓库。除了建筑本身的选择，没有采集器就意味着这一基地的产出完全与行星资源浓度脱钩，这就引出了行星工厂和行星开采的第一大不同，即：**工厂行星的选择与资源浓度无关，并且不与在同行星上进行开采的其他角色或玩家产生任何冲突。**

既然与资源浓度和损耗无关，细心的朋友们可能就会问了，那岂不是在任意行星上都能建立行星工厂？这句话本身没错，但是行星的选择依然会很大程度上影响工厂的规划和效率。首先，生产P4所用到的高科技工厂（High-tech Production Plant）只能在贫瘠（Barren）和温和（Temperate）两种行星上建造。考虑到温和行星较少，并且其出产的P1价值更高，贫瘠行星便成了工厂行星的最佳选择。其次，由于我们需要在每颗行星上设置尽可能多的工厂，所以为了节省资源我们需要尽可能地缩短节点与节点之间的链接长度。基于这两点的补充，选择工厂行星的第一准则便呼之欲出了：

- **小而贫**

熟悉种菜或者天文的朋友们可能知道，行星后面跟的数字越小、越靠近恒星、其表面积也就越小（欧塔I比欧塔II小，II比III小，依此类推）。回看欧塔本地，你就会惊讶地发现其实欧塔萨塞是个十分合适铺设行星工厂的地方，因为其最小的四个行星都是能够放P4工厂的贫瘠行星，可谓天时地利。

其实欧塔萨塞的各个行星除了大小和性质俱佳，还有不少优势，其中之一就是海关税率低。众所周知，行星开采的P1产出最后是通过发射到海关收进菜船中的，而海关要在这个过程中收取一定比例的税金。行星工厂也是如此，更是会**受到税率的双倍影响**。原因很简单，当我们通过海关输入P1等基础材料的时候，海关也会按税率收取“进口税”，这一进一出便是两轮税收。基于双重收税、并且P4价值高的特点，税率高于或等于5%的行星（说的就是你，M-O）一般不建议作为行星生产的基地。那我们选择工厂行星的第二条准则便出现了：

- **低税金**

在上一段中，笔者已经提到了P4产物价值高的这一特点。其实相比P1，P4以及作为其主要组件的P2和P3不仅单件价值更高，每个工厂每小时内产出的体积也更加小。这两点综合起来就会为我们的日常运输安全带来一定的影响。举个例子，一个最便宜的P4纳米工厂（Nano-factory）的体积是100立方，它的Jitabuy价值是同体积生物燃料(biofuels，最便宜的P1)的17倍。除了P4本身的价值，由于其生产流程复杂，并且需要输入原材料，星城之类能够进行角色间物资交换的建筑就显得尤为重要。所以本手册建议所有的P4生产都不要包含过门这一举动，生产出来的P4也应该在本地建筑进行制造消化或者交由专业的快递员进行运输。换句话说，选择工厂行星的最后一条准则便是：

- **过门零**

综合以上三点准则，为工厂行星进行选址的时候，应该尽量选择**体积较小的贫瘠行星，**海关的税率也是**越低越好，**并且星系内就有星城等可以进行制造、挂靠或者快递的建筑，**过门的需要为零, **即：

**小而贫，低税金，过门零。**

如何确定制造目标

由于生产P4的复杂性，笔者并不建议一时兴起进行生产，而是在有一个清晰的目标以后开始生产。那么P4的生产无非就是两个目的：为后续的制造提供组件或者贩卖P4挣ISK。考虑到《萌新手册》更偏向后者，本手册就以**生产可以赚ISK的P4**为目标进行生产规划的演示。

制定了挣ISK的大方向以后，我们应该先对自己愿意付出的投入进行一个粗略的计算。其实单看投入，行星生产跟EVE其他可以独立完成的PVE活动十分接近，无非是投入ISK、原料、时间和精力，而这些资源又分固定投入与变动投入[footnoteRef:1]。然而，行星生产也有属于它自身、相对特殊的限制条件。

| 投入 | 限制 | 产出 |

| --- | --- | --- |

| ISK（固定与变动） | 运输与仓储体积（变动） | ISK（出售P4） |

| P1/P2/P3 | 行星PG与CPU（固定） | 组件（用以后续制造） |

| 时间（固定与变动） | 行星数量（固定） | |

| 精力（固定与变动） | | |

首先，每个Omega账号可以有三个角色，而每个角色可以同时运营的行星数量是有限的。技能点满的情况下为六个，一般菜农都是4级行星统筹管理学，也就是一个角色同时运营五个行星、一个账号十五个行星。除此之外，每个行星的指挥中心根据等级又对PG和CPU有一个限制。前者和蓝图研究等制造行业的11条线多少有些类似，而后者又像是在配船时碰到的资源分配问题。除了这些固定条件的限制，行星生产的日常运营又在受到运输和仓储的体积限制的同时需要进行经常的搬运，也就是《萌新手册》中提到的菜船容量、海关容量和发射台/仓库容量。

**那么问题就来了，面对如此纷繁的投入选项和限制条件，我们该如何制定适合自己的目标呢？**

笔者认为，投入方面应该根据现有的资源**量身定做**，而在限制条件之下的权衡问题则应该依赖通用的经验和法则进行应对。本章节的重点在第一个部分，平衡各种资源将是下一个章节——**权衡**——的核心内容。

还是跟着上文的思路，这里假设读者是一位初入EVE、有行星采集经验以及学习热情的萌新。虽说无论是老炮还是萌新都希望能够以少量的投入换取大量的产出，但是萌新可以接受的投入和老炮们是不一样的。相信很多萌新都有这样的感触，感觉很多精彩的活动不是没船就是没技能，然后钱包里的ISK攒不了几亿就花在了新船或者脑浆上。笔者本人也是萌新的一员，深知我们并不介意多付出一点时间和精力，但是却没有办法调动大量的ISK资源。

这样一想，我们的投资策略就呼之欲出了：**以时间和精力的投入换取更高的回报率，尽可能减少被束缚住的资金的同时不放弃产出。**

**为了找到回报率较高的P4产品，我们需要借助一个强大的工具——Adam4eve.eu。**

在上图的设置中，第1栏修改的是海关和市场的税率。虽然欧塔的各个海关都是0.1%的税率，但是adam4eve网站只能使用整数（0或1）。在这里，笔者采用1%的税率为其他费用提供一点缓冲利润。市场税是一个很复杂的机制，销售税、代理人费和改单费都有不同的计算方式。笔者在这里不进行详细的计算，简单来说，在皮米进行挂买单收原材料只需要1%的代理人费；在吉他砸单卖P4需要支付2.25% (5级会计)-5% （0级会计）的销售税，挂卖单需要在其基础上再加3%（加达里共和国声望0，海军声望10，代理人关系学5级）-5%（加达里共和国声望0，海军声望0，代理人关系学0级）的代理人费用。由于我们选择在皮米挂买单收原料、在吉他挂单/砸单卖P4，新人建议选择1%海关税+5%市场税的组合，而有一定贸易技能基础的可以选择1%海关税+3%市场税的组合。

如何布局工厂行星

OK，目前我们已经对工厂行星的选址、目标产物和生产链的选择进行了讨论，接下来的一步就是行星建筑的具体规划。对于仅仅接触过行星采集的读者来说，这一步貌似比较简单，只要在选好资源热点的情况下无脑塞满P1加工厂即可。然而，对于P4的生产来说这种堆砌的方式反而会降低效率。举个例子，对于任何P4-9-4来说，从P1开始的完整生产链需要30个高级工厂Advanced Industry Facility和1个高科技工厂Hi-tech Industry Facility，光这些就需要消耗总计21400MW的PG，这是一个连5级指挥中心都无法供应的PG量。接下来笔者将详细讲述如何调整生产链和布局，想要先上手的朋友们可以跳过这2页直接看布局和运输方法。

面对这一问题，我们需要对复杂的生产链进行**产量或者分段切割。**

所谓**产量切割**，就是把原先计划放在同一行星上的30个高级工厂一分为二（生产P4的1个高科技工厂不动），以生产效率减半的代价达成仅仅依靠15个高级工厂便能单星球生产P4的目的。在这种情况下，欧塔的4个贫瘠星球每小时能够生产2个广播节点，如果将欧塔5生产的P3运出来加入某个行星的P4生产，那么每小时就能够生产2.5个广播节点。

**分段切割**就是把P1→P2→P3→P4这个比较长的链条分段，将其中的一个步骤与其他部分分开放置在一个行星上。首先，我们知道每生产一轮的P4需要2-3种P3工厂同时生产两轮原料，也就是说如果需要时时满足P4制造所需的原料，P3工厂的数量应该是P4工厂的2*2=4倍(P4-7-4)或2*3=6倍(P4-9-4和p4-9-6)。同理，P2工厂的数量也是P3工厂的4倍（P4-7-4和P4-9-4）或6倍(P4-9-6)。对于广播节点来说，前者的比例是6倍，后者的比例是4倍，也就是说那30个高级工厂由6个P3和24个P2工厂组成。**那分段切割在这种情况下就是把P2的生产单独拿出来放在几个行星上，然后将成品P2统一运到某一个行星上进行综合的P4加工。**

![image9](/images/planetary-p4/image9.webp)

进阶技巧

- **遇到危险就把菜放到海关里**：和行星采集一样，行星生产是几乎没有风险的一项PVE活动，唯一会遭遇敌人的地方就在海关附近，然而你只要没有离开海关2500M的范围就可以轻松地将菜船里面值钱的产出（比如刚生产完的P4）放在海关里。假设敌人这个时候打爆你的船，就算海关的35000方塞不下所有的东西，你也只会损失价值较低的P1或者P2。在菜船上装上1-2个结构抗和2点反，你甚至可以反杀一波。

- **善用发射台和高科技工厂平衡CPU：**在大多数情况下，每个行星的指挥中心都是多CPU缺PG，这时候我们可以考虑使用高科技工厂和发射台来消耗CPU。前者可以作为替换P2/P3生产链的关键选项，后者可以梳理生产思路（比如将输入和产出放在不同发射平台里面）并且提供1W方的储存空间。

- **多多留意各个生产阶段对应产物的体积：**在强调效率的行星生产过程中，一次性完成所有行星的原料补充/产出收集就意味着节约很多时间，尤其是在菜船无论怎么配置都不太灵活的大前提下。虽然从P1到P4大多数情况下都是产物体积逐渐变小，但是P4-7-4却比输入的P3体积更大，这时候就需要我们多多关注运输体积。举个例子，4级的盖伦特工业舰技能（菜船63000方）意味着72个广播节点和72个无菌导管的原材料可以从星城一波运完，这样就比跑两趟效率更高，风险也更低。

- **PI小号不一定需要4级指挥中心和统筹管理：**这一点冬夜和阿蕉都提到过，但是笔者直到最近才清晰地认识到：虽然合作社这两个技能双4级，但是小号可以选择在欧塔I-IV以双3级技能的基础运营4条12个广播节点/天的完整P1-P4生产线（即产量切割），这也就意味着三个几万技能的小号角色加起来就可以一天生产144个P4，按照500K/个的盈利，72M/天的收入不仅挣出了月卡钱，还能养猪抽脑浆。

- **不同生产链的组合会给予玩家更多的灵活性：**虽然将所有行星资源集中以一种方式制造一种P4听起来更加方便管理，但是这也就意味着把所有的鸡蛋都放在了一个笼子里。如果说这一个笼子是复杂的P1-P4生产链，修改它将会需要消耗很多的时间和精力，而P4价格的浮动又导致我们有时需要修改生产链以追求更高的利润。P1-P4和P2-P4的组合意味着当其中的某一项收益变低的时候可以通过一定的调整及时改变行星生产的产品。

- **所有行星的布局都应该在满足基本功能的同时以捋清思路为目的：**从上文的截图中已经看出，行星生产的制造链比起采集要复杂很多，PI角色数量和生产的P4种类一多更是容易让人头昏脑涨。这时候如果每个球的布局能够达到一目了然的地步，那么无论是初始的线路设置还是后续的调整策略都会方便很多。

- **了解市场将会极大地放大行星生产的收益：**从上文中提到的两种每日收益的区别可以看出，贸易相关的技能和知识能够大幅影响菜农的收入，所以说笔者鼓励新人们去学习一下市场规律、了解一下贸易技能都有什么用并且熟练掌握市场数据折线图中各个图标的含义。在萌新阶段，因为PVE活动收益普通，所以说拿出几个小时来学习市场能够省下的ISK或许比多刷一点怪收益更好。考虑到FRTU的新人有相当一部分收入来自于出售LP，学习市场相关的知识也能够直接地提升LP兑换的比例。

- **工具很好用，理解算法更重要：**本手册中推荐了的Adam4eve是十分强大的一款工具，但是它有着自己的算法，它的结果可能跟表面上看起来的有些不一样，我们需要保持清醒的头脑，时刻注意哪些数据可能因为算法的不同会出现偏差。
