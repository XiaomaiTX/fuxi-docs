# 探索与活动

本板块收集星际探险与游戏活动的攻略，主要涵盖俗称**挖坟**的空间信号扫描，各类版本活动的玩法与归档，以及对游戏背景剧情故事与相关任务的攻略和汇总。

## 主要方向

- **空间信号**：扫描与破解遗迹、数据地点，获取蓝图、材料与稀有道具。
- **虫洞指南**：虫洞的探测、生存与机制介绍。
- **特殊任务**：关于游戏背景故事、空间代理人和史诗任务等攻略与介绍。
- **版本活动**：周期性活动（如冰雪节、血色收割等），以及随版本更新的活动教程与归档。
