# 三神裔空间入门

> 来源：<https://docs.qq.com/doc/DQmtHQXRsaU5vcm9y>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 术语对照
官方名称：**波赫文（Pochven）**；中文社区常称「三神故土」「三神空间」。进出主要靠纤维（Filament）与虫洞通道，单向纤维会随机落到区域内的某个星系。
:::

原作者: Rallfall yukikaze

由于原来与帝国区之间相连的星门已经全部关闭，目前这些空间只能通过虫洞或者特殊的纤维进入。

![image1](/images/triglavian-space-intro/image1.webp)

（原来的星门已经被奇奇怪怪的东西塞满了）

原来星系内的空间站也被三神裔所占领，同时这些空间站的服务同样需要一定的声望值才能使用：-0.05以上停靠；1.0以上可以进行舰船装配；2.0以上可以在空间站维修舰船；3.0以上可以使用克隆仓和提炼工厂；4.0以上可以使用工业。当然，玩家建筑的服务如挂靠等不受三神裔声望影响。

![故土地图和三神势力划分](/images/triglavian-space-intro/image2.webp)

_故土地图和三神势力划分_

目前三神裔空间里存在五种NPC，分别为：三神裔，Edencom，流浪者，冬眠者，自由无人机。这些NPC之间会相互进行战斗，玩家可以选择帮助或者袖手旁观，其中自由无人机和冬眠者还有流浪者对于玩家永远是为红色（敌对），三神裔和Edencom则会因为声望的不同对蛋人为蓝色（友军）或红色或者是白色（中立），蓝色和白色时NPC都不会主动攻击你，但是如果你主动攻击的话，不管是蓝色声望还是白色声望，NPC均会进行反击（直接拉红开干）。NPC有时候会主动攻击与自己敌对声望的玩家建筑。还有，一定要注意，三神裔空间内所有的敌对NPC都是会捏蛋的哦。

![图为一小股三神裔巡逻舰队 PH铁壁正在被流浪者舰队攻击](/images/triglavian-space-intro/image4.webp)

_图为一小股三神裔巡逻舰队 PH铁壁正在被流浪者舰队攻击_

这些NPC之间会进行战斗，这些战斗通常位于星门，海关，恒星0m，异常或者是玩家建筑，战斗过程中产生的残骸可以被打捞，里面也会有掉落，根据NPC的不同，掉落也会有不同。三神裔掉落三神裔调查数据库（小红书）装备突变体，各种收藏品；冬眠者会掉落蓝牌子和安提特拉元素；Edencom联合防御阵线会掉落势力弹药和一些衍生装备；自由无人机会掉落Interstellar Navigation logs和一种特殊的芯片。注意的是这四种NPC的loot中均可能掉落不等数量的Interstellar Navigation logs（我称为三神裔牌子）。你甚至可以不用自己去打，看着NPC互掐，等他们打完再跳下去捡loot。平时多开截击转一转，就能捡不少。

![图为三神裔，Edencom，自由无人机，流浪者，冬眠者在星门五方混战](/images/triglavian-space-intro/image5.webp)

_图为三神裔，Edencom，自由无人机，流浪者，冬眠者在星门五方混战_

玩家可利用捡到的Interstellar Navigation logs在空间站中的三神裔忠诚点商店兑换各种三神裔道具，如舰船蓝图，技能书等

关于生产和驻扎问题，昨天我和几个小伙伴也在星系内刷了怪，如果有人对阿三星系刷怪感兴趣的话我会在下个帖子放出配置和介绍打法，目前收益为止，但是如果你刷怪阿三会给你赏金isk，大概是一跳60m。三神裔空间内所有的残骸打捞产出均为三神裔T2制造组件，牌子价格目前也不明朗，不过目前大致比例应该为1：30000。

进入三神裔空间的虫洞会刷新到新伊甸的00星域和虫洞星域，目前我摸清楚的规律是：

1.通往三神裔空间的虫洞大概率会刷新在固定刷新流浪洞的星系，所以说三神裔虫洞的刷新星系是比较确定的。

2.虫洞质量均为大洞且为1B kg。

3.在10月27日的更新后，现在你可以直接跳洞口0m而不是90km。

4.本地刷新虫洞的时候会出现三神裔巡逻舰队，你会在星门，玩家建筑或者流浪洞信标上见到他们。

5.三神裔星系通往00的洞口会固定刷无人机NPC，通往C5/C6的虫洞会固定刷冬眠者NPC。可以根据这一规律来刷怪。

6.通往三神裔空间的虫洞口会有三神裔舰队防守，务必注意自己的声望。

7.洞口的NPC是无限刷新的，所以不要妄想把怪打光。

值得注意的一点是，即使把洞压了，依旧会无限刷怪，信号也会消失，可以利用这一点来刷怪。

![图为一个通往00的洞，洞口一大堆无人机怪](/images/triglavian-space-intro/image8.webp)

_图为一个通往00的洞，洞口一大堆无人机怪_

目前星系内会随机刷新出这几种异常：

1.星际舰队集结点：NPC为三神裔开采舰队，有时候流浪者，Edencom，自由无人机等NPC会进入这个异常与三神裔舰队进行交战。

2.观测站闪点：NPC为Edencom，打完可以获得2.5B赏金和一次开箱机会，箱子中可能开出泽尼塔级蓝图。

3.矿异常：目前矿异常分为三种，具体区别由于我没有去扫矿，所以也不是很清楚。

4.世界方舟攻击点：里面会有一条世界方舟等着你。

5.战斗异常：和高安一样的战斗异常，比如古斯塔斯藏身处等。

目前三神裔星系内的所有未知信号均为虫洞信号。

![image10](/images/triglavian-space-intro/image10.webp)

由于版本更新之后CCP修复了拆无人机建筑获得三神裔声望，并且在10月27日的更新中，CCP选择重置目前玩家的声望。现在简单获得三神裔声望的方法为，在三神裔星系内，找到NPC交战的地区，摸一下正在与三神裔交战的NPC，直接跳走，等10分钟就可以获得声望。目前无人机NPC可获得的声望为0.005~0.01，流浪者NPC为0.04~0.064。声望的涨幅和你击杀的NPC类型有关，如击杀战列会获得更多的声望。

目前CCP显著提升了进入故土的纤维的爆率，所以以后可以通过纤维进出故土。
