虫洞基础知识

虫洞无处不在，但又不是那么容易就出现在你的眼前，在不理解虫洞的人眼里，虫洞通常是“危险”、“神秘”的代名词，很多人会好奇虫洞到底是什么，在研读过贴吧许多关于虫洞机制介绍的精品贴后，结合自身实际，我用最容易理解的说法向大家解释一下。

你可以将虫洞理解为一个星图之外的世界，我们称它为“虫洞世界”。它与外界同样存在着：星域、星座、恒星系。每一个虫洞都是一个恒星系。这个时候你肯定会问虫洞明明左上角是一堆乱七八糟的数字，怎么可能是恒星系呢？不要着急，下面我将为你解开这些数字的奥秘：

![image1](/images/wormhole-production/image1.webp)

很明显右边的红字代表安等，所有虫洞的安等都是-1.0。左边的白字代表了该虫洞的编号，每一个虫洞都有着唯一的编号，就如同RF-X7V，jita这些名字，所有虫洞的名字都是J开头。其中J0开头的洞为破碎洞。接下来我们点开它：

![image2](/images/wormhole-production/image2.webp)

一个详细的恒星系介绍出来了，他的星域是D-R00016，星系是D-C00154，恒星系就是J133458。

与外界不同的是，你无法直观的看到你所在的星域和星系，只能以编号来确认，即使相同星系的虫洞也不一定会相连在一起，反而连接到其他星域星系更为常见。当然，虫洞不仅连接着其他“虫洞世界”的恒星系，也连接着现有世界的恒星系。

接下来我们讲讲洞的级数。虫洞共分六级，一二三四五六等级依次上升，与此同时，洞里洞口的大小、洞内的资源都逐级提升。我们用CX称呼洞口，X即是洞的等级，比如六级洞称为C6。那么如何辨认虫洞的等级呢？我们还是点开左上角的虫洞编号，看到它的星域星系。

![image3](/images/wormhole-production/image3.webp)

依旧是J133458，他的星系和星域是D-开头的，这说明它是一个 四级洞 。ABCDEF分别对应一二三四五六级虫洞，G代表了一个最特殊的虫洞： 希拉洞 。还有一种方式是通过洞口的信息来确定，我们就接下去介绍洞口。

虫洞口即是虫洞世界的星门，它很多特殊的地方。首先它既连接现实世界，也连接虫洞世界。打个比方，你在一个虫洞，他可能有两个虫洞口，一个连接着另一个虫洞，另一个连接着jita。其次，它有着自身的属性。我们打开一个虫洞口，通常可以看到以下文字：

![image4](/images/wormhole-production/image4.webp)

上方是这个虫洞口的编号：R474，它的含义是这是一个二级洞通向六级洞。虫洞口的编号 不是唯一 的，相同情况的洞口都会是这个编号。

![image5](/images/wormhole-production/image5.webp)

粗体为永联虫洞，斜体为漫游洞。

这张图可以很好地解释虫洞口编号。有一种特殊的编号叫K162,你可以这么理解，你所在的洞口开了一个通往别的地方的洞口，那么对面看这个洞口的编号就是K162，对面无法从这个虫洞的洞口编号得到任何信息。

接下来是描述。首先第一段文字你就当他放屁，没有任何意义。

![image6](/images/wormhole-production/image6.webp)

这一句话代表了虫洞口的对面是什么。未知领域指的是一~三级洞，危险的未知领域是四、五级洞，致命的未知领域则是六级洞。通往现实世界的洞口则会明确地告诉你通往高安、低安、00区域。所以我们也可以通过洞口大致分辨对面是什么洞。

虫洞是有 寿命 的星门。

![image7](/images/wormhole-production/image7.webp)

描述文本出现大于一天说明它真的大于一天。描述文本出现撑不了一天说明还剩下4~24小时的时间。即将到达生命周期的终点则是小于四小时，化为乌有是最后的15分钟。通常我们不会见到大于一天或者化为乌有，当虫洞到达时间时，它会坍塌。当然它即使不到达寿命时间也会坍塌，因为它还有 质量 的要求。

![image8](/images/wormhole-production/image8.webp)

质量文本共有三种，未受到影响是可通过质量大于50%，尚未达到严重程度是10%—50%，即将崩塌则是10%。不同大小的虫洞有不同的 通过质量 ，这个通过质量会有10%的浮动。

![image9](/images/wormhole-production/image9.webp)

虫洞口的口子大小分为超大型、大型、中型、最小型。虫洞口的通过质量分为 单次通过质量 和 通过质量总量 ，单次通过质量限制了你的船型，通过质量总量则是虫洞寿命的另一指标。洞的大小会影响这两个因素。普遍来讲，超大型可以通过旗舰（除超级旗舰）以下的舰船，大型则是战列、中型巡洋、小型驱逐护卫。当然也有例外，大白的质量近似于巡洋，所以可以通过中型洞。比如常见的大洞，超过3E的质量就无法通过。你可以这么理解，你的体型决定了你能钻进什么样的洞，这个洞如果被太多的人钻过会死掉，不管他是不是到了快死的年纪。

洞口不同于星门，当你处于开火倒计时的时候，你仍旧可以过洞，但一个洞口在短期内（五分钟）只能够通过两次，即一个来回，这被称为 极化 。另外过洞会有巨大的声响，所以不听命令过洞的，当什么处理不用我多说了吧XD

OK，洞口的要素介绍完毕，接下来介绍洞的特殊之处。

虫洞，也就是恒星系，你无法在总览看见远处的虫洞口。也就是说如果你没有做洞口标记的习惯，当你跃迁远离洞口时，你总览里的洞口会消失，再想回到你来的地方，不好意思，请扫描洞内的信号。无数单枪匹马不带核心扫描探针进入虫洞的朋友们都会吃到这个教训，“宝船赠与有缘人”的梗也由此而出。总览被蒙蔽的同时你的本地也会进入黑灯状态，只要没有人说话它永远是漆黑一片，当有人在本地发言时，他的名字会出现在本地，并在他发言完毕五分钟后消失。因此虫洞本地打字是大忌讳，很有可能因为你的一句话，你的舰队将损失目标，甚至可能成为目标！

虫洞通常会有 永联 这个概念。什么意思？就是说比如一个洞是五级永联六级，那么当一个通往六级洞的洞口坍塌的时候，五级洞里会生成另外一个洞口通往另外一个六级洞，塌掉一个生一个塌掉一个生一个，子子孙孙无穷尽也，这就叫做永联。OK这里介绍一种永联洞的黑话。123456依旧代表同级洞，7代表高安，8代表低安，9代表00,10代表希拉但是没有人永联希拉。那么我们就可以解释很多名词，如425，本洞四级洞，永联2级洞和5级洞。除了永联也会有随机的口子出现，也就是K162，这是别的地方生成了通向本洞的虫洞口的标志。还有一种漫游洞，它的产生完全随机，连接的星系也完全随机。

虫洞有 天象 的概念，在拥有天象的洞内会有永久BUFF和DEBUFF，比如生产队梦寐以求的磁星洞，就有武器伤害加成等BUFF和DEBUFF，天象强度随洞的级数增强。

此外还有破碎洞，它是NPC打架打爆所有行星的洞，所有的行星都叫做破碎，而且它本身也很“破碎”，会有非常多的虫洞信号，通常是“交通洞”。

虫洞生产

虫洞内的收益按虫洞等级逐级提升，一级虫洞几乎只能成为行星生产的洞，低级洞的异常收益都并不理想，好在有可爱的虫洞坟可以提供客观的收入。我们居住的269虫洞永联6级虫洞，因此我们主要介绍六级洞的生产方式。

居住在虫洞异常里的是 冬眠者 ，他们是全宇宙最顶的异常怪：反跳、网子、毁电，还有非常高的DPS。当然高风险永远伴随着高收益，这些冬眠者提款机会爆出他们的数据节点等奇怪的打捞件，这些打捞件体积小价值高，有固定的的NPC会收购，因此价格稳定。我们在洞里的所有受益都来自于这些打捞件，毕竟冬眠者不是海盗筒子部没法给你发赏金。

我们在虫洞中生产的方式是集体生产，配置是三神裔的战列舰勒沙克和姐妹会战列舰大白涅斯托，偶尔会有甲加成船。由勒沙克提供火力，大白提供奶量，加成船保证容错率。这些舰船所需要的最低技能，请在联盟论坛https://forums.winterco.org/t/topic/4873里查看。如果你不会用联盟论坛，“找你的公司管理或者换一个公司。”

你的技能与你的收益息息相关，所以请不要偷工减料。LSK请把你的大型先驱者武器研究升级到V，T2弹药对你的收益提升是非常大的。大白请保证的你的装甲技能和船体硬度尽可能地高，因为根据经验冬眠者往往喜欢先欺负大白驾驶员，一个不留神死了的话可是没有补损的。我们的单开收益是1.5E每小时起步，只要每一个人都认真完成自己的任务，上到单号2.5E是非常轻松的。双开轻松超大航。

在生产前，你的大白应该带上无人机，LSK要准备好转速和射程脚本。所有生产船只肚子里应该带上移动式仓库、一大坨跃迁稳定器，扫描探针发射器和探针（T1即可）和一定数量的噪声纤维。

虫洞收益采用平分的方式结算。

准备阶段

当你加入我们的qq群后，请关注群的消息。生产队起队后会有生产FC@全体，并公开舰队，舰队名一般为FRT虫洞社区之类的，请根据你的生产船加入对应的中队。

虫洞异常与外面的异常不同。每一个被清掉的异常会在同星系的其他虫洞产生。我们需要做一些准备工作来让我们的生产顺利进行。

压洞

准备好你的压洞战列和补刀重拦，更换白蛋。在有经验的FC指挥下进行压洞，一般你需要做的操作是开推/不开推来回虫洞。如果发生洞难了，请听FC的指示回归本洞。

压洞战列改装件上粒子锚，中槽带500推，低槽视情况带钢板。

压洞巡洋粒子锚500推。更高级的压洞重拦要带上零点，重拦并不要求每个人都有，但能够开重拦的朋友也请准备准备。

最新消息，入洞不带扫描船和压洞战列会被查ESI赶出去！

扫洞

第二步骤是扫洞。在洞里你必须掌握扫描的技巧，并不需要很高的技能，能扫出信号即可。

首先我们需要扫出本洞的C6信号，然后跃迁到虫洞口按规定保存虫洞的信号点。然后过洞保存回洞点“回”。接着用爱神虫洞该虫洞编号，可以得知这个虫洞永联的洞口和可能有的虫洞口信号。注意，由于会有其他地方连接到这个C6洞的K162存在，所以爱神虫洞除了永联洞口的情报以外，其他洞口情报都不靠谱，我们还是需要合作扫描出这个C6的所有虫洞信号并明确他们通向何处。向FC汇报洞内的异常数量。

当你对虫洞口和虫洞等级有一定了解后，你可以根据爱神虫洞的永联信息一直找到高安口、帝国口，但这不是当前要做的事情。

在扫出所有虫洞信号后，我们应该勘探所有C6和他所连接的洞洞内的建筑，确认是否有活人存在，确认是否对生产有威胁，最后由FC确认是在本C6洞刷还是塌洞更换C6洞。

做点

为什么要做点？

因为他狗的CCP把异常点做在离怪几十千米的地方，战列慢悠悠的速度需要爬很长时间。为了节省时间成本，我们需要把生产点做到一个合适的地方。

C6共有4种异常：核心堡垒、核心基地、明镜、读数。

堡垒、基地、读数的生产点都在最中心圆盘正上方5000M的点（保证不卡建筑），明镜则是在六边形镂空圆盘正中。

做点的方法非常简单：开上你的 蛋 或者 微风级 。跳异常点，保存生产点附近的一个建筑位标到自己的文件夹，接着进行折返跳，跳到保存的建筑旁，用Q键移动大法移动自己到生产点，保存位标到生产点文件夹，这个点就完成了。

![image12](/images/wormhole-production/image12.webp)

如果你实在不会，在做点的时候在mumble询问，会有人手把手教给你。

准备完成

回到铁壁登上你的生产船，听FC的指令出站检查人数，随后FC会带跳至C6洞口。确认你的 钢板全部下线 后听FC指令过洞。所有人过洞后FC会带跳至安全点，此时接近你附近的大白2500内，上线你的钢板，打开你的主动抗性装备和辅助装备，等待FC带跳异常点。

生产过程中FC会发一封邮件到邮件列表：FRTWHD SELLS，这一封邮件会包含本次生产所有人员的名字，请打开它确认你的名字是否在上。每一次人员变动都会有一封邮件，最后分赃的时候是按照邮件上的名字平均分配的。

舰载扫描

前文提到过，虫洞内的本地属于黑灯状态，因此只有Dscan能够让你知道你14.3AU以内是不是安全的！所以在虫洞 永远不要停止Dscan ！每三秒一次的Dscan在任何时间，只要你身在虫洞就一定不要停止！Dscan就是你的命，将命运牢牢掌握在自己手中才是最重要的。养成这个好习惯可以让你有更充裕的时间决定逃跑或是反打。

Tips：生产过程中通常会有小机灵鬼开一些奇怪的船或者蛋来吓唬你，请一定一定一定不要停止Dscan！即使是一个蛋，对生产队的打击也可能是巨大的！

生产奥义！

即将要开始生产的你一定又紧张又兴奋。

生产奥义第一条就是保持冷静！无论发生什么情况都要镇定，慌乱会让你的操作变形，从而产生不必要的损失。生产队被抓、即将怪损，请冷静地向FC提供信息，听从FC的指示，完成自己应该做的事情。

生产第二奥义：绝不划水！用老话来说，我们在虫洞的生产方式是平均主义，即你的付出和你的收获不一定对等。三个和尚没水喝的故事想必大家都听过，阻止这个人间惨剧的方式也非常简单，就是 从我做起 。也许别人会有划水行为，但是当每一个人都把责任扛在自己肩膀上的时候，团队的效率就会变得非常高。等待别人先做事情，损伤的也是自己的利益。我们在洞里是一个团队，虽然不会有眼睛盯着你做了些什么，但是你的一举一动大家都会感受到。没有人压洞，我去压洞；没有人做点，我去做点；有人没点遥修我盯着关注列表提醒大家，久而久之大家都会认同你。反之，什么责任都不愿意承担的人，也许一时不会被发现，但是日久见人心。所以请主动承担责任，无论在游戏还是现实，这个品质永远不会让你吃亏。

生产第三奥义:学会容忍。没有谁天生就该会什么东西，每个人都有学习的过程。所以给后来的人一点容忍度。不要因为一点失误就去责怪对方，那很有可能不仅无法解决问题，反而会有更多问题出现。善待新人，每一个新加入虫洞的人就和新加入EVE的新人一样，耐心地帮助他们。宽容的力量远比指责更能解决问题。

总而言之，我们是一个团队，我们是一家人，请时刻牢记这一点。

开工！

简单地介绍一下情况，一支生产队中，大白是奶，勒沙克是火力。同时大白具有 舰队仓库 的功能，贴近大白2500M可以不耗电上线装备和换装。很可惜这里没有T，怪物总会随机开火，当 战列怪 闪红你的时候请一定要及时点要甲！否则死亡几率极大。LSK随时注意切换你的弹药和中槽脚本，这是提高效率很重要的一环。不要停止Dscan！

切回到实际当中。当FC带跳异常点落地后，首先要建立大白的 传电链 。我们采用的是 向下传电 法，在你的中队（后勤中队）当中，你需要锁定你名字的下一个人，将你的 两个 传电挂给他。在传电链成型后，你应该收到你上方的两个传电，同时传电给下一位同志，如果没有收到传电请在Mumble清楚地报出姓名提醒一下他。调整好你的广播，随时遥修选择了要甲的人。注意，甲修是需要转一圈以后才会有修量产生，所以不要走神，及时锁定挂上修。反过来说如果一开始被怪集火的人掉血很快，请不要激动，锁定和产生修量都需要时间，急也没用。你的大白高槽一般会有五个修，但你的电量并不支持你一直开启五个修。一个正常的生产队的大白数量可以让每个大白挂上三个修给被集火目标就能够应对所有情况。你完全可以自行机智地控制电量，只要不死人什么姿势都可以。这里我建议新人：当被集火目标血量下降较快时，挂上个修给他。当他的血量平稳时逐渐减少到三个修。大白特别需要注意的是六个战列怪同时出现的那一波，反应不及时容易出现危险状况。不要停止Dscan！

LSK在平时应当以：战列>战巡>巡洋的顺序焊怪物。请注意一下怪的血量，在眼神交流中和队友配合，不要集火一个目标从而提升效率。LSK最需要注意的是KEY怪。和全宇宙的异常一样，冬眠者也拥有KEY怪，只要你消灭了这一类型的怪物会立刻刷新下一波怪物，这时我们需要花费很大精力面对全宇宙最残忍的怪物的暴动，非常容易怪损。如何判断KEY怪？

打开爱神虫洞网址，输入你的虫洞编号。打开你当前的异常名称，它会告诉你每一波怪的类型、电子战类型。其中带锁的就是KEY怪。在你处于新手期时，请千万不要在清完其他怪前动KEY怪。不要停止Dscan！

绝大多数情况下，LSK需要在最后一波怪清完后开启高槽的炸弹清除积累下来的护卫怪。 基地？ 的第一波key怪是护卫，所以我们要使用炸弹清理它们引出下一波怪。同联盟的舰队一样，被炸弹炸到请不要点遥修！这是基本素质。你会听到你的护盾报警声但不要紧张，咱都是甲抗船。此时大白需要锁定我们的 MTU ，确保它不会被心狠手辣的LSK给炸死。里面装满了你的产出，保护好它。不要停止Dscan！

最后一波怪死亡后会出现一个建筑：隐形的传输中继站。攻击他后， 数字僭祖 就会出现。这个流浪者反击战列舰有极高的速度，旗舰级别的毁电，长达几十公里的100点跃迁干扰和网子，3点跃迁稳定和 整个异常点一半的收入 。看起来很恐怖，实则不过是我们的提款机罢了。在炸弹停止后，放出你的无人机干他。LSK使用近战弹药转速脚本，并在开火倒计时后换上你肚子里的 长反 反住他。没错，这个家伙虽然很强但是过于谨慎，在血量进甲后会尝试逃跑，必须有4点反才能抓住他。如果没有抓住他，他会跑向异常、虫洞口、星体等各个地方，甚至有可能在你清理下一个异常的时候跑回来GANK你，所以不要忘记反住他。当他闪红LSK时，强力的毁电会很快毁干目标的电量。此时请被闪红的LSK点要甲和 要电 ，此时大白不要管要电，挂上你的修，其余LSK将你高槽的一个传电挂给那个小倒霉蛋，可以根据你现有电量自行机智，但是保证BOSS转火前目标和你自己都不要断电。接着LSK往死里焊，挨打点遥修就很快可以解决这个提款机，没有任何难度。在BOSS进入结构前，收回你的无人机方便FC快速带跳下一个点。不要停止Dscan！

以上就是刷异常的所有要点，操作不多也非常简单。双开操作复杂但也没有复杂到那里去，至少比大航简单。所以虫洞刷怪真的是轻松赚得多。

回家

不要以为刷完一切就结束了，我们是过洞生产，回家也是带有风险的。当FC选择带回时，他会将生产队带到安全点，请根据指示朝回洞点加速。此时FC会回收产出，不要停止Dscan！不要在最后一步因为松懈而功亏一篑。等FC回来，他会带跳回洞口，听指示决定是否下线钢板，听指挥有序过洞，再听命令过洞跳回铁壁，这样一次生产就完成了。

要注意，如果生产队人数过多，或者有很多运输船只的人过了C6洞口，洞口质量很可能不够所有人回家，这个时候俗称洞难。不过不要害怕，让你们放在仓库里的扫描探针和纤维就起了作用，会有专业人员指导你们如何逃出虫洞迷宫，回到帝国区或联盟区找到口子回家的。

关于产出，它们需要被运输到收购NPC的空间站里的。所以不要着急，等到合适的口子出现会有满技能的大佬出掉产出给你发钱。如果你很急的话你可以选择自己出产出，但是出现问题你要自己掏钱包补偿。 大家都很希望产出早点变现。
