# 步入虫洞

> 来源：<https://docs.qq.com/doc/DQk9uelNKZlBDVGNC>（原文作者见 `author` 字段；内容转载自腾讯文档归档）

:::tip 洞的编号
虫洞星系编号以 J 开头（如 J123456），其中 **J0 开头为破碎洞**；洞口大小用 C1–C6 表示等级，等级越高洞内资源与难度越高。
:::

虫洞和其他地区最大的差异在于两点:

1、本地频道不显示人数(除非在本地说话，注意非特殊情况请勿在本地随意打字，暴露自己是愚蠢的行为)

2、交通的不确定性，虫洞通道受到总通过质量，单次通过质量以及极化的影响。

虫洞主体分为两个部分：虫洞星系和虫洞信号

虫洞星系：你进入一个虫洞以后会发现它和其他的星系一样，也会有恒星行星卫星，星系名称一般为J1XXXXX，如下图所示

根据星系信息我们可以通过一些网站得知这个虫洞被ccp赋予的属性，以上图J161411为例

![image2](/images/wormhole-basics/image2.webp)

通过查询我们查到虫洞最基本的信息，比如虫洞的固连洞口，虫洞的天象，这些信息可以帮助你更快找到高安低安00洞口。

特殊的虫洞：破碎洞/席拉

破碎洞：特点是其洞内所有行星都为行星（破碎的）。这种洞不能下建筑和杆子，一般以海盗怪为洞内特色，比如萨沙洞、血袭者洞。洞内有可能有大量6-10 10-10。喊上队友蹲你保护你的安全，一起发财。

席拉（Thera）：唯一有空间站的虫洞，背景是eve姐妹会的探索据点，席拉洞人员流动大，洞口产生速度快，一般席拉洞需进行特别注意防止敌对大规模人员进入联盟领地。

联盟日常参与扫描存点的人需要注意，直接右键信号存点只是存了虫洞的信号点0m，离洞口一般还有2km-7km的距离，为了预防突发情况，洞点必须存在洞口0m！洞点必须存在洞口0m！洞点必须存在洞口0m！

所以标准的存点步骤是 扫到虫洞信号，隐跳到虫洞100km，右键虫洞天体图标进行存点

请注意，2级洞和5级洞需要慎重对待。当前版本的洞团一般以2级洞为高安洞口，5级洞为生产洞口，遇见这种等级的洞一般会有其他玩家活动，危险性也会大大提升。

扫描与侦察一般使用具有隐秘行动能力的小白或者任意一族T2隐侦,推荐使用Astero, Buzzard, Helios. 高富帅可以采用扫描T3+全套扫描蛋

![image5](/images/wormhole-basics/image5.webp)

过洞后立即保存洞口为home点；跳任意天体50到100km，并迅速隐形，在跃迁途中按CTRL+B保存为个人安全点。

360°14AU做一次Dscan扫描如有玩家活动的迹象，立刻在mumble反映情况,在值守舰队或预警频道做简要说明（把虫洞星系名称 天象 洞口最大通过质量 敌对舰船汇报给FC）保持隐形待命；如果确认没有情况后按F9打开地图观察是否有建筑，把建筑所属的公司拉到舰队（如果洞内有星城之类的东西,尽快撤离，你可能误入了高洞团的母巢）；如果有余力可以自行查阅建筑所属公司、虫洞kb来帮助舰队进行下一步指令。

确认没有危险，解除隐形，下针，起跳安全点并尽快隐形，开始逐个扫描信号（回家口的位置可以观察得出，可以留到最后扫描）并按做点规范保存位置在指定文件夹里。扫描过程中的虫洞点一定要按照做点规范保存坐标。坟和数据点可以在扫描结束后自行处理。

扫描过程中保持一定频率的D扫更加安全（BV一起按）。

虫洞洞口的阶段机制

虫洞的洞口分一二三四这三个阶段，而影响一个洞口是几阶段的因素有两种：质量和时间。

第一，质量。一个洞所有通过它的船只都会对它的质量造成影响（这里忽略护卫和驱逐级别的），而洞口的质量是有一定上限的（根据具体是什么洞口决定），超过这个上限洞口就会直接崩塌，利用这一点，我们可以进行日常人为的塌洞排除危险，也可能运用到在虫洞的战斗中。当洞口允许通过总质量减少到0或者为负的时候，洞口就会坍塌。（比如说哪怕洞口剩下的通过总质量只有1KG了，在单次允许通过质量范围内的船只一样可以通过。但是通过后，该洞口立刻坍塌。）

当洞口质量还剩下50%和10%的时候，与刚刚刷新相比，他的大小会显得更小。

（质量影响有三种阶段）

一阶段：剩余质量大于50%，小于100%

“质量未受到影响”。

二阶段：剩余质量大于10%小于50%

“已经受到影响，但不严重”。

三阶段：剩余质量小于10%

“即将崩塌”。

第二，时间。一个洞口并不是无限期存在的，洞口是逐渐衰减到消失的，如果看到一个时间三阶段的洞口而你又不能确保它是什么时候出现的，为了安全最好不要过或者带着有探针的船过，这样被塌在对面还能想办法扫出去。

（时间影响有四种阶段）

一阶段：可以存在的时间大于24h。就是刚刚扫出来。

“该虫洞尚未进入自然周期的衰退阶段”，它还能开放一天。

二阶段：可以存在的时间大于4h。小于24h

“该虫洞已经开始衰退”。可能撑不了一天。

三阶段：可以存在的时间大于5min。小于4h

“该虫洞即将到达它的生命周期”。

四阶段：可以存在的时间小于5min。

“该虫洞即将化为乌有”。

极化：连续穿越同一个虫洞洞口两次将会有4分钟的“极化”限制，使你不能再次穿越该虫洞洞口。

作战中因为虫洞和星门不一样，即使开火也可以直接过洞，所以极化现象是一种平衡，pvp行动中要注意敌我的极化时间。

塌洞：当开推经过洞口时，由于开推了的影响，导致质量会增加，从而提升塌洞效率，计算好每次通过的质量是能否成功塌洞的关键。一般塌洞由装备了同吨位希格拉粒子锚插的船进行，零界纠缠盾抗重拦进行补刀，具体操作请根据洞口质量结合描述自行机制。超大洞一般需报备给值班fc，确定不会有联盟级别行动后再做塌洞处理。不要做一个无脑的塌洞兽哦。

当前版本的虫洞刷新速度加快，在00地区生产，一次懒惰，可能会让整个联盟为你擦屁股，为了自身的安全和联盟行动的需要，多扫洞，多报备，保证自己的安全，增加联盟活动的内容，才是一个有好习惯的联盟成员。
