# 贸易与市场

本板块收集贸易与市场经营相关的攻略。EVE Online 有相当真实的经济系统，从规划账号发展、节约战备开支，到规避诈骗合同与不合理市场溢价，再到逐步理解游戏商业市场、成为商业大亨，尽在于此。

## 主要方向

- **市场交易**：游戏内主要的公共市场与联盟集结地市场的挂单买卖，订单管理。
- **快递服务**：常用运输路线，如何利用快递节省成本、规避市场溢价。
- **合同须知**：物品交换合同、快递合同与拍卖合同的使用，与如何识别和规避诈骗合同。
- **市场工具**：常用估价工具与价格数据来源。
- **市场规则**：联盟市场条例与交易注意事项。
- **商业进阶**：PLEX 市场、如何以最优价格购买月卡、LP 市场等。
