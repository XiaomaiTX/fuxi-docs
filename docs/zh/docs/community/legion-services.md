# 军团服务

伏羲军团作为EVE Online历史悠久的大型军团，具有健全的军团服务与游戏内容。

## 军团IT平台

[军团SEAT](https://seat.fuxi-legion.com)是军团运营的核心平台，涵盖**舰队补损**，**福利发放**，**技能规划**，**角色管理**等功能。

## 法拉利快递服务

法拉利快递`Ferrari Express`是隶属于伏羲军团的工业运输军团，为军团成员在活动区域提供便捷的快递服务。

运费，服务等明细详见**集结群公告**或[官方网站](https://ferrari-express.nantianmen.space)，以二者最新消息为准。

## 独享工业星系

位于特布特星域的**V0DF-2**星系是伏羲军团与其附属工业团的**独享工业星系**，提供相关工业服务。
