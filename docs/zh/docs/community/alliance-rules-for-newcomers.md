# 新人经常触犯的联盟规则

:::warning 规则以当期公告为准
联盟规则会随管理调整。本文整理的是新人最常触犯的几条，发生争议时以联盟当期公告与管理人员的裁定为准。
:::

- 新人经常触犯的联盟规则

0，在错误的地方刷怪或挖矿或扫信号。

FRT的成员必须在双熊猫头主权刷怪，如果你看不懂这句话，在群里先问清楚。具体可看：FRT刷怪规定

FRTU的成员会有自己的专属刷怪星座，入团邮件会告诉你，新手群也可以询问。

第一次警告，第二次严重警告，第三次可能会飞。总监群也会留下截图记录，请不要当那个麻烦。

1，隐轰炸弹带错类型或自己失误误炸队友。对受害人等值赔偿，情况严重可能被踢

如果你不知道怎么用隐轰，不明白什么是4种炸弹类型，什么是聚焦涅槃，什么是涅槃，别带炸弹。

2，舰队战斗未授权战场打捞，丢MTU，退舰队捡垃圾，可征求由当值舰队 FC 同意后就地击杀，连续触犯踢团黑站。

没有指挥同意，不要乱捡垃圾，越值钱的麻烦越大。一般的T2装备和弹药可以随便捡，没事的。绝对不要丢MTU。

3，如果被蓝加攻击，先截图并保存战斗记录。如果没有被蓝加攻击，不得以一切理由攻击蓝加。

如果你觉得某个蓝加是脚本，和总监举报，不要自己干一些攻击别人船体或者打无人机的事情。

4， 禁止本地市场购买物品，加价挂单出售。禁止在本地接受联盟合同，加价重新挂出合同。_禁止在本地市场扫货后，重新出售或出口至其他地区。_

_上述三种情况都视为RELIST，一经查实，将限制违规者一周内不能使用市场。如果再犯，延长违规者不能使用市场的时间，情形恶劣的加入联盟黑名单。_

5，FRTU的号不允许在寂静谷刷怪，挖矿，扫描。只允许运输，行星开发，工业制造，和打自己刷怪出的远征。

等你符合条件以后可以加入FRT主团，就没有这些限制。

6，使用大航飙车PVP，损失自负。使用大航刷怪，一次违规联盟黑名单。

别用大航刷怪，后果严重。

7，刷异常不报点，打捞垃圾没有征求同意，会被警告。

8，挖坟或者破解必须清完所有箱子，不要用货柜扫描只挑值钱的开。被举报者警告，多次违规踢团。

9，公共星系锚定星门泡泡用于反收割的，需在门后200km以上锚定。

不得锚定在星门后200km以内，不得锚定在星门前，不得锚定在星门0米，不得锚定在500km以外。锚定规则的目的是使友军可以反向加速直接起跳星门。必须有人值守。锚错的泡泡会被打掉。

10， 超旗只能在 WC 成员联盟之间出售。 你不可以出口超旗，亦不可把超旗放在公开合同。 超旗不允许出售给租户。不允许使用超核网络公开赌博超旗。

***如果某超旗经由正式FC，嫌疑人所在公司管理，或者联盟级管理判定是走私行为，******超旗******会被击毁，即使被夺回，******超旗******也必须被销毁。请注意以上人员必须保留非常详细的证据链，时间线，涉事人物。 ***

11，寂静谷本地和联盟各个频道，不得发超网链接。

12，不要有诋毁其他盟内军团和拉人的行为。如果对招新感兴趣，可以联系管理，不要通过任何矮化友军或者挖墙脚的行为来宣传。
