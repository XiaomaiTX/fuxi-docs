# 联盟服务

伏羲军团是**凛冬联盟群（Winter Coalition，简称 WC）**的成员军团。凛冬成立于 2017 年 10 月，由原 OSY 华人社区发展而来，以Fraternity.为主导力量，是联合不同时区、不同语言联盟的全时区联盟群，内部分为以中文为主的 WC-CN 和以英文为主的 WC-EN 两部分。

本页汇总联盟为成员提供的各类服务，以及对应的官方文档入口。具体费率、地址与规则可能随时调整，使用时请以**联盟 Wiki 与联盟公告**为准。

:::tip 服务可能随时变更

本页仅作导航与总览。涉及金额、地址、保证金比例等可能变动的信息，请以 [凛冬联盟 Wiki](https://wiki.winterco.org/zh/start) 对应页面为准。

:::

## 账号与认证：SeAT

[SeAT](https://wiki.winterco.org/zh/guide/it/seat)（<https://seat.winterco.org>）是联盟的身份认证、数据与服务管理中心，也是使用其他联盟服务的前提。

- 使用 EVE Online 账号注册后，需要关联自己名下的**所有角色**；
- 联盟语音、Discord 等服务的权限由 SeAT 同步；
- 出勤（PAP）查询、补损（SRP）申请等均在 SeAT 中完成；
- 在 SeAT 中绑定在一起的一组角色视为**一个成员**，各项考核按「成员」而非单个角色统计。

## 通信与集结

### 语音：Mumble

[Mumble](https://wiki.winterco.org/zh/guide/it/mumble) 是联盟指定的团队语音平台。联盟规定**成员上线游戏必须加入语音频道**，以便及时组织救援行动。

| 项目   | 说明                                               |
| ------ | -------------------------------------------------- |
| 客户端 | <https://www.mumble.info/downloads/>               |
| 前提   | 已加入军团并完成 SeAT 绑定                         |
| 要求   | 设置按键发言（蓝麦），建议同时设置本地发言（黄麦） |

:::warning 警惕仿冒官网

`mumble.com` 与 Mumble 官方无关，请只从 <https://www.mumble.info/downloads/> 下载。

:::

联盟在多个地区部署了语音服务器（中国大陆、欧洲、新加坡、澳大利亚、北美、南非），具体地址见 [Mumble 文档](https://wiki.winterco.org/zh/guide/it/mumble)。

### 消息与集结：Discord 与 QQ

[Discord](https://wiki.winterco.org/zh/guide/it/discord) 是联盟主要的图文与语音社区，[QQ](https://wiki.winterco.org/zh/guide/it/qq) 承担面向国内成员的集结通知。

Discord 频道按用途划分，常见的有：

| 类别       | 频道示例                                                          | 用途                                      |
| ---------- | ----------------------------------------------------------------- | ----------------------------------------- |
| 应急与情报 | `#help-my-rorq-tackled`、`#attack-notifications`                  | 大鲸鱼（Rorqual）被缠求救、建筑被攻击通知 |
| 军事       | `#frt-alliance-pings`、`#frt-military-pings`、`#frt-mining-pings` | 联盟及军事相关内容、月矿与挖矿集结        |
| 社区       | `#general`、`#pvp`、`#trading`、`#services`                       | 闲聊、PVP 讨论、交易、服务广告            |
| IT 支持    | `#helpdesk`、`#shipping-helpdesk`                                 | 服务问题求助、快递相关咨询                |

联盟同时设有德语、西班牙语、法语、俄语等语言频道。安装 Discord 后需在 SeAT 中完成关联才能获得完整权限。

## 物流、工业与贸易

### 快递货运

联盟提供了联盟内部使用的小件速递与大宗货物运输服务，代表服务为 [S.F Express 顺丰快递](https://wiki.winterco.org/zh/services/courier/%E9%A1%BA%E4%B8%B0%E5%BF%AB%E9%80%92)。

- 通过游戏内**私人合同**挂给快递公司执行；
- **必须填写保证金（Collateral）**，它是事故赔付的唯一来源，未填写的合同会被拒接；
- 合同内不能包含箱子（Plastic Wrap）——含打包盒的合同无法退回；
- 费用按体积（ISK/m³）或包船距离计算，有起步费与体积上限，详见 [快递服务总览](https://wiki.winterco.org/zh/services/courier/start)；
- S.F Express 提供运费计算器：<https://sf-express.winterco.org/>。

### 固定收购（回购）

[Panda Logistics](https://wiki.winterco.org/zh/services/buyback/panda_logistics) 是联盟直属的回购服务，以非盈利为宗旨，协助成员资金回流与联盟战备保障。

- 收购矿物、打捞件、衍生装备与行星产物等（不含蓝图、损坏物品、未打包船只、深渊物品等）；
- 以约吉他收单价的 95% 回购（以联盟 Wiki 为准），报价流程通过 <https://www.e-351.com/buyback/panda-logistics> 完成；
- 合同备注中需粘贴 **Janice 静态估价链接**以锁定估价，否则可能因市场波动被拒单。

### 旗舰制造与工业

联盟在多个星域部署了旗舰与超级旗舰制造设施，并通过工业地图公示工业中心、反应中心与行星生产区域的分布与规则，详见：

- [联盟工业与制造指南](https://wiki.winterco.org/zh/services/capital_manufacture/start)；
- [联盟服务（含联盟工业设施分布）](https://wiki.winterco.org/zh/guide/corporation_handbook/setcr_handbook/%E8%81%94%E7%9B%9F/%E8%81%94%E7%9B%9F%E6%9C%8D%E5%8A%A1)。

### 市场与交易规则

联盟对内部市场与合约交易有明确规定，包括禁止将联盟合同或市场中购买的物品加价转售、禁止向中立或敌对势力出售超旗等，详见 [市场条例](https://wiki.winterco.org/zh/rules/trade/markets)。

## 社区、治理与外交

- **联盟规则**：所有成员活动均受 [联盟规定](https://wiki.winterco.org/zh/rules/start) 约束，核心原则是「友善诚实，团结互助」。纠纷举报应先联系所在军团管理，再由军团管理联系联盟管理。
- **外交**：与友军势力或联盟外势力发生纠纷时，由 [联盟外交官](https://wiki.winterco.org/zh/coalition/leadership) 负责协调；联盟亦公开现有 NIP 协议。
- **联盟论坛**：<https://forums.winterco.org/>，用于交流、提案与官方公告。
- **联盟动态**：[联盟更新](https://wiki.winterco.org/zh/alliance_news_and_update/start) 与 [联盟日志 Daily of Alliance](https://wiki.winterco.org/zh/daily_of_alliance/start) 记录最新消息。
- **教程资源**：[教程区](https://wiki.winterco.org/zh/guide/start) 汇总联盟编写的各类指南，[总览设置](https://wiki.winterco.org/zh/guide/overviews) 提供推荐总览。

## 租地服务

联盟对外提供 [租地服务](https://wiki.winterco.org/zh/renting)，租户通过定期缴纳星币获得部分闲置星系用于生产作业，由租地管理联盟 Azure Citizen（宝蓝公民）负责管理，主要面向专心生产的玩家。
