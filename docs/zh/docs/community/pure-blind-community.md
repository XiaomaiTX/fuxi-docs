# 黑渊社区教程

**黑渊（Pure Blind）** 是伏羲军团的主要生产星域。本页介绍黑渊的地图、死亡克隆集结点、新人生产方式推荐、语音导航，以及军团提供的回收与联系渠道。

各条生产路线的具体打法已拆分到攻略板块，见文末「生产路线教程索引」。

> **数据时点：2026-10**。文中标注 `xxM` 的收益为军团文档中的留空占位，实际数值随版本与市场波动，请以军团最新公告为准。

## 死亡克隆集结点

1. 在游戏左上角的搜索框中输入 `5ZXX-K - Uncle Huang's retire house (Fuxi Holding)`，将该目标设为终点。
2. 进入建筑后，点击左上角头像 → 基地空间站 → 选择基地空间站 → 选择当前空间站。

## 成员生产顺序与优先级

- **刷无畏标 / 航母标**：需要 5 个角色号，可以单人或多人拼标生产，预期收益单号每跳（20 分钟）约 `xxM` ISK。
- **炸鱼**：组队刷避难，几个人凑一个炸避难的队伍，在黄圈区域生产，预期收益 `xxM`。
- **狂怒者级（狂怒）挂集会点**：ISK 足以覆盖狂怒的损失，收益主要来自 6/10 信号，一个信号约 130M ISK。
- **yst挂避难**：预期 ISK 收益 `xxM`，另有产出的信号价值 `xxM`。
- **刷莫德团任务**：吃 LP，需要三开，按当期 LP 价格折算每小时收益 `xxM`。
- **姐妹会任务**：吃 LP，需要多开，按当期 LP 价格折算每小时收益 `xxM`。

### 无氪金新人的建议生产方式

分两种情况：

**有值守舰队时**（通常是游戏 DT 后，即 +8 时区晚上 7 点到十点半）：

- **灾难炸鱼**：几个人凑一组，在黄圈星系生产。
- **刷旗舰标**：开多米尼克斯级（多米）几个人凑一组，在篮圈星系生产。

**无值守舰队时**（无法上语音等情况）：

- **狂怒挂集会点**：军团提供无限续杯的狂怒，并按固定价格收购产出的远征。
- **扫信号挖气云**：军团提供生产船与回收体系。
- **yst挂避难**：军团按固定价格收购产出的远征。

## 军团服务与联系

| 事项                | 说明                                      |
| ------------------- | ----------------------------------------- |
| 航母标 / 无畏标采购 | 集中采购更优惠，联系军团负责人            |
| 异常信号产出回收    | 军团按固定价格收购（狂怒 / 伊什塔级产出） |
| 气云产出回收        | 可售予回收矿物的玩家，或直接回收给军团    |
| 日常沟通            | 军团 QQ 群，同时用于集结通知              |
| 任务区情报          | 黑渊任务频道，含炸弹堵门提醒              |
| 教程答疑            | 军团群内联系文档维护者                    |
