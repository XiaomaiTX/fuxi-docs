# 客户端、账号与加速器

## 下载并安装 EVE Online 客户端

建议通过 [官网安装](https://www.eveonline.com/download)。下载完启动器后，游戏会进行第一次更新；建议在更新期间完成账号注册与登录，并在设置中勾选下载完整客户端，下载完成后再打开游戏。

> 未下载完整客户端可能导致游戏过程中出现异常卡顿。

## 注册 EVE Online 账号

注册 EVE Online 账号时**务必使用 [军团注册链接](https://invite.fuxi-legion.com)**：在该界面输入邮箱、用户名和密码即可注册。

:::tip 同一个邮箱可以注册多个游戏账号

同一个邮箱可以注册多个游戏账号；游戏登录使用的是用户名 + 密码，偶尔需要邮箱验证码，请保证你的邮箱有效可用，建议使用网易邮箱、Outlook、Gmail 等。

:::

## 为什么要使用军团注册链接

EVE Online 对招新官与经过链接注册的新玩家都有丰厚奖励，而军团会对使用军团注册链接的新玩家提供额外的返利。

新玩家使用链接注册后，可以获得 100w 自由技能点的奖励；新玩家在使用链接注册后，如果充值了 PLEX 或者购买了 Omega 时间，可以联系招新官提供充值返利。

:::tip 已经注册的账号如何领取招新链接的 100w 技能点

如果你通过官网自行注册了，后续依然可以在招新链接中登录来领取 100w 技能点。但请确保你使用了军团招新链接，否则不提供任何充值返利活动等。

:::

## 运行游戏为什么需要加速器

游戏内诸多操作受到服务器延迟的限制，包括但不限于：跳跃星门、锁定、激活装备、频道发言、市场交易等等。不使用加速器可能导致较大的操作延迟，严重时可能导致过门卡顿、掉线等，极有可能导致舰船损失。

## 开始游戏前的检查清单

- **身体状态是否正常，如果过于疲劳或者犯困，早点休息，睡觉损是这个游戏极为常见的死亡方式**
- 检查游戏是否已下载好完整资源
- 检查 Mumble 语音设置
- 检查加速器是否正常开启
