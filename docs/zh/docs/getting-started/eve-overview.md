# 认识 EVE Online

## EVE Online 是什么游戏

EVE Online 是一款以太空为背景的**沙盒型大型多人在线角色扮演游戏（MMORPG）**。玩家扮演克隆飞行员（Capsuleer），驾驶舰船在名为**新伊甸（New Eden）**的宇宙中探索、战斗、生产与贸易。

与大多数 MMORPG 不同，EVE 没有固定的主线剧情，也不强制玩家的成长路线。游戏提供的是一个**由玩家驱动的世界**：市场物价由玩家交易决定，星域主权的归属由玩家联盟的战争决定，军团与联盟的组织、外交与政治都发生在玩家之间。因此"在 EVE 里做什么"更多取决于你自己的选择，而不是游戏给你的任务列表。

EVE 自 2003 年上线运营至今，宇宙中包含**超过 7,000 个恒星系**，全部玩家共享同一个游戏世界。

## 在 EVE Online 里可以做什么

官方的新手指引把玩家的玩法方向归纳为四条职业道路，可以随时切换或同时尝试：

| 职业道路     | 主要活动                                                  | 对应本板块                 |
| ------------ | --------------------------------------------------------- | -------------------------- |
| **执法者**   | 挑战 NPC 势力与犯罪目标，参与安全任务，维护（或挑战）秩序 | 见下文「战斗与舰队行动」   |
| **自由战士** | 与其他玩家对抗，从单挑、小队战到大规模舰队会战            | 见下文「战斗与舰队行动」   |
| **探险家**   | 探索遗迹与数据站、规避危险、寻找虫洞与捷径                | 见下文「探索与其他玩法」   |
| **工业家**   | 采矿、提炼、制造舰船与装备、参与市场贸易                  | 见下文「采矿、工业与制造」 |

游戏内可以同时参与的内容远不止这四类，下面按主题展开。

### 战斗与舰队行动

- **PvE**：清理异常空间与死亡空间、执行任务、击杀 NPC 势力舰船。
- **PvP**：从单人遭遇战、小队伏击，到数十至数千人参与的主权战争与旗舰会战。
- **舰队行动**：由舰队指挥官（FC）统一指挥的集体作战，是新人融入军团、获取出勤（PAP）与补损（SRP）的主要途径。

EVE 中舰船被击毁后**不会复活**，损失是真实的。这使战斗决策具有实际代价，也是游戏经济与玩家政治能够长期运转的基础。

### 采矿、工业与制造

- **采矿**：在小行星带、冰带、月矿与气云点开采原料。
- **工业与科研**：将原料提炼为矿物与材料，再制造舰船、装备与弹药，或研究蓝图提升效率。
- **行星工业**：在行星表面建立生产线，稳定产出中间材料与成品。

工业链条覆盖从原料到成品的完整环节，每个环节都可以成为独立的收益来源。

### 贸易与市场经营

- 游戏内所有可交易物品都由玩家挂单定价，玩家之间可以**低买高卖**、跨星域倒卖赚取差价。
- 常见经营方式包括区域贸易、合同买卖、运输服务与制造业配套供应。
- 市场的供需波动会直接反映在物价上，阅读市场数据本身就是一项技能。

### 探索与其他玩法

- **探索**：扫描并破解遗迹、数据站，获取蓝图、材料和稀有道具。
- **虫洞空间**：连接不同星域的不稳定通道，风险与收益都更高。
- **任务与势力战争**：承接 NPC 势力任务，或加入势力战争参与低安全区域对抗。
- **社交与组织**：军团管理、外交、间谍活动、情报与后勤，都是 EVE 中真实存在的"玩法"。

## EVE Online 的基本特色

| 特色               | 说明                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| **单一共享宇宙**   | 全部玩家在同一个游戏世界中活动，市场、政治与战争都是全局性的                  |
| **技能离线训练**   | 技能训练**实时进行，与你是否登录游戏无关**；一次最多可安排 150 个技能进入队列 |
| **技能点与属性**   | 训练速度由角色的主要/次要属性、克隆状态与植入体共同决定，前期规划影响长期效率 |
| **玩家驱动的经济** | 几乎所有物品都由玩家生产与交易，物价由市场供需决定                            |
| **真实损失**       | 舰船与货物被摧毁后不会返还，风险意识是 EVE 的核心素养                         |
| **团队合作取胜**   | 结果更取决于规划、情报与组织协作，而非个人单打独斗                            |

### Alpha 与 Omega 克隆状态

EVE 提供免费与订阅两种状态，账号是否有游戏时间决定角色的克隆状态：

- **Alpha（免费）**：可免费游玩，使用战列舰及以下的大部分舰船，为标准技能训练速度，部分系统（如合同、行星工业、工业与科研税费）受限。
- **Omega（订阅）**：解锁全部舰船（含二级科技与旗舰）、技能学习速度翻倍、完整技能树与合同系统等。

需要说明的是，Omega 状态既可以用现实货币购买，也可以用游戏内赚取的**伊甸币（PLEX）**兑换——也就是说，善于经营，勤于生产的玩家可以不花钱维持 Omega。

## 新玩家应该先建立的认识

1. **先选一条路，再谈深入**：不必一开始就学会所有玩法，跟着官方新手教程完成基础操作，再咨询军团新人教官选择玩法和发展路线。
2. **舰船是消耗品**：EVE 中"船被爆掉"是常态，不要为了保住一条船而不敢行动；损失本身就是学习成本。
3. **技能训练越早开始越好**：训练队列是离线进行的，早一天排上队列就早一天积累。
4. **有个组织比单打独斗重要得多**：EVE 的高价值内容（舰队会战、大规模工业、区域战争）都依赖团队协作，加入军团，参与军团活动是快速上手游戏并赚取大量收益的捷径。
5. **欧服（Tranquility）与国服（Serenity）是两个独立世界**：角色、资产与市场互不通用，伏羲军团所在的是**欧服**。
