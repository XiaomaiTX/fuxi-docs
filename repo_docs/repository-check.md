# 仓库维护任务清单

本文列出可周期性启动的仓库维护任务及其检查内容。

## Rspress 站点规范审查

- **Skill：** `rspress-best-practices`
- **检查内容：** `rspress.config.ts` 配置、文档目录和导航、frontmatter 与中英文内容一致性、MDX 和主题实现、静态资源引用、搜索与机器可读输出、构建和部署设置。

## 代码与文档检查

- **命令：** `pnpm run lint`
- **检查内容：** ESLint 规则和文档作者字段。

## 站点构建检查

- **命令：** `pnpm run build`
- **检查内容：** 文档作者字段及 Rspress 静态站点构建是否成功。

## 站点运行抽查

- **命令：** `pnpm run dev`
- **检查内容：** 中文和英文入口、导航、页面渲染、内部链接及静态资源显示。

## 中英文内容与术语审查

- **检查范围：** 按主题对照 `docs/zh/` 与 `docs/en/` 中的对应页面。
- **内容同步：** 核对重要事实、步骤、限制条件和更新状态是否一致，记录缺失页面、过期内容及实质差异。
- **EVE Online 术语：** 按游戏语境审校中英文术语，优先采用游戏内或官方资料使用的名称；没有明确官方名称时，采用玩家熟悉且含义清楚的表达，并在两种语言中保持一致。避免脱离游戏语境的直译或一般词义误用；对不确定的术语记录上下文以便核实。
